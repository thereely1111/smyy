- 频段区间/时间区间的**写法与取值合法性**未经数值核验（是否统一为 `[a,b)`、是否满足 0 ≤ a < b ≤ 100、时间端点是否非负且为整数）→ 若存在闭区间、越界或格式混写，需先定清洗口径（**UN7，待实测**）。

- 时间轴上界 `T_ceil = max_i(E_i+(n_i−1)P_i)` 未实测（影响 q03 资源包络，需下游算出）。
- 无缺失值的直接证据：数值列 n=150 完整；字符串列需核验无空单元格。

## 4. 逐问契约（详细字段见 `truth/problem_contract.json`）

### q01 问题1｜时频冲突检测
- **动词**：检测（判定 + 枚举 + 统计），**非优化**。
- 输入：附件1 全部 150 行；R1–R4、R12。
- 输出：`result1.xlsx` 每行一对冲突装备（无序去重）+ 论文冲突统计（对数、类别组合分布、装备冲突度分布、窗口重叠次数合计）。
- 约束：判定必须基于「频段交叠 ∧ 时间交叠」；不修改任何参数；输出须被 3 列模板容纳。
- 完成判据：冲突集合完备且无假阳性（两套独立实现互校 + 抽样回代 + 对称/对角零/无重复结构检查）。

### q02 问题2｜冲突消解
- **动词**：消解（离散决策优化 + 可行性判定）。
- 输入：附件1 原始集、q01 冲突清单、R5–R12。
- 输出：`result2.xlsx`（仅登记被改动装备：B 列频段 或 C 列时间 或 D 列「是」）+ 论文**表1**（A/B/C × 保留/调整/撤销）+ 供 q03 使用的无冲突计划集。
- 关键约束：单参数或撤销（R6）；|δ^f| ≤ 10、|δ^t| ≤ 5（R10）；不调次数与间隔（R7）；频段数不变、频段索引 ∈ [0,100)（R2，题面未给类别频段限制）；目标方向 少撤销 ≻ 保 A ≻ 少调整 ≻ 小幅度（R8/R9/R10）；**硬条件：消解后冲突数 = 0（含新引入冲突）**。
- 完成判据：静态校验器对全 150 计划复算冲突为 0，且逐行核查单参数/幅度/频段合法性全部通过；表1 计数守恒。

### q03 问题3｜最多还能安排多少 C 类
- **动词**：最大化安排（装箱/填充优化）。
- 输入：q02 的无冲突计划集（题面「基于问题2 求解得到的无冲突用频计划」）、C 类参数模板（UN4）、资源口径（UN2/UN3）。
- 输出：最大可新增 C 类数量 K + `result3.xlsx`（序号｜频段区间｜时间区间）+ 论文说明。
- 约束：新增计划之间及与既有计划均零冲突；**可用频段 = 全部 100 个频段**（题面无类别频段限制）；频段数不变、时间为 Δt 整数倍；**取消 10Δf/5Δt 幅度限制**（题面明示）；「不增加时频资源」（口径待确认）。
- 完成判据：给出可行放置 + 可审计的资源计数上界及间隙；若仅得启发式解必须如实标注，**不得称全局最优**。

### q04 问题4｜允许 C 类调整间隔时长的消解
- **动词**：消解（q02 动作集扩张后的松弛变体）。
- 输入：附件1 原始集 + q01 冲突清单（题面「对**问题1** 中检测出的时频冲突进行消解」→ 不依赖 q02 的解）。
- 输出：`result4.xlsx`（A 编号｜B 频段｜C 时间｜D 间隔｜E 撤销）+ 表1 统计 + 与 q02 的同口径对比。
- 约束：间隔调整**仅限部分 C 类**，`|δ^T| ≤ 10Δt`；仍守 R6（一个计划只调一个参数）；建议沿用 R10 幅度上限（UN5）；次数仍不动（R7）。
- 完成判据：零冲突 + 间隔约束逐行核查（类别与幅度）+ 表1 守恒 + 与 q02 差异量化。

- **主 q01_m01（库外，最小可行）**：时频占用集合展开 + 逐对交叠判定（稀疏集合 与 0-1 布尔矩阵**双实现互校**）。
  `conflict(i,j) ⟺ B_i∩B_j≠∅ ∧ ∃u∈W_i,v∈W_j: u∩v≠∅`；矩阵形式 `⟨M_i,M_j⟩>0`。
  规模论证：C(150,2)=11175 对，每对 ≤ n_i·n_j ≤ 144 次窗口比较 ⇒ 约 10⁶ 级运算，**可穷举精确解，无需启发式**。
  步骤：解析区间→校验(0≤l<r≤100 等)→生成 B/W/O→频段倒排分桶剪枝→逐对判定→输出无序对 + m_ij→双实现比对→统计。
  风险：AS1 口径错误（系统性偏差）、开闭区间解析、重复/自对、result1 与论文统计口径不一致（UN6）。

### q02 冲突消解
- **主 q02_m01｜M-OPT-002（IP/MILP）**：候选动作**预枚举** + 分层（字典序）0-1 规划 + 冲突割平面迭代。
  动作集 `A_i = {δ^f∈ℤ∩[−10,10]} ∪ {δ^t∈ℤ∩[−5,5]} ∪ {撤销}`，`Σ_k x_{i,k} ≤ 1`（R6）；
  目标 `min 撤销数 ≻ min A 类被调整数 ≻ min 调整总数 ≻ min Σ|δ|`；
  硬约束用**动作对兼容性表 compat(i,j)**（两动作组合是否消解原冲突且不引入新冲突）表达，替代无界 big-M（满足卡片 hard_constraints）；
  迭代：先解松弛覆盖模型→静态复算→把新暴露冲突对作为割加回（建议迭代上限 ≤20 轮，未收敛降级）。
  所需附件字段：附件1 全 5 列 + q01 冲突清单 + 类别映射(AS4) + 频段合法域 + 时间包络。
  终止：gap ≤ 1% 或分层目标逐层固定，且零冲突校验通过。
  风险：compat 表稀疏存储、新冲突不收敛、多解不唯一（需固定求解器版本/分支规则）、求解时间不可控。
- **备 q02_b01｜M-OPT-007**：冲突图最大权独立集（先定保留集）+ 最小幅度贪心平移 + 局部搜索/模拟退火。**须报告种子、重复次数与最好/平均解，不得标为全局最优**。启用条件：MILP 30 min 仍 gap > 5% 或规模超限。
- **口径备选 q02_a01｜M-OPT-004**：把 R8/R9/R10 作 4 目标求 ε-Pareto 前沿，交由闸门选点（仅当 UN8 选「加权权衡」时启用；不虚构权重）。

### q03 最多新增 C 类
- **主 q03_m01｜M-OPT-002（集合装载/装箱型）**：逐频段 0-1 空闲位图 `Occ[b,t]` → 枚举候选模板 `(l,S)`（w 固定时 l 约 90 个、S 在 `[0,T_ceil−(n−1)P−L]`）→ 位图按位与筛除与既有计划冲突的模板 → 互斥约束 `z_i+z_j ≤ 1`（模板重叠）→ `max Σ z_j`；贪心（FFD 型一维装箱）先给下界作 warm start。
  上界论证（论文「最多」的可信度来源）：`K_ub = min( ⌊|F|/(n·L·w)⌋ , 逐频段空闲段切分容量 )`，并报告 `K_ub − K`。
  所需数据：q02 输出的无冲突集、C 类参数模板（UN4，需实测 w、L）、UN2/UN3 口径、合法域 [10,100)。
  风险：上界与可达解间隙（不得把下界解称"最多"）、UN4 未定导致单计划格子数错误、新增计划之间的频段耦合、result3 不含间隔/次数需论文显式声明取值。
- **备 q03_b01｜M-OPT-005 + M-OPT-007**：固定频段组合后化为一维周期放置 DP（给出切片精确最优）+ 跨频段模拟退火/列枚举联合。启用条件：模板池过大或 UN4 取「带宽/窗长可自选」。

### q04 允许 C 类调间隔的消解
- **主 q04_m01｜M-OPT-002**：复用 q01 判定器与 q02 模型骨架，C 类动作集追加 `δ^T∈{−10..10}\{0}`（保持 `T_i+δ^T ≥ 1`、L 与 n 不变），A/B 动作集不变；因间隔改变会使第 2..n 个窗口整体重排（不再等间距），**必须重新展开 O_i' 再判重叠**，周期剪枝失效。目标与分层同 q02（`Σ|δ^T|` 计入调整幅度）。
  风险：规模上升（90 个 C 类 × 21 个间隔动作）、与 q02 对比必须同口径同校验器、避免同时选两类动作违反 R6。
- **备 q04_b01｜M-OPT-007**：两阶段——先取 q02 可行解，再对 C 类做**单参数间隔交换**的大邻域搜索（每次接受前复算零冲突），天然形成「q02 解 → q04 改进解」的可解释收益链。
