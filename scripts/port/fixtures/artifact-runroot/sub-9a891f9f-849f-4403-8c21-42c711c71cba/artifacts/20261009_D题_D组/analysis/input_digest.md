D 题  时频冲突检测与消解 
随着用频装备数量剧增，电磁兼容矛盾日益突出。在制定用频计划时，为避免用频装备
之间相互干扰和制约，需要对其中潜在的时频冲突进行检测和消解。 
现考虑某特定区域内，大量用频装备在一段时间内对某一有限带宽的频率资源都有使用
需求的情形。为简化问题，对时频资源进行离散化处理：在时域上，用固定的时间长度 Δ𝑡 作
为时间资源的基本单位，表示用频时间不可拆分的最小值，规定用频计划所占用的时间长度
必须是 Δ𝑡 的整数倍；在频域上，以固定的频带宽度 Δ𝑓 将系统可提供的有限带宽频率资
源离散化为100 个宽度相同的频段，每一个用频计划可以占用连续的多个频段，并且占用的
频段数量保持不变。 
所有用频装备均提报了用频计划，需从提报的用频计划中检测潜在的时频冲突。每个用
频计划包含四个参数：频段区间、首次使用的时间区间、相邻两次使用该频段的间隔时长以
及使用次数。当两个用频计划的时间区间和频段区间都存在交叠时，则判定它们之间存在时
频冲突。时频冲突消解就是通过调整某些用频计划的参数（比如平移频段区间或者时间区间
等），甚至撤销某些用频计划，使得消解后的用频计划不存在时频冲突。 
一个用频计划只能调整其中一个参数或撤销。对于检测到的时频冲突，除非特别说明，
一般不调整使用次数和使用间隔时长；应尽可能减少撤销用频计划；尽量减少被调整的用频
计划数量；在用频计划中，A 类用频装备优先级最高，B 类其次，C 类优先级最低，高优先
级用频装备的用频计划应尽量保持；尽量减少调整的幅度，规定频段、时间调整的最大平移
幅度分别为 10Δ𝑓、5Δ𝑡。 
附件1 给出了3 类共150 个用频装备提报的用频计划，建立数学模型解决以下问题。
