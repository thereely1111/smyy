## 0. 一句话结论

本题是**离散时频资源格点上的"冲突判定 + 组合消解 + 剩余资源装载"问题**：150 个周期性的频段-时间占用集合，两两求交即得冲突（q01）；在"每计划至多改一个参数、平移幅度受限、按类别优先级尽量少动少撤"的多层目标下消解冲突（q02）；在 q02 结果的空闲格点上最大化新增 C 类计划数（q03）；再放开 C 类"间隔时长"（±10Δt）重新消解（q04）。四问共用同一套**时频占用集合表示**，这是全流程的地基。

**阻断性未决项 6 条**（见 §12），其中"间隔时长口径""冲突是否跨全部使用轮次判定""时间视野 H""类别定义"4 条会直接改变 q01 的冲突对数量，必须在闸门 1 拍板后才能进入代码阶段。

## 3. 附件 1 数据画像（实测，来自 `data_profile.json`）

**结构**：表头 5 列 `用频装备编号 / 频段区间 / 时间区间 / 间隔时长 / 使用次数`；数据 150 行；编号 `A001…A020, B001…B040, C001…C090`；**无重复编号、无空单元格、区间字符串 100% 可解析**。

**按编号前缀统计的类别分层（关键发现：同一类参数模板完全一致）**

| 类别 | 数量 | 频段宽度 `L`（段） | 首次时长 `d`（Δt） | 间隔 `g`（Δt） | 使用次数 `n` | 频段索引范围 | 首次时间区间端点范围 | 最大占用末（推得） |
|---|---|---|---|---|---|---|---|---|
| A | 20 | 10（全部） | 5（全部） | 60（全部） | 3（全部） | 2 → 92 | 0 → 490 | 620 |
| B | 40 | 15（全部） | 3（全部） | 40（全部） | 4（全部） | 0 → 100 | 15 → 498 | 627 |
| C | 90 | 3（全部） | 2（全部） | 8（全部） | 12（全部） | 0 → 99 | 2 → 533 | 643 |

- 实测全局频段索引：`min = 0`，`max = 100`（右开边界，故实际占用 `[0,100)` 共 100 段，与 F04 的"100 个频段"自洽；且存在频段索引起点为 0 的记录 → **强烈提示频段编号为 0 基**（见 H-C1）。
- 实测首次时间区间端点：`min = 0`，`max = 533`；按 F19 口径推得**任何占用的最晚时刻 = 643Δt**（C 类），A 类 620、B 类 627。
- 计划占用"时频格点当量"合计 `Σ L·d·n = 16,680` 格（重叠部分重复计数）：A 每计划 150 格、B 180 格、C 72 格。
- 参照资源域 `100 频段 × 643 Δt 槽 = 64,300 格` → **占用率上界 ≈ 25.9%**（未去重，去重后更低）。含义：资源整体不拥挤，冲突主要来自随机布置下的局部叠压；这同时暗示 q03 的可新增量可能很大（数量级判断，**具体值待执行**）。
- 一致性检查（实测）：无任何记录的 `L ≤ 0` 或 `d ≤ 0`；无任何 `band_end > 100` 或负索引；无 `g < 0`。

**与 `facts.json` 的交叉核对**：probe 的 `间隔时长` 三值 `{8:90, 40:40, 60:20}`、`使用次数` `{3:20, 4:40, 12:90}`、`n=150` 与上表完全一致 → 两套独立解析互证。

## 8. 机理识别（为什么是这类模型，而不是套高级方法）

- **机理核心 = 离散格点上的集合交叠 + 资源独占**。F04 把频率离散为 100 段、F03 把时间离散为 Δt 槽，任一计划展开成有限个 `(band, slot)` 格点（`SY13`）；F06 把"冲突"定义为两集合交叠；电磁兼容的物理背景（同频同时不可共用）对应**资源互斥约束**，即同一格点最多被一个保留计划占用。这直接指向：**判定 = 集合求交；消解 = 带互斥约束的离散再布置；q03 = 空闲格点上的最大装载**。
- **无连续动力学、无守恒/扩散、无统计样本、无观测噪声** → 微分方程、回归、时序、仿真类卡片均不匹配；**不应**为了"显得高级"引入神经网络/Monte Carlo（方法库 §14）。
- **结构事实支撑的规模判断（实测/计数，非猜测）**：计划对 `C(150,2)=11,175`；每对最多 `n_i×n_j ≤ 12×12=144` 次窗口对，且每次窗口对的时间判据可写成 `|τ_i-τ_j + x_i(d_i+g_i) - y_j(d_j+g_j)|` 型丢番图比较（H02 口径下）；频段判据是一维区间重叠，`O(1)`。因此 q01 属于**可精确完全枚举**规模（无近似必要）。
- **决策结构**：F08 的"只能调整其中一个参数或撤销"是典型的**互斥选择（SOP，one-of-many）**语义；F12 把位移限制为有限整数集；F09–F12 给出**分层目标**。这正是 `M-OPT-002` 卡片 `problem_signature`（"是否、只能、至少一个、若则、不能同时"）所描述的结构，也符合 §13"资源分配 → LP/MILP 主 + 贪心基线"。
- **不确定性来源不是随机而是口径**：本题无概率数据，风险全部来自 §12 的语义未决项 → 用**情景/口径枚举（M-UNC-002 思想）**而非随机模拟处理。

### q02 冲突消解（仅平移频段/时间，或撤销）

- **首选 m03｜分层（词典序 / ε-约束）0-1 再布置 MILP** — `method_id: M-OPT-002`（多目标分层结构引用 `M-OPT-004`）

### q03 不增加资源下最多新增多少 C 类装备

### q04 允许部分 C 类调整间隔时长的消解

- **首选 m07｜在 m03 上扩展"间隔"决策档的分层 MILP（同一内核，仅候选集扩容）** — `method_id: M-OPT-002`
  - 变化点：C 类计划的候选集追加 `D_i^γ = {γ ∈ [-10,10] 整数 : g_i+γ 合法}`，且该档**只属 C 类**（F17"允许部分 C 类"）；每个计划仍只能选一个操作（F08 仍成立，即"调间隔"与"调频段/调时间/撤销"互斥）。
  - 合法性建议（**待确认 C12**）：`g' = g + γ > 0`（间隔须为正）或允许 `g'=0`（此时窗口首尾相接 `[τ,τ+2),[τ+2,τ+4)…` 因半开区间仍不重叠）；`g'` 须为 Δt 整数倍；`g'<g` 会**压缩**时间跨度，`g'>g` 会**拉长**（可能越出 `H`，需 H08 判定）。
  - 关键机理：C 类周期由 `P = d+g = 10Δt` 变为 `P' = 2 + g' ∈ [2,20]`（或 `[1,20]`）→ **占用相位可变**，这是比 5Δt 平移强得多的消解自由度（尤其对 `g=8, d=2` 的密集重复），预期可显著减少撤销/调整数（**假设，待执行验证**）。
  - 所需数据：同 m03 + F17 + C12 拍板。
  - 可检验性：仅 C 类出现 D 列（间隔）非空，A/B 类间隔列必须为空；`|γ|≤10` 逐条核对；复检 0 冲突；表 1 与 q02 逐类别对照（撤销/调整数应不增加——因决策域是 q02 的超集，可作单调性检验）。
  - 风险：`g` 可变使"周期占用"失去固定结构，候选方案数与冲突判定成本上升；若 `H` 未定，`g'>g` 档的合法性无法判定；题面"部分 C 类"未给数量上限，需在论文中明确采用"不限量、由优化决定"的口径。
- **备选 m08｜破坏-修复两阶段启发式（ALNS 风格：先按 q02 消解，再用间隔调整修复剩余冲突）** — `method_id: M-OPT-007`
  - 核心思想：以 q02 的 m04 解为起点，把仍有冲突的计划放入"间隔调整"邻域（`γ` 单步 ±1 或整档替换），配合撤销回退算子；目标仍按 H09 分层评估。
  - 优点：直接复用 q02 结果、实现路径短、规模不敏感；缺点：无最优性证书，易停在局部最优 → 必须多种子重复 + 与 m07 小规模精确解对照。
  - 适用条件：m07 超时或不可行时的降级路线（卡片 `fallbacks`：构造启发式/局部搜索/MILP 小规模基准）。
- **`selection_summary`**：`primary_method_id M-OPT-002`、`backup_method_ids [M-OPT-007]`；`problem_fit 0.9`、`data_fit 0.6`（`γ` 合法域与"部分"含义未定）、`interpretability 0.85`、`computational_fit 0.45`（C 类 90 个 × 21 档，规模明显大于 q02）；`key_assumptions` = H06/H08/H09/H11 + C12；`known_risks` = 规模膨胀、单调性被口径破坏；`reason_for_selection` = "与 q02 同构，最大化复用已验证的 MILP 骨架，只扩容候选集，便于两问对照解释"；`disqualifying_conditions` = 若 90×21 候选导致模型不可解 → m08；`required_user_confirmations` = C9/C10/C12。

**方法库自检**：引用 ID `M-OPT-002 / M-OPT-004 / M-OPT-007`（均存在于 `方法库/索引.md`）；`null（库外）` 三处均已说明理由（区间相交基元、冲突图/最大独立集、周期打包解析）。卡片 `hard_constraints` 核对：M-OPT-002"Big-M 无界需谨慎"→ 已要求位移域有界（±10/±5）并用逐格点互斥约束替代大 M；M-OPT-007"不得把一次随机运行当全局最优"→ 已写入多种子重复与上下界对照；M-OPT-004"权重无依据且结论高度依赖权重时不得只报单点"→ 已选 ε-约束/词典序并承诺报告分层代表解而非单点。未违反 `§14`（未虚构分布/权重/样本量，未因"最优"二字直接上遗传算法）。
