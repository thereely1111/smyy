问题二 · 第二检测点选在哪里

先划出「一定听得见」的候选区 第二测点不能随便放：它必须落在有效接收半径内，否则测不到，一切无从谈起。

第一个检测点已经拿到一条示向度。为了交会，机器狗需要移动到第二个位置再测一次。这个位置有两个硬约束：其一，它到源的距离要在有效接收半径（1000–1500 m）内；其二，考虑到我们只知道源在定位区域 A 中，必须保证对 A 里任意位置都满足半径要求——于是候选区是一个以第一测点为中心的环形区域的再加工。

第一测点、定位区域与候选区
保守半径 ρ 1000 m
定位区域半径 rA 34 m
第一测点 定位区域 A 乐观圆 半径 ρ 强保证圆 半径 ρ−rA

候选点的强保证条件

对定位区域 A 中的每一点 p，第二测点 s 都要满足 dist(s, p) ≤ ρ，其中 ρ 取有效接收半径的下限 1000 m（最保守）。
# 强保证候选区 Sfeasible = { s : maxp∈A dist(s, p) ≤ 1000 } # 等价：以 A 的「远端」为界 maxp∈A dist(s,p) = dist(s, cA) + rad(A) # c_A 为 A 的形心
若只按「源可能在这些位置」估计，用一个半径 1000 m 的圆就够；但要用「强保证」口径（对 A 内所有点成立），可行域半径要再减去 A 的尺寸 rA，即 ρ − rA。图中随两个滑块实时变化：拖动 ρ 改变乐观圆，拖动 rA 改变两者之差。

赛题对应与结论小结

赛题对应：本幕对应问题二的第一步——在已知第一检测点、一条示向度、以及源位于定位区域 A 内的前提下，圈出第二检测点的可行范围。

本幕结论：第二测点必须落在有效接收半径内，否则根本测不到。按「强保证」口径（对 A 内每一点都要求 dist(s, p) ≤ 1000 m），可行域是以第一测点为中心、半径为 ρ − rA 的圆（ρ 取保守下限 1000 m，rA 为定位区域尺寸）；若改用「源只在这些位置」的乐观口径，半径就是 ρ。拖动两个滑块可以看到，两者之差随 rA 增大而扩大。

问题二 · 把「最优」写成可优化的式子

既要测得准，又要跑得少 最优第二测点 = 让后验不确定区域最小，同时别为了小的收益跑太远。

「最优」不能只说「交会角接近 90°」。真正要权衡的是两件事：一是测完之后源还剩多大的不确定区域（最坏后验半径 R），二是机器狗从第一测点移动过去要花的时间（移动距离）。把它们写成同一个目标函数。

目标函数

# 在候选区上做单目标权衡搜索 J(S) = maxR(A | S) + λ · dist(p1, S) # 各项含义 maxR(A | S) : 以 S 为第二测点后的最坏后验包围半径 dist(p₁, S) : 第一测点到第二测点的移动距离 (m) λ : 权衡系数（米 / 米），越大越重视省距离
λ 取值侧重点典型第二测点
λ → 0纯精度优先与第一测点成 90° 交会的最远可行点
λ = 0.3平衡交会角略偏，位置更近
λ ≥ 1移动优先贴着候选区最近边界
题面更看重的是一次性把源定准（后续还要移动去清除），因此正式解取较小的 λ；λ 的扫描用于说明结论的稳健性。
J(S) 的两项随交会角的变化（示意）
权衡系数 λ 0.30
交会角游标 90°
maxR 项 λ·距离 项 J(S) 合计 交会角游标

赛题对应与结论小结

赛题对应：本幕对应问题二对「最优第二检测点」的量化定义——把「测得准」与「跑得少」写成同一个可优化的目标。

本幕结论：用 J(S) = maxR(A | S) + λ·dist(p₁, S) 权衡两项：前者是以 S 为第二测点后的最坏后验包围半径，后者是移动距离。当 λ → 0 时纯精度优先（取与第一测点约 90° 交会的最远可行点）；λ 增大，解随之向第一测点靠近。因题目更看重一次把源定准，正式解取较小的 λ。这一步把「最优」从定性描述变成了可搜索的标量目标。

问题二 · 在候选区上搜索

把候选区离散成网格，逐格算 J(S) 连续区域上无解析解，用网格搜索既直观又可复现。

把强保证候选区按固定步长（例如 50 m）离散成网格，对每个网格点计算 J(S)，取最小者作为最优第二测点。下面的热力图用颜色表示 J(S) 的高低。

要点一

最优解通常落在与第一测点大致成 90° 交会、且尽量靠近第一测点的可行边界内侧，而非最远处。

要点二

若强行选 90° 最远点，maxR 项最小但移动距离大，J 反而可能升高。

要点三

λ 由小到大扫描时，最优测点沿候选区向内移动，结论对这一改动稳健。

赛题对应与结论小结

赛题对应：本幕对应问题二的求解方法——在强保证候选区上求 J(S) 的最小值，从而给出最优第二测点。

本幕结论：连续区域上无解析解，因此把候选区按 50 m 步长离散成网格、逐格计算 J(S) 取最小者。最优解通常落在与第一测点大致呈 90° 交会、且尽量靠近第一测点的一侧，而非最远点；若强行取 90° 最远点，maxR 项虽最小，却因移动距离过大使 J 回升。λ 从小到大的扫描显示最优测点沿候选区向内移动，说明该结论对权重取值稳健。
