中药材热风烘干过程的热湿耦合建模

径向一维热湿耦合有限体积统一骨架 · 四问逐级加深

一、题目重述与信息结构

某中药材形状大致呈圆柱形：长 25 cm、半径 2 cm。烘干开始时药材温度 28°C、干基含水率 2.55 kg/kg。热风烘干分预热平衡与恒温干燥两阶段，烘房温度与水分浓度随时间变化（附件1）。四个问题是同一套热湿耦合 PDE 的逐级加深：

  • 问题一：预热平衡阶段（0-1800 s），附录2 常物性 → 建立温度与水分浓度模型，填表1/表2；
  • 问题二：整个烘干过程（2-3 天），附录3 变物性 → 填表3/表4；
  • 问题三：在问题二基础上求各处水分 <0.15 kg/kg 所需烘干时长（h）→ 填表5；
  • 问题四：考虑水分流失导致的半径收缩（附件2：2→1.198 cm），附录4 物性 → 动边界模型，填表6。

关键简化：长径比 25/2 = 12.5 ≫ 1，轴向梯度可忽略 → 径向一维柱坐标模型即可（这是本题第一个得分点）。

这一步的关键是画出“烘房环境 → 表面对流 → 内部扩散”的能量/质量双通道结构图，标清四问共用的控制方程与各自不同的物性来源（附录2/3/4）。评委一眼就能看出你是否抓住了“一套 PDE、四套参数”的主线。

二、物理机理与控制方程

药材内部同时发生导热与水分扩散，两者在表面通过对流与烘房环境耦合：

质量：∂C/∂t = (1/r)·∂/∂r( r·D(C,T)·∂C/∂r ) 能量：ρ(C)·cp(C)·∂T/∂t = (1/r)·∂/∂r( r·k(C)·∂T/∂r )

边界条件（Robin 第三类）：

  • 表面 r=R： -k·∂T/∂r = h·(T|R − Ta(t))，  -D·∂C/∂r = km·(C|R − Ca(t))；
  • 中心 r=0：轴对称，∂T/∂r = ∂C/∂r = 0。

其中 Ta(t)、Ca(t) 由附件1 线性插值给出（28→50.25°C、0.0196→0.0503 kg/kg，覆盖 0-14400 s 预热段；之后按恒温 50.25°C / 0.0499 处理）。对流换热系数 h = 25 W/(m²·K)，对流传质系数 km = 8×10⁻⁷ m/s。

本题最易踩坑：① 把“水分浓度”当体积浓度处理——题给的是干基含水率 kg/kg，扩散方程形式不变但物性公式都按它定义；② 忘记中心胞元体积是 r=0 处的四分之一圆（dr²/8），直接套内部胞元格式会导致中心通量凭空翻倍。

三、数值方法：有限体积法（FV）

沿半径取 21 个节点（r = 0, 0.1, …, 2.0 cm，dr = 0.1 cm），对每个环形胞元做质量/能量守恒：

  • 内部胞元（2πr_m·dr）：净通量 = 右面流入 − 左面流出，界面系数取相邻节点算术平均；
  • 中心胞元（体积 dr²/8）：只有右面 flux[0] 流入 → dC[0] = flux[0]/(dr²/8)；
  • 表面半胞元：内部扩散补给（−flux[-1]）减去表面对流传质（km·R·(C|R−Ca)）→ 这是符号最容易写反的地方；
  • 时间推进：显式 Euler，dt = 0.5 s（由 D·dt/dr² < 1/4 限制，全程稳定）。
dC[-1] = ( −flux[-1] − km·R·(C[-1]−Ca) ) / ( R·dr )

问题四引入 Landau（ξ = r/R(t)）坐标把变域问题映射到固定域 [0,1]：扩散项除以 R(t)²，另产生一个指向中心的对流项 (ξ·Ṙ/R)·∂C/∂ξ——收缩“泵送效应”由此显式进入方程。

自检三件套：① 干燥中后期 Cmax 单调下降且无振荡；② 预热段内部节点水分几乎不动（D 小 4 个量级）；③ 时间步减半结果不变（收敛性）。三条都过，数值解才算站得住。

四、从问题一到问题四的模型升级路径

问题一：预热平衡（附录2 常物性）

ρ=820 kg/m³、cp=2600 J/(kg·K)、k=0.36 W/(m·K) 均为常数，D = 7×10⁻⁹·e^(−0.89C)。结果特征：热快湿慢——1800 s 全场温度 28→33.4~36.6°C，而水分只在表面约 0.1 cm 薄层内下降（表面 2.55→1.312，内部仍 2.55）。

问题二：全过程（附录3 变物性）

ρ=650+128C、cp=1450+2736·C/(C+1)、k=0.21+0.38·C/(C+1)、D=2.4×10⁻³·e^(−0.45C)·e^(−3850/T)。D 对温度指数敏感：升温到 50°C 后 D 增大约一个量级，干燥明显加速；3 h 时中心水分 2.19、表面 1.01 kg/kg。

问题三：烘干时长判定

沿用问题二模型，监测 Cmax(t) = max_r C(r,t)，首次降到 0.15 kg/kg 的时刻即烘干时长：16.87 h。注意判据是“各处”——中心永远是最后达标点。

问题四：动边界收缩（附录4 + 附件2）

ρ=760+90C、cp=1850+2150·C/(C+1)、k=0.12+0.20·C/(C+1)、D=4.2×10⁻⁴·e^(−0.30C)·e^(−3850/T)；半径按附件2 从 2 cm 收缩到 1.198 cm。虽然扩散路径缩短，但附录4 的 D 比附录3 低约 5 倍，烘干时长反而延长至 21.49 h（结束时 R = 1.207 cm）——物性差异主导、几何收缩次要。

五、结果与灵敏度分析

四问的参考结果（有限体积法，21 节点，dt=0.5 s）：

问题阶段关键结果
问题一1800 s 预热平衡中心 33.4188°C / 表面 36.5905°C；表面水分 1.312，内部 2.55
问题二3 h 全过程中心 49.81°C（趋近烘房）；中心水分 2.19 / 表面 1.01
问题三Cmax<0.15烘干时长 16.87 h
问题四动边界收缩烘干时长 21.49 h，R 由 2 → 1.207 cm

值得写进论文的几个灵敏度结论：

  • 扩散系数前置常数 ×2（其余不变），问题三烘干时长约缩短 35%——干燥后期由内部扩散控制，D 是第一敏感参数；
  • 对流换热系数 h ±20%，只影响预热段升温快慢（±0.4°C 量级），对 16.87 h 的烘干时长几乎无影响——因为后期瓶颈在内部扩散而非表面传热；
  • 问题四若忽略收缩（固定 R=2 cm + 附录4 物性），烘干时长约 27 h，比动边界模型长 26%——收缩的“路径缩短”效应贡献显著但不足以抵消物性放慢。
最后一条是很好的讨论点：动边界同时带来两种相反效应——路径变短（加快）与对流泵送指向中心（减慢），净效应是加快约 5.5 h。很多论文只算几何效应不写对流项，会被追问。

六、模型评价与论文写作要点

优点

  • 四问共用一套径向一维热湿耦合 FV 骨架，只换物性函数与网格映射（固定域 / Landau 域），论文结构紧凑、代码可复用；
  • 有限体积天然守恒，表面通量、中心胞元、动边界对流项都有明确的物理意义，答辩好讲；
  • 结果给出“热快湿慢”“物性主导几何”等机理结论，不止于填表。

局限与改进

  • 忽略轴向梯度与端面效应（长径比 12.5 下端面贡献约 4%，可在论文中用修正因子说明）；
  • 未显式考虑蒸发潜热在内部的相变耗热（简化为表面效应），更精细可引入蒸发-冷凝源项；
  • 附件2 半径数据只有 145 个点，长时段用线性插值，收缩速率 Ṙ 的估计有锯齿，可用样条平滑改进。
论文结构建议：摘要（务必写关键数字 16.87 h / 21.49 h）→ 问题重述 → 假设与符号说明（记得补“单位”列）→ 机理分析与控制方程 → 问题一～四模型与求解 → 灵敏度与稳健性 → 结论 → 参考文献 → 附录（代码 + result1.xlsx ～ result4.xlsx 文件说明）。
