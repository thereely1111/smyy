问题四 · 半径收缩的动边界

半径会缩小的热风烘干：把动边界折成固定域 药材圆柱随水分流失逐渐变细，半径由 2cm 收缩到约 1.207cm，烘干所需时长 21.49h。

前三问把药材当作半径不变的圆柱处理；问题四要求考虑干燥过程中半径随时间真实收缩（动边界）。圆柱体长 L=25cm、初始半径 R₀=2cm、初始温度 28°C、初始干基含水率 C₀=2.55 kg/kg，物性改用附录4的变物性参数。半径收缩使物理求解域随 R(t) 不断缩小，必须在动边界上重新建立热湿耦合模型。

与前三个问题的差别 固定 vs 收缩

问题一~三半径固定 R≡2cm，求解域始终为 [0, 2cm]，边界静止。

问题四半径随含水率下降而收缩，求解域 [0, R(t)] 逐时缩小，边界在移动。

边界移动意味着网格与通量边界都要随之更新，不能沿用固定半径的离散方式。

半径为什么会收缩 附件2 收缩数据

水分从细胞中流失后，细胞壁塌陷、孔隙收缩，宏观上表现为药材整体体积变小。收缩数据取自附件2：半径 R(t) 由 2cm 单调收缩到约 1.207cm。

收缩前期较快（0~6h），后期趋缓并逐渐贴近终值。

R(t) 是问题四的已知输入，用于动边界位置与归一化坐标。

为什么改用附录4 物性 变物性参数

附录4 中扩散系数 D、导热系数 λ、体积热容 ρcₚ 均随含水率 C 与温度 T 变化，更贴近真实干燥过程。

其中 D 在同等 C、T 下比附录3 低约一个量级，这是问题四时长变长的关键原因。

物性随 C 变化 → 方程非线性 → 需迭代求解。
问题四的难点不在公式本身，而在于「边界会动」——半径每时每刻都在缩小，网格必须跟着缩，表面蒸发与换热的通量条件也要按当前半径折算。把这些处理干净，才能如实刻画收缩药材的热湿耦合过程。
问题四 · 动边界建模

Landau 坐标：把收缩的动边界折成固定域 令 ξ = r / R(t)，物理域 [0, R(t)] 随时间收缩，归一化后变为固定域 [0, 1]。

直接在有界缩小的物理域上离散，需要每步重建网格、处理移动边界，代价高且易出错。Landau 坐标把物理半径 r 除以当前半径 R(t)，映射为无量纲坐标 ξ=r/R(t)∈[0,1]。这样一来，动边界问题被转换成固定域上的问题，代价是方程中多出一个由收缩引起的对流（收缩）项。

归一化方程与边界条件 Landau 坐标下的热湿耦合

// Landau 坐标变换：把动边界 r ≤ R(t) 映射到固定域 ξ = r / R(t) , ξ ∈ [0, 1] , r = ξ · R(t) // 归一化扩散方程（R 随 t 收缩，额外产生对流项） ∂C/∂t = (D / R²) · (1/ξ) · ∂/∂ξ ( ξ · ∂C/∂ξ ) − (ξ · Ṙ / R) · ∂C/∂ξ 扩散项（半径归一化） 收缩对流项 // 边界条件与初值 ξ = 0 : ∂C/∂ξ = 0 轴对称，中心无净通量 ξ = 1 : −(D / R) · ∂C/∂ξ = k_m · (C_s − C_eq) 表面蒸发按 k_m / R 折算 t = 0 : C = C₀ = 2.55 kg/kg 初始干基含水率 // 温度边界同理，热边界按 h / R 折算 −(λ / R) · ∂T/∂ξ = h · (T_∞ − T_s) // 附录4 变物性（随 C 与 T 变化） D = 4.2e-4 · exp(−0.30 · C) · exp(−3850 / T_K) [m²/s] λ = 0.12 + 0.20 · C / (C + 1) [W/(m·K)] ρcₚ = (760 + 90 · C) · (1850 + 2150 · C / (C + 1))

关键点：扩散项中的 D 被除以 R²，表面蒸发项被除以 R，换热的 h 同样被 R 折算——半径收缩既缩短了扩散路径，又让边界通量随半径变化，两种效应叠加在归一化方程中。

求解流程 从收缩域到固定域，再换算回去

物理域随 R(t) 收缩→ 归一化 ξ = r / R(t)→ 固定域 [0,1] 离散求解→ r = ξ · R(t) 换算回物理坐标

归一化后，网格节点固定在 ξ = k/20（k = 0…20，共 21 个节点），物理位置随 R(t) 一起收缩；时间步长取 dt = 0.5s。

物理域收缩 vs 归一化固定域 · 节点映射示意
物理域（随 R 收缩） 归一化域（固定） 坐标映射

左栏是收缩的物理域 [0, R(t)]，节点物理位置随半径一起向左收缩；右栏是归一化域 [0, 1]，节点位置始终固定在 ξ = k/20。两栏的节点编号相同、数量相同，只是横坐标被 R(t) 缩放。这对箭头表示 ξ = r/R(t) 的正向映射与 r = ξ·R(t) 的换算。

Landau 变换原理 把动压成静

令 ξ=r/R(t)，则物理域 0≤r≤R(t) 对应 0≤ξ≤1，与时间无关。

求导时需计入 R(t) 的时间依赖，由此引入 ∂ξ/∂t = −ξ·Ṙ/R，从而在方程中留下一个对流项。

变换不改变物理本质，只是把「移动的网格」换成「固定的网格」。

收缩对流项的来历 (ξ · Ṙ / R)

半径收缩相当于边界向中心挤压，物质被「推」向内侧，宏观上表现为一个附加的对流输运。

收缩越快（Ṙ 越大）或当前半径越小（R 越小），对流项越显著。

Ṙ<0（半径减小）时该项使含水率向外侧重分布，加速外层干燥。

数值实现 有限体积法

网格ξ 方向 21 个节点，等距布置

时间dt = 0.5s，共用一套离散格式

迭代物性随 C 变化，每个时间步内做内迭代

边界 ξ=1 的通量与 ξ=0 的对称条件一起，构成两组封闭的三对角方程组。

表中「中心 0cm / 0.5cm / 1cm」为三个固定物理位置的含水率；因半径随干燥收缩，1cm 处始终仍在药材内部（R(6h)≈1.376cm > 1cm）。最后一列为当前半径处的表面含水率，其横坐标即为该时刻的 R(t)，故「表面」列的位置随时间向内移动。21h 时中心降到 0.15、表面 0.081，径向梯度依然明显。

半径收缩的两个阶段 先快后慢

0~6h 含水率高、收缩最快，半径由 2.00cm 迅速降到约 1.376cm；6h 之后含水率下降趋缓，收缩速率随之减慢。

18h 之后半径基本贴近终值 1.207cm，残余收缩量很小。

半径的「先快后慢」与失水的推进节奏互补：收缩主要发生在干燥前期，后期半径已接近终值，含水率的下降反而主导了剩余的烘干时间。

中心与表面的差距 径向梯度

6h 时中心 2.3091、表面 0.6204，内外差距大；12h 时中心 0.8918、表面 0.2757；18h 时中心 0.2732、表面 0.1176。

到 21h，中心 0.15、0.5cm 处 0.1356、1cm 处 0.0991、表面 0.081——由内到外单调下降。

中心含水率始终是整体最大值，故 Cmax 曲线与 Cc 曲线重合。
问题四 · 径向剖面

干区由外向内推进，半径同步收缩 把 6h / 12h / 18h / 21h 的径向含水率剖面叠在同一张图上，可看清干燥前沿的推进与半径的缩小。

剖面曲线以物理半径 r 为横轴、含水率 C 为纵轴。表层先失水、含水率迅速下降，形成一层低含水率的「干壳」；干壳随时间向内加厚，干燥前沿（陡降段）由外向内推进。与此同时，每条剖面的右端点就是该时刻的表面位置 r=R(t)，随着半径收缩而逐步向左移动。

四条剖面自上而下依次对应 6h→21h：表层含水率随时间是快速下降的，4h 之后外侧已经远低于中心。虚线竖线标出 6h 与 21h 的表面位置 R，可见表面位置从约 1.376cm 移动到 1.207cm。红色虚线为 0.15 的目标阈值，21h 剖面除中心外都已降到阈值以下。

干壳的推进 由外向内

热风从表面带走水分，表层先干；随干燥推进，干壳逐渐加厚，含水率的陡降段（干燥前沿）持续向内移动。

6h 时剖面还比较平缓（中心到表面 2.31→0.62），21h 时外层已整体压低（1cm 处仅 0.0991、表面 0.081）。

这正是「降速干燥」的体现：干壳越厚，内部水分向外迁移的阻力越大。

收缩与剖面的耦合 半径缩短路径

半径收缩让传质路径变短，理论上会加快内部水分迁移；但归一化方程中的对流项会把含水率向外侧重分布，同时附录4 的低扩散系数放大了内部阻力。

两者叠加的结果是：剖面在后期仍保持明显的径向梯度，中心含水率最后才降到 0.15。

若忽略半径收缩，同样的物性下剖面收尾会更快——这正是问题四比问题三多出 4.62h 的来源之一。
问题四 · 结论

半径收缩下所需烘干时长 21.49 h 半径由 2cm 收缩到约 1.207cm；收缩缩短了路径，但附录4 的低扩散系数主导，总时长反而更长。

采用 Landau 坐标把动边界化为固定域求解，配合附录4 的变物性参数与表面按 R 折算的蒸发/换热边界，问题四得到所需烘干时长 21.49 h。此时半径收缩到约 1.207cm，整体最大含水率为 0.15 kg/kg，中心 0.15、0.5cm 处 0.1356、1cm 处 0.0991、表面 0.081。

为什么收缩反而更慢 路径 vs 扩散系数

缩短路径半径由 2cm 收缩到约 1.207cm，内部水分到表面的路程变短，本应加快干燥。

主导因素附录4 的扩散系数 D 在相同 C、T 下比附录3 低约一个量级，传质阻力显著增大。

两种效应相抵后由低扩散系数主导，故 21.49h > 16.87h。

结果可信度 数据一致性
