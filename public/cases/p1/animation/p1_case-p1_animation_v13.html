中药材热风烘干：圆柱体内的热湿耦合传热传质 长 25 cm、半径 2 cm 的圆柱药材，初始 28 °C、干基含水率 2.55 kg/kg。热风把表面加热到 50.165 °C，水分沿浓度梯度由内向外迁移，目标是把干基含水率降到 0.15 kg/kg 以下。

本题把一根圆柱药材的烘干过程交给一套「温度场 + 含水率场」的双场耦合模型：内部靠导热 λ 与 Fick 扩散 D，表面叠加对流换热 h 与水分蒸发/吸收 km。四个问题沿「预热平衡 → 全过程 → 达标时长 → 动边界收缩」逐层加约束。

读题结局指标只有一个：把干基含水率降到 0.15 kg/kg 以下。四个问题分别是这个目标在「短时预热」「全程变物性」「全域同时达标」「半径随含水率收缩」四种约束下的展开。

物理机理 · 热湿耦合

表面先热、内部后热；水分受浓度梯度由内向外迁移 温度场与含水率场互相耦合：温度升高加快水分扩散与蒸发，水分蒸发又带走潜热、反作用于温度。

径向剖面示意 · 温度 T(r) 与含水率 C(r)
温度剖面 含水率剖面

上panel：温度由中心向表面升高（外高内低），1800 s 时中心 33.42 °C、表面 36.59 °C；下panel：含水率由中心向表面降低（内高外低），中心仍保持 2.55，表面降到 1.312 kg/kg。

控制方程 传热 / 传质

// 传热：内部导热 λ + 表面对流 h ∂T/∂t = (λ/(ρ·cp))·(1/r)·∂/∂r( r·∂T/∂r ) 表面： q = h·(T_air − T_s) h = 25 W/(m²·K) T_air: 0–300 s 由 28 °C 升到 50.165 °C 后稳定 // 传质：内部 Fick 扩散 D + 表面蒸发/吸收 km ∂C/∂t = (1/r)·∂/∂r( D·r·∂C/∂r ) 表面： j = km·(C_s − C_a) km = 8×10⁻⁷ m/s C_a（热风含水率）：最终 0.04986 kg/kg

耦合温度决定扩散系数 D 与表面蒸发速率；蒸发带走潜热又降低表面温度，两场需联立求解。

热湿耦合链条 表面 → 内部

热风加热表面 → 表面水分蒸发（km） → 内部形成浓度梯度 → 水分由内向外迁移

表面先失水、内部仍高湿，形成从中心指向表面的浓度梯度，驱动水分持续外迁；这正是「中心含水率几乎不变、表面快速下降」的物理原因。

附件1烘房热风环境

热风温度 0–300 s 由约 28 °C 升到 50.165 °C 后稳定。

热风含水率对应值最终 0.04986 kg/kg，作为表面传质的远场浓度 Cₐ。

边界条件表面换热 / 传质

表面对流换热系数 h = 25 W/(m²·K)。

表面传质系数 km = 8×10⁻⁷ m/s，控制蒸发/吸收强度。

物性来源附录 2 / 3

问题一采用附录 2 的常物性（导热 λ、扩散 D 视为常数）。

问题二全过程采用附录 3 的变物性，λ 与 D 随温度/含水率变化。

数值方法 · 有限体积法

径向 21 节点 + 显式欧拉推进：中心胞元用 dr²/8，表面叠加两类通量 把连续的圆柱径向方程离散成 21 个控制体，逐时步显式更新温度与含水率。

空间网格

径向 21 节点、dr = 0.1 cm；轴向按 L = 25 cm 均匀，简化为一维径向问题。

节点越密，表面浓度梯度捕捉越准。

时间推进

显式欧拉 dt = 0.5 s，逐时步同步更新温度与含水率。

dt 受 D 与 dr 约束，取 0.5 s 兼顾稳定与效率。

边界处理

中心用曲面积分校正；表面把内部扩散补给与表面对流蒸发叠加为净通量。

两个边界共同决定整体干燥速率。

为什么这样递进

四问共用同一套传热传质方程与数值方法，差别只在约束：Q1 冻结物性看短时响应；Q2 放开物性看全程；Q3 把「某个点达标」升级为「所有点达标」；Q4 再把固定的外边界改成随含水率收缩的移动边界。

从「一个时刻」到「整个时间」、从「一点」到「全域」、从「定边界」到「动边界」，约束一圈圈收紧。

结论①干燥由表面向内推进

1800 s 内中心含水率始终保持 2.55，只有表面降到 1.312 kg/kg。

说明短时预热阶段失水几乎全部发生在表层。

结论②全过程趋于稳定

变物性全过程中，中心温度约 8 h 升到 50 °C 并趋稳，表面含水率降到约 1.01 kg/kg。

温度先达标，含水率随后缓慢收敛。

结论③达标时长受边界模型影响

定边界需 16.87 h 使各处 < 0.15；动边界半径收缩到约 1.207 cm，整体时长 21.49 h。

两者相差约 4.6 h，边界是否收缩不可忽略。

总览四条结论共用同一套热湿耦合模型：温度场快速趋于热风温度，含水率场则决定烘干时间；问题三给出定边界下的达标下界，问题四说明半径收缩会显著改变进程。四个子问题详见 问题一、问题二、问题三、问题四。
