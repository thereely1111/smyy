问题一研究什么 preheat · 0–1800s

研究圆柱形药材被热风加热初期 0–1800s 的预热平衡阶段：物料由初温 28℃ 缓慢升温，内部建立径向温度梯度。

模型与参数 · 附录 2 常物性

热湿耦合：能量方程 与 水分扩散方程 沿圆柱半径方向建模：温度由径向导热 + 表面对流换热控制，含水率由内部扩散 + 表面蒸发控制。

能量方程 heat

∂(ρ·cp·T)/∂t = (1/r)·∂/∂r( r·λ·∂T/∂r ) 边界 r=R： −λ·∂T/∂r = h·(T − T_air) /* 表面对流换热 h=25 W/(m²·K) */ 中心 r=0：∂T/∂r = 0 （对称）

水分扩散方程 moisture

∂C/∂t = (1/r)·∂/∂r( r·D·∂C/∂r ) 扩散系数： D = 7×10⁻⁹·e^(−0.89·C) m²/s 边界 r=R： −D·∂C/∂r = km·(C − C_air) /* 对流传质 km=8×10⁻⁷ m/s */
径向温度剖面示意：外圈热、内圈冷
内圈 · 中心较冷 外圈 · 表面较热 T(r) 剖面 @1800s

中心 33.42℃ → 表面 36.59℃，径向温差约 3.17℃；热量由表面向内传导，越靠近中心升温越滞后，形成稳定的「外高内低」梯度。

分析结论 3 条

① 温度场外高内低：表面 36.59℃ 高于中心 33.42℃，径向温差约 3.17℃。

② 热量以升温为主：1800s 内中心升 5.42℃、表面升 8.59℃，尚未达到环境温度。

③ 水分流失少：中心保持 2.55，仅表面由 2.55 降至 1.312，迁移集中在近表面层。

阶段定位 为后续干燥建立基础

预热阶段把物料整体“焐热”，为问题二/三的变物性主干燥阶段提供初始温度场与含水率分布。

问题一结论：0–1800s 预热平衡阶段温度场呈稳定的外高内低径向梯度（中心 33.42℃ / 表面 36.59℃），热量主要用于升温；水分迁移局限于近表面层，中心含水率保持 2.55、表面降至 1.312。该阶段为下一阶段干燥建立了温度基础。
