时频冲突检测与消解模型研究

约 24 页 · 图 12 张 · 表 7 张 · 参考文献 12 篇

摘要

针对区域内部大量用频装备在一段有限带宽上的用频计划冲突问题，本文把时频资源离散化为「100 个 Δf 频段 × Δt 时间轴」的二维格网，并将每个用频计划（频段区间、首次使用时间区间、间隔时长、使用次数）展开为若干个时频矩形，从而把冲突检测与消解统一为矩形相交判定与矩形移动问题。问题一以「频段相交且存在一对矩形时间相交」为判据，对附件 1 的 3 类共 150 件装备（A 类 20、B 类 40、C 类 90，合计展开为 1500 个时频矩形）做两两检测，逐对写入 result1.xlsx，并给出冲突对总数、涉及装备数量与类别分布等统计结果。问题二将消解建模为「每件装备至多执行一个动作（频移 ≤10Δf、时移 ≤5Δt 或撤销）」的词典序多目标优化：先最小化撤销数量，再最小化调整数量与调整幅度，并优先保持高优先级装备；本文以「冲突定向让路」贪心算法求解，反复取冲突对并让低优先级一方以最小幅度让路，得到无冲突用频计划并按表 1 格式汇报。问题三在问题二的无冲突计划上放宽平移幅度但不增加时频资源，针对参数完全一致的 C 类装备构造容量模板 (3Δf, 2Δt, 8Δt, 12 次)，给出面积上界 U = ⌊剩余面积 / 单件面积⌋ 作为理论标尺，并以「频段分带 + 相位排布」的贪心算法给出可行解，输出 result3.xlsx。问题四将决策空间扩展为「频移 / 时移 / 间隔调整（仅 C 类，|Δiv| ≤ 10Δt）/ 撤销」，复用问题二的消解引擎并在其中插入间隔试探，输出 result4.xlsx。结果表明，四问可由一套「矩形化—冲突判定—受限让路」的骨架串联，问题三的可行解与容量上界之比刻画了装填效率，问题四相较问题二的撤销量下降且全部来自 C 类，量化了「间隔自由度」的价值。

第三章（节选）

第 k 次使用　Ti,k = [ ti + (k−1)·ivi , ti + (k−1)·ivi + τi )
冲突判据　max(fsi, fsj) < min(fei, fej)　∧　∃ k,l : max(Ti,k 左端, Tj,l 左端) < min(Ti,k 右端, Tj,l 右端)

由于频段区间对所有次使用共用，冲突判定可先行剪枝：频段区间不相交的计划对直接判定为无冲突，只有频段相交时才需要逐对矩形比较时间。为避免端点误判，全部区间均按半开区间处理，比较一律取严格不等号，从而保证 [35,40) 与 [40,45) 这类首尾相接的情形不被计入冲突……

第四章（节选）

设每件装备的动作变量为 ai ∈ {不动, 频移, 时移, 撤销}，问题二的目标按词典序写作：

min lex　( Σ 撤销数 , Σ 调整数 , Σ |调整幅度| )　s.t.　|Δf| ≤ 10Δf, |Δt| ≤ 5Δt, 每件至多一个动作

本文采用冲突定向让路贪心：每次取一个冲突对，令优先级较低的一方以最小可行幅度让路，优先尝试频段平移、其次时间平移，两者均不可行时撤销该计划。由于每个计划至多被调整一次或被撤销，迭代次数有上界，算法必然终止，且终止时冲突数为零……
