一、题目重述与信息结构

大量用频装备在一段时间内对一段有限带宽提出使用需求。为便于计算，题目对时频资源做离散化：时域上以 Δt 为最小不可分单位，占用时长必须是 Δt 的整数倍；频域上以 Δf 把带宽切分为 100 个等宽频段，一个计划占用连续若干频段且占用频段数不变。

每个用频计划由四个参数描述，展开后等价于时间—频率平面上的 n 个矩形：

  • 频段区间 [a,b)：表示占用 [f₀+aΔf, f₀+bΔf)，宽度即频宽；
  • 首次使用时间区间 [t₀,t₀+τ)：第 1 次使用的时间窗，τ 为单次时长；
  • 间隔时长 iv：相邻两次使用在时间上相距 iv 个 Δt；
  • 使用次数 n：共使用 n 次。
第 k 次使用的时间区间　T_k = [ t₀ + (k−1)·iv , t₀ + (k−1)·iv + τ )　,　k = 1,2,…,n

冲突定义：两个用频计划在频段区间与时间区间上同时存在交叠，即判定为时频冲突。消解则是通过平移频段 / 时间区间、调整间隔时长，甚至撤销计划，使消解后不再存在冲突。

四个问题的递进，本质是约束强度与决策空间不同：

  • 问题一：纯检测，把潜在冲突对全部找出并落表 → 描述性统计；
  • 问题二：幅度受限下的消解（频移 ≤10Δf、时移 ≤5Δt，且一个计划只能动一个参数）→ 受约束决策；
  • 问题三：在问题二的无冲突计划上，不增加时频资源的前提下最多再安排多少 C 类装备 → 容量最大化；
  • 问题四：允许 C 类调整间隔时长（|Δiv| ≤ 10Δt）后的消解 → 决策空间扩展。

二、数据预处理与探索性分析

预处理的核心是把四参数展开为矩形集合，并在展开时统一量纲：

  • 区间解析：频段区间、时间区间在附件中以 "[80,90)" 这类字符串给出，需用正则取出左右端点，并注意半开区间约定；
  • 矩形展开：按上式把每件装备展开为 n 个矩形 (fs,fe,ts,te)，150 件合计的矩形数即冲突检测的规模基数；
  • 量纲统一：频段一律用 Δf 为单位、时间一律用 Δt 为单位，避免后续平移幅度（10Δf / 5Δt）与坐标混用；
  • 基线统计：逐类统计频宽 / 时长 / 间隔 / 次数的取值分布，确认同类参数是否一致（本例完全一致）；
  • 占用刻画：把 100 个频段 × 时间轴铺成格网，统计每个频段的占用计数与时间占用率，为问题三的剩余空间估计打底。
频段占用率 = Σ(各计划占用频段数 × 频段使用时间) / (100 × 时间跨度)

探索阶段至少产出三张图：时频占用热力图（横轴时间、纵轴频段，深色即拥挤区）、各频段占用计数条形图（找最拥挤频段）、三类装备参数分布图（说明参数规律性）。

红线：端点相接不算冲突。 [35,40) 与 [40,45) 在时间上首尾相接但不交叠；若误用闭区间或「≤」比较，会把大量无冲突计划对误判为冲突，问题一的统计结果将整体偏大。半开区间的比较式务必写成严格小于。

三、时频冲突的形式化与检测模型

把每件装备 i 展开为矩形集合 R_i，则两件装备的冲突判定为「频段相交 且 存在一对矩形在时间上相交」：

频段相交：max(fs_i, fs_j) < min(fe_i, fe_j)
时间相交：∃ k,l　max(ti,k, tj,l) < min(ti,k+τ_i, tj,l+τ_j)

以装备为顶点、冲突关系为边，可构造冲突图 G = (V, E)。问题一即「求出全部边」；问题二即「通过移动顶点与删除顶点，把图变成空图」，这为后续两问提供了统一语言。

检测算法与复杂度：

  • 朴素两两：枚举 C(150,2) = 11175 对装备，每对至多 n_i × n_j 次矩形比较。本例 n ≤ 12，直接枚举完全可行；
  • 剪枝：先判频段区间是否相交，不相交直接跳过——这一条能砍掉绝大多数比较；
  • 规模化：若装备数上万，可按频段分桶 + 时间扫描线（区间相交的经典 O(m log m) 做法），把两两比较降为局部比较。

问题一应给出的统计口径：冲突计划对总数、涉及冲突的装备数量与占比、冲突对按类别（A-A / A-B / …）的分布，以及冲突在频段维度的聚集情况（哪几个频段最拥挤）。

这一章最容易出的错是「把装备级判断和矩形级判断混在一起」：频段是否相交是装备级属性（所有次使用共用同一频段区间），时间是否相交必须逐对矩形级比较——因为第 i 件的第 3 次使用可能只和第 j 件的第 1 次使用撞上。

四、从问题一到问题四的模型升级路径

问题一：时频冲突检测

按上式枚举所有冲突对，逐行写入 result1（序号 / 冲突装备1 / 冲突装备2），并统计冲突对数、涉及装备数、类别分布。无需建模优化，考的是定义理解与实现严谨。

问题二：幅度受限下的冲突消解

决策变量为每件装备的动作：频段平移 Δf_i、时间平移 Δt_i、或撤销，且

每件装备至多执行一个动作　；　|Δf_i| ≤ 10Δf　；　|Δt_i| ≤ 5Δt　；　不调整 n 与 iv

目标不是单一标量，而是词典序（lexicographic）多目标：先最小化撤销数量，再最小化被调整的计划数量，再最小化调整幅度，同时要求高优先级（A > B > C）装备尽量不动。

可用的求解思路：

  • 冲突定向让路（贪心）：反复取一个冲突对，让低优先级一方让路；幅度 δ 从小到大试探，先试频移、再试时移；两方都动不了才撤销。实现简单、结果稳定，能保证结束时无冲突；
  • 精确方法：把「是否调整 / 如何调整」建模为 0-1 整数规划（每件装备一个动作变量），用 CP-SAT / Gurobi 求精确最优，适合小规模或作为贪心的对照；
  • 改进方向：贪心对「先处理哪个冲突对」敏感，可按冲突度（度数）从大到小排序、或做多次随机重启取最优，作为灵敏度对照。

问题三：无冲突计划上的 C 类容量最大化

基准是问题二得到的无冲突计划，不再限制平移幅度，但不增加时频资源——即只能在 100 个频段 × 现有时间跨度内「见缝插针」。C 类装备参数完全一致，故可定义一个容量模板 (bw_C, τ_C, iv_C, n_C)，单件占用的时频面积为常数。

容量上界　U = ⌊ (100 × T − Σ 已占用面积) / (bw_C · τ_C · n_C) ⌋

这一问本质是带周期结构的二维装箱：每个模板在频段方向占 bw_C 宽、在时间方向以 iv_C 为周期、每次占 τ_C，占空比为 τ_C / iv_C，因此同一频段内可容纳的件数受占空比限制（最多约 iv_C / τ_C 件）。求解可用「按频段分带 + 按相位排布」的贪心：逐条候选频带、逐个起始时刻试放，能放则放。

问题四：允许 C 类调整间隔时长

把决策空间从「频移 / 时移 / 撤销」扩展为「频移 / 时移 / 间隔调整 / 撤销」，其中仅 C 类可调整间隔且 |Δiv| ≤ 10Δt。间隔一变，该装备后续所有次使用的时间窗整体伸缩，冲突格局随之变化。工程上可直接复用问题二的消解引擎，只在「频移 → 时移」之后插入一段「间隔调整」试探：

for δ = 1…10:　iv ← iv ± δ　→　重新做冲突判定　→　无冲突则接受，否则回滚
问题四是问题二的「参数扩展」而非新模型——同一套冲突判定、同一套让路策略，只是让 C 类多了一种动作。把这一点写清楚，四个问题就串成了一条主线：检测 → 受限消解 → 容量最大化 → 放宽参数再消解。

建议做的灵敏度分析：

  • 平移幅度上限：把 10Δf / 5Δt 分别放宽到 5 / 10 / 20Δf，看撤销数量的变化曲线——若继续放宽几乎不再减少撤销，说明瓶颈是局部频段极度拥挤而非幅度不够；
  • 让路顺序：按装备编号顺序 vs 按冲突度从大到小排序，对比撤销数与调整数，检验贪心策略的稳健性；
  • 间隔调整上限：问题四中把 |Δiv| ≤ 10Δt 收紧到 5Δt，量化「间隔自由度」对撤销量的贡献，这是问题四最有说服力的结论；
  • 优先级权重：若把优先级改为「撤销代价」权重，观察 A 类是否始终零撤销——检验约束是否真正生效。
一个能写进论文的好结论：问题四相比问题二的撤销量下降，全部来自 C 类，且下降幅度与间隔调整上限近似单调——它把「间隔自由度」的价值量化了，而不是笼统地说「参数放宽了，结果变好了」。

六、模型评价与论文写作

优点

  • 用「时频矩形 + 冲突图」统一刻画四问，几何含义直观，检测与消解共用一套判定函数；
  • 问题二把多目标写成词典序，既贴合题面「减少撤销 → 减少调整 → 减小幅度」的措辞，又便于算法实现；
  • 问题三给出面积上界作为理论标尺，可行解与上界的差距即装填效率，结论有量化依据；
  • 问题四以「参数扩展」的方式复用引擎，代码改动小、逻辑链条完整。

局限与改进

  • 消解采用贪心，不保证全局最优；可用整数规划 / CP-SAT 求精确解并给出最优性间隙；
  • 问题三的排布为启发式，与面积上界之间可能仍有空隙，可尝试按频段分区的周期排布或列生成法逼近上界；
  • 未考虑「一件装备的多参数联合微调」，可引入局部搜索（邻域移动 + 模拟退火）进一步压缩撤销量。
