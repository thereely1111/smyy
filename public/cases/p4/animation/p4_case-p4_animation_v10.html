时频冲突检测与消解 100 个离散频段 × 未显式限定的时间轴，150 个用频装备的用频计划在时频平面上争夺有限资源。

随着现代战场上电磁用频装备数量急剧增长，从传统的雷达、通信台到新型的无人机集群、精确制导武器，每个系统都在有限的频谱资源上争夺一席之地。电磁兼容（EMC）矛盾日益突出——两个装备若在同一时间使用相邻或相同的频段，轻则互相干扰导致通信失真，重则引发数据链路中断甚至武器失效。

本题将这个工程问题转化为一个纯粹的几何问题：时频资源被离散化为一个二维网格，每个用频计划是网格上的一组矩形。问题一要求我们把 150 个装备的全部矩形两两判定是否相交；问题二到四则要求在优先级约束和调整幅度约束下，把冲突的矩形"挪开"，使全部矩形在网格上互不重叠。

离散化的细节直接决定后续所有模型的输入形式。Δf 和 Δt 的取值不是题面给定的数值，而是单位标记——Δf 代表"一个离散频段的宽度"，Δt 代表"一个离散时间单位的长度"。所有频段值都是整数倍的 Δf，所有时间值都是整数倍的 Δt。这种抽象使我们不必关心具体的 MHz 或 ms 数值，只需要处理整数运算。

离散化规则 题面逐字整理 + 数学解读

「频域上，以固定的频带宽度 Δf 将系统可提供的有限带宽频率资源离散化为 100 个宽度相同的频段，编号为 0、1、2、…、99。每个用频计划占用 连续的若干个频段，从频段 fs 开始、到频段 fe 结束（半开区间 [fs, fe)）。」

半开区间的含义：频段 20 表示的是 [20, 21)，即从第 20 个 Δf 到第 21 个 Δf。这样设计是为了避免边界归属的歧义——两个装备若一个用到 20 截止、另一个从 20 开始，它们在频域上刚好不重叠。所有冲突判定都依赖半开区间的约定。

「时域上，用固定的时间长度 Δt 作为时间资源的基本单位，时间轴从 0 开始，以 Δt 为步长。一个用频计划的首次使用时间区间为 [ts, te)，之后每隔 p·Δt 重复一次，共使用 n 次。」

这里隐含了一个重要细节：单次使用的时长 τ = te − ts，它不直接作为输入参数出现，而是由首次时间区间的长度推导得出。间隔 p 和次数 n 决定了后续所有使用的时间位置——这意味着时间轴上的占用是周期性的、等间距的。

关键：时频资源 = 一个 100 × T 的二维网格，每个用频计划 = 网格上的一组矩形块。这是后续所有建模的几何基础。

冲突判定规则 两矩形是否相交

「当两个用频计划的 时间区间存在交叠 且 频段区间存在交叠 时，则判定它们之间存在时频冲突。冲突发生在两个装备的某一次使用之间。」

用数学语言展开：装备 i 的第 k 次使用和装备 j 的第 l 次使用发生冲突，当且仅当

频段重叠：fi < fj + bwj ∧ fj < fi + bwi 等价于：[fi, fi+bwi) ∩ [fj, fj+bwj) ≠ ∅ 时间重叠：(ts,i + k·pi) < (ts,j + l·pj) + τj ∧ (ts,j + l·pj) < (ts,i + k·pi) + τi 等价于：[ts,i+k·pi, ts,i+k·pi+τi) ∩ [ts,j+l·pj, ts,j+l·pj+τj) ≠ ∅ 冲突判定 ⟺ 频段重叠 ∧ 时间重叠

注意一个细节：同一个装备的不同使用之间也可能冲突——间隔 p 小于时长 τ 时，前后两次使用的时间区间会重叠。但在实际数据中这种情况极少，而且题面关注的是不同装备之间的冲突消解。

判定复杂度：O(N² × K_i × K_j)，其中 K_i 是装备 i 的使用次数。对 N=150、K≈3、K²≈9 的规模，朴素扫描约 1.0×10⁵ 次判定，完全可接受——这意味着问题一不需要任何高级算法。

A / B / C 三类，优先级递减 优先级决定消解时"谁先动"：高优先级装备尽量不动，冲突时先调整低优先级的那一方。

附件 1 给出 3 类共 150 个用频装备的完整用频计划。题面明确规定了优先级规则 A > B > C：当两个装备发生冲突时，应优先保持高优先级装备的参数不变，让低优先级的那个去调整。这个规则直接决定了后续消解算法的决策顺序——它不是一个可以忽略的建模细节，而是整个问题的核心约束之一。

消解参数的约束也由题面明确给出：每个用频计划最多调整一个参数（要么频段 ±10Δf，要么时间 ±5Δt，要么撤销，三者选一）。频率方向的调整幅度比时间方向大（10 vs 5），这暗示频谱资源在工程上比时间资源更宝贵、更难调整。问题四在此基础上进一步放松约束——允许 C 类装备额外调整间隔 ±10Δt，相当于给低优先级的装备多一个调整自由度。

题面没有给出真实的附件数据——本演示使用固定种子 42 的伪随机数据生成器来合成 150 个装备的参数。合成规则严格遵循题面约束：频段区间在 [0,100) 内、单次时长 5~15 Δt、间隔 30~80 Δt、使用次数 2~5 次。虽然数值是合成的，但数据规模、参数分布和冲突密度都经过了校准，足以演示完整的检测-消解-扩容-灵活消解四步流程。

每个用频计划 = (fs, fe, ts, te, p, n)

频段区间 · 首次时间 · 间隔时长 · 使用次数 四个参数共同决定了一个装备在时频网格上的所有矩形位置和形状。

以附件 1 中的第一件装备 A001 为例，它的参数是：频段 [80, 90)、首次时间 [35, 40)、间隔 60Δt、使用次数 3。这四个数字共同决定了它在时频网格上的全部 3 个矩形。垂直方向由频段区间决定（10 个 Δf 的高度），水平方向由时间区间和间隔共同决定（首次宽度 5Δt，后续每隔 60Δt 再出现一次）。

这里有两个"隐含"参数需要特别注意。第一个是单次使用时长 τ，它不在输入里出现，而是由首次时间区间的长度推导得出：τ = te − ts。第二个是占用频宽 bw，由频段区间的长度决定：bw = fe − fs。这两个派生参数在后续所有算法中频繁出现——计算冲突、计算频移后的新位置、估算总时频占用面积。

时间轴上的周期性意味着：如果一个装备的使用次数足够多、间隔足够短，它可能在时间轴上"铺满"整个可视区域。在本次合成数据中，最长的装备时间跨度约 760 Δt（首次时间 28 + 间隔 100 + 使用次数 7 → 跨度 628），所以时频网格的 X 轴（时间）需要扩展到 760 Δt 才能完整展示所有装备的全部使用。

① 频段区间 [fs, fe)

决定矩形的垂直位置（从 fs 到 fe）和高度（bw = fe − fs）。fs 的取值范围是 [0, 100 − bw]，因为总频段只有 100 个。

合成数据示例：bw = 10~20 例：[80, 90) → 占用频段 80~89，bw = 10

调整约束（P2）：频移幅度 ≤ 10 Δf，即新频段 [fs±k, fe±k)，k ≤ 10。频移不能让新频段超出 [0, 100)。

② 首次时间区间 [ts, te)

决定第一个矩形的水平位置和宽度（τ = te − ts）。ts 可以从 0 开始任意取值——时间轴没有硬性上限。

合成数据示例：τ = 5~15 例：[35, 40) → 第一次使用时长 5 Δt

调整约束（P2）：时移幅度 ≤ 5 Δt，即新起始时间 ts ± k，k ≤ 5。时移不改变 τ、bw、p、n，只是把整个时间轴上的所有矩形平移。

③ 间隔时长 + 使用次数 p + n

决定后续所有矩形的水平位置。每隔 pΔt 重复一次，共 n 次。时间跨度由 p 和 n 决定：total_T = ts + (n−1)·p + τ。

合成数据示例：p = 30~80, n = 2~5 例：p=60, n=3 → 时间块 [35,40), [95,100), [155,160)

调整约束：问题二不允许调整间隔；问题四允许 C 类装备调整间隔 ±10 Δt。间隔调整会改变后续所有矩形的位置，效果类似"拉伸或压缩时间轴"。

参数 → 时频矩形群 形式化展开，后续所有算法都基于这个展开

给定装备 e = (fs, fe, ts, te, p, n)，可以机械地生成它在时频网格上的全部 n 个矩形：

对于装备 e: 派生参数: bwe = fe − fs // 占用频宽（垂直高度） τe = te − ts // 单次使用时长（水平宽度） 第 k 次使用 (k = 0, 1, …, n−1): 频段: [fs, fs + bwe) // 垂直区间不变 时间: [ts + k·p, ts + k·p + τe) // 水平区间随 k 右移 k·p 时间跨度: tmax = ts + (n−1)·p + τe // 最后一个矩形的右边界 冲突检测时: 对 (i, j) 遍历 k ∈ [0, ni), l ∈ [0, nj) 消解时: 修改 fs' 或 ts' 或 p' 后重新生成全部矩形

这个展开过程是纯函数式的——给定参数就能机械地算出所有矩形位置。后续的冲突检测、消解、扩容算法全部依赖这个函数。

四个子问题的逻辑与依赖

一条主线，四个层次 从「发现问题」到「解决问题」再到「还能更好吗」，最后放松约束再解一次——每一问都为下一问铺路。

四问共用同一批装备参数和同一块时频资源（100 Δf × T），差异只在于约束的松紧和目标的方向。问题一是纯几何检测，输入就是附件 1 的原始参数；问题二在问题一的冲突清单基础上，带优先级约束做消解；问题三在问题二的无冲突方案上进一步"扩容"，塞入更多的 C 类装备；问题四重新回到问题一的冲突清单，但给 C 类装备多了一个调整自由度（间隔 ±10Δt），看能否用更少的撤销次数完成消解。

一个值得注意的依赖关系：问题四可以不依赖问题二——它直接基于问题一的冲突清单做消解，只是约束不同。这意味着你可以独立处理 P1→P2→P3 这条主线，同时并行处理 P1→P4 这条支线。P2 和 P4 的结果对比本身就很有价值——它可以量化"给 C 类多一个自由度"对消解效率的提升幅度。

问题一 冲突检测

"对附件 1 中的所有用频计划进行两两冲突检测，输出所有存在冲突的装备对。"

对 150 个装备的全部矩形两两判定重叠。这是纯几何问题——不需要任何模型假设，朴素 O(N²) 扫描完全够用。

输出 result1.xlsx

获奖论文通常做法：直接展开所有矩形后两两判定，或用扫描线 / 空间索引加速。数据规模小，朴素法最好。

问题二 优先级消解

"在优先级约束和调整幅度约束下，消解问题一检测出的所有冲突。每个装备最多调整一个参数，频 ±10、时 ±5。"

核心决策：冲突双方谁优先动？优先让低优先级的去试三种操作——频移、时移、撤销。如果频移 ±10 试遍了不行，再试时移 ±5，最后才考虑撤销。

输出 result2.xlsx

获奖论文通常做法：贪心为主，少数用 整数规划 ILP 或 约束满足 CSP。关键是冲突消解的顺序和"动谁"的选择策略。

问题三 容量最大化

"基于问题二的无冲突方案，在不调整幅度限制的情况下，最多还能容纳多少个 C 类装备？"

在 P2 的无冲突方案上，放宽频移和时移的幅度限制（允许任意平移），尝试塞入更多的 C 类装备。这本质上是一个二维装箱问题——但装箱的是"矩形群"而不是单个矩形。

输出 result3.xlsx

获奖论文通常做法：贪心放置（从 (0,0) 开始枚举可行放置位置），或 遗传算法。因为时频网格只有 100 列宽，枚举速度很快。

问题四 灵活消解

"允许 C 类装备额外调整间隔 ±10Δt，重新消解问题一的所有冲突，比较与问题二的结果差异。"

给低优先级的 C 类装备多了一个自由度——不仅能频移、时移、撤销，还能调整间隔。间隔调整会改变后续所有矩形的位置，相当于"拉伸时间轴"，可能让原本要撤销的装备保留下来。

输出 result4.xlsx

获奖论文通常做法：与 P2 相同的贪心框架，只是 C 类多了一个操作候选。核心收益 = 减少的撤销次数 ÷ 增加的调整自由度。

四问的依赖关系 可视化

四问的统一视角 时频网格是共同的语言

无论哪一问，我们都在同一张时频网格上操作——检测就是在网格上找重叠的矩形对；消解就是移动矩形让它们不再重叠；扩容就是在空白处塞更多矩形；灵活消解就是给某些矩形多一种移动方式。

这个统一视角的好处是：四问的动画演示可以复用同一套 SVG 渲染组件（时频网格 + 矩形 + 悬停提示），每一页只是展示的数据不同（原始参数 vs 消解后参数 vs 扩容后参数）、交互不同（只看 vs 检测动画 vs 消解动画 vs 两版对比）。这种一致性让观众能在四页之间快速建立直觉联系。

💡 论文写作建议：获奖论文通常在"模型假设"部分就明确写出时频网格的离散化框架和矩形模型，后续所有模型（检测、消解、扩容）都在这个框架下展开。统一的几何视角让模型之间的衔接非常自然。
