问题四 · 题面与建模

C 类装备现在可以调间隔了 动作空间从 3 项扩到 4 项，理论上撤销数量会更少、调整幅度会更温和。

题面原文：「若允许部分 C 类用频装备对用频间隔时长进行调整，但要求与原间隔时长的差异不超过 10Δt，请对问题 1 中检测出的时频冲突进行消解。」核心变化只有一个——C 类装备在消解时，除了频移、时移、撤销之外，多了 间隔微调 这个动作。

🎯 获奖论文思路：把"自由度"看成资源 📐 参数化搜索空间 🌿 邻域动作扩展

间隔调整到底动了什么 与"时移"的本质区别

每件 C 类装备在频段上占 bw 宽，在时间上按固定间隔 p 重复使用 n 次。间隔调整就是把 p 换成 p+δ。注意：它不是整个人平移（那是时移），而是把第 2 次之后的使用时间"重新摊开"，间距变大或变小。

// 第 k 次使用的时间区间 原： [ ts + k·p , ts + k·p + τ ) k = 0..n−1 新： [ ts + k·p' , ts + k·p' + τ ) p' = p + δ 约束 |δ| ≤ 10Δt // 与原间隔差异不超过 10Δt 决定 k = 0 时刻 不动，只有 k ≥ 1 的块整体伸缩

首块 ts 保持不变是"间隔调整"与"时移"最好的区分点：时移把 n 块一起搬家，间隔调整只改"块与块之间的距离"。

为什么这可能减少撤销 它是"多点同时避让"的杠杆

问题二里，某些 C 类装备之所以只能撤销，是因为频移（≤10）和时移（≤5）的幅度有限，动了还是躲不开对手。而间隔调整一次性改变 n−1 个后续矩形的位置——原来 3 处同时冲突，改间隔后可能只剩 1 处甚至 0 处。

举例：C 类 n=3，p=40。对手在 t∈[45,52) 有个块。原布局块落在 40、80、120，第 2 块刚好撞上。改 δ=+10 → p'=50，块变成 50、100、150，第 2 块挪到 50 仍撞；改 δ=−10 → p'=30，块变成 30、60、90，全部避开。δ 的大小方向都要试。

代价：间隔调整的搜索空间比单点微调大，n 越大、越接近"重新排布"，越需要有效的枚举顺序。

A / B 类 动作不变

频移 ±10Δf、时移 ±5Δt、撤销。间隔调整权限不下放给 A/B——题目只说了"部分 C 类"。

C 类 动作 +1

新增间隔 ±10Δt。尝试顺序：频移 → 时移 → 间隔调 → 撤销。先试幅度小、影响面窄的动作，把大动作留到必要时。

结果对比 幕 2 实证

撤销数应更少；频移/时移的平均幅度应更小（因为一部分装备改用间隔解决了）。详细数字在幕 3 的对比表里。

论文加分点：把问题二、问题四抽象成同一套"动作空间 + 优先级 + 约束"框架下的两个实例。问题二是动作集 A₂={频移, 时移, 撤销}，问题四是 A₄=A₂∪{间隔调}。这样只需写一份消解引擎，改一个动作集合参数即可跑出两版解——这也是幕 2 动画能左右同时播放的原因。
进一步的启发式思路：① 间隔枚举优先试"能让矩形落在对手空隙里"的 δ；② 对同一装备，比较"间隔调 +10"与"间隔调 −10"哪个留下的空隙更大；③ 用局部搜索 / 模拟退火在 δ 邻域内找最优。

怎么读这两张图 观察要点

  • 金色块（撤销）的数量：右图应不多于左图。若相等甚至更多，说明间隔枚举策略还不够聪明，需要改进 δ 的搜索顺序。
  • 紫色块（间隔调）的位置：它们原本大概率是"问题二里只能撤销"的那些 C 类装备，现在被救回来了。
  • 青色块（C 类）的整体形态：间隔调后，同一装备的 n 个块间距会变化——肉眼能看到块"被重新摊开"或"被挤紧"。
  • 两图的空余面积：撤销少了，使用的时频格就多了，右图的"空区"应比左图小。

灵敏度分析 δ 上限取不同值时

把题面的 10Δt 换成 5、15、20 再跑一遍，看撤销数怎么变——这是论文里很常见的"参数灵敏度"章节。

典型结论：δ 上限越大，可救回的 C 类越多，但边际收益递减。当 δ ≥ 某个阈值后，撤销数不再下降——说明瓶颈已不在间隔自由度上。

为什么右版可能"不够好" 暴露算法的局限

如果运行后发现右版撤销数并未明显下降，往往是下面三个原因之一——把它们写进论文的"讨论"部分，反而显得严谨。

  • δ 搜索太粗：只从小到大地试 ±1..±10，没优先试"能让矩形正好落进对手空隙"的那些 δ。
  • 贪心的顺序依赖：先消解的装备可能"占了位置"，让后面的装备更难调整。可配合随机重启 / 多起点比较。
  • n 过大导致整体位移越界：间隔变大时，末尾矩形可能超出时间范围，被直接判不可行。
对策：① 间隔枚举改为"枚举所有使某块恰好避开对手的 δ"；② 对同一冲突对尝试"让高优先级方动"的备选；③ 引入局部搜索在邻域内下降。

四问联动的收尾 论文结构建议

  • 问题一：给出检测到的冲突对总数与冲突装备清单——这是后面三问的共同输入。
  • 问题二：基线消解方案的统计（保留 / 调整 / 撤销）。
  • 问题三：在问题二无冲突基线上，最多还能塞进多少件 C 类——容量上限估计。
  • 问题四（本页）：放宽间隔约束后的消解方案，与问题二做定量对比，体现"额外自由度"的收益。
