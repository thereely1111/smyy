问题一 · 冲突检测

对附件 1 做时频冲突检测 冲突 = 两装备某次使用在频段和时间上都有重叠。等价于两个矩形在时频网格上相交。

题面要求将所有检测出的冲突对逐一填入 result1.xlsx。这是整个 D 题四问的起点——冲突没找全，后面的消解就无从谈起。题面的几何模型把电磁兼容这个工程问题抽象成了一个纯粹的矩形相交判定问题，看似简单，但里面藏着两个容易出错的细节：半开区间的边界归属，以及同一装备"周期性使用"导致的多次重叠。

核心问题的几何本质：150 个装备共产生约 500 个时频矩形，两两判定是否相交。朴素 O(N²R²) 扫描对 N=150、R≈500 完全够用——总共约 28 万次矩形相交判定，秒级即可完成。实际上这个规模下，任何"优化过"的空间索引（扫描线、区间树、网格哈希）在常数项上都会比朴素法更慢，因为数据量太小、常数项主导。

获奖论文通常不会在问题一上花太多笔墨，但会用一段话明确自己的检测算法是"朴素两两扫描"，并给出复杂度估算（C(150,2) × ⟨R⟩² ≈ 28 万次判定），作为后续消解算法正确性的前提验证。少数论文会在这一步就做冲突图连通分量分析（把连通的冲突分量找出来），为问题二的消解顺序做准备——这是一个值得加分的预处理。

算法流程 逐对判定，四行核心

输入: equip[0..149]，每个含 rects[] (共 ~500 个矩形) 输出: conflicts[] = [{a, b, overlaps[]}] for i in [0, N): // 第一件装备 for j in [i+1, N): // 第二件装备（避免重复对） overlap ← [] for r1 in equip[i].rects: // i 的每次使用 for r2 in equip[j].rects: // j 的每次使用 fs ← max(r1.fs, r2.fs) // 频段交集下界 fe ← min(r1.fe, r2.fe) // 频段交集上界 ts ← max(r1.ts, r2.ts) // 时间交集下界 te ← min(r1.te, r2.te) // 时间交集上界 if fs < fe and ts < te: // 半开区间：严格小于 overlap.append([fs,fe,ts,te]) if overlap ≠ ∅: conflicts.append({i, j, overlap})

关键在最后一行判定：fs < fe 且 ts < te 才冲突。用严格小于而不是 ≤，是因为频段/时间区间都是半开的——边界刚好相接（fs = fe）不算重叠。

复杂度分析 为什么朴素法就够

维度规模因子
装备对数C(150,2) = 11 175O(N²)
矩形对数（平均）≈ 3² = 9O(⟨R⟩²)
总判定次数≈ 10 万毫秒级
最坏情况（⟨R⟩=10）≈ 112 万仍在秒级
复杂度的关键在于"平均每装备约 3 次使用"。即使极端情况下某装备使用 10 次，总判定次数也只有百万量级。所以问题一不需要任何高级数据结构——朴素法最稳、最不容易写错，反而比扫描线更可靠。

下方网格展示全部 150 个装备的时频占用。初始只显示淡色矩形（表示"已绘制但未检测"），然后逐步用红色框高亮冲突对及其重叠区域。每一对冲突装备都可能有 1 处或多处矩形重叠——比如两个间隔相同、使用次数相同的装备，如果首次时间也接近，就会有多次同时冲突。

红色矩形标记的是重叠区域的几何交集——它的宽和高分别是两装备时间交集和频段交集的长度。如果重叠区域在时间上很短、频段上也很窄，说明这对冲突其实比较"轻微"，后续消解时可能只需要微调其中一方的时间或频段就能绕开。反之，如果重叠区域很大（几乎覆盖其中一个装备的全部矩形），说明这对冲突很棘手，可能需要幅度较大的调整甚至撤销。

建议的观看顺序：先点「自动播放」整体感受冲突的密度和分布，再回到第一对用「下一对」逐对细看。重点关注三类组合——A-A 冲突（两边都是高优，最难办）、C-C 冲突（两边都是低优，最好调）、以及重叠处数特别多的对（说明两装备的周期节奏"撞上了"）。

统计视角 · 论文要给的数字

冲突集中在哪里 按优先级组合、频段密度、时间窗口三个维度看，热点区域一目了然。

冲突不是均匀分布的。识别热点频段和时段，对后续消解的策略选择至关重要——如果冲突集中在某几个频段，频移消解就会比时移更困难，因为频移幅度只有 ±10Δf，可操作空间更窄；同样，如果冲突集中在某个时间窗口，时移消解也会受限。这正是"先统计、后消解"的价值所在。

另一个值得关注的维度是优先级组合：A-A 冲突最棘手（两边都不想动），C-C 冲突最灵活（随便怎么调都行）。如果检测结果里 A-A 冲突特别多，问题二的消解难度会显著提升——甚至可能需要撤销少量装备。这一节的三个统计图，正好对应题面要求的"在论文中给出时频冲突的统计结果"。

获奖论文参考思路 统计阶段可以加分的三个动作

冲突统计通常会从三个维度展开：① 按优先级组合统计（A-A / A-B / A-C / B-B / B-C / C-C 各有多少对）；② 频段 / 时间冲突密度热力图，用于识别热点区域；③ 每对冲突的严重程度（重叠面积占两个装备总面积的比例）。第三个维度尤其重要——严重冲突对后续消解策略的选择有直接指导意义：重叠面积比小于 20% 的冲突可能只需微调，大于 80% 的冲突大概率需要撤销其中一方。

交付物 · result1.xlsx

结果表的格式与填写要点 模板非常简单：A 列序号、B/C 列冲突的两个装备编号，每对装备只填一行。

注意：题面模板的 每一行代表一对冲突装备，即使它们之间存在多个矩形重叠，也只填一行。我们的检测算法已经按「装备对」做了归并——这意味着 result1.xlsx 的行数 = 冲突装备对的数量，而不是冲突矩形对的数量。这是初学者最容易搞混的地方。

result1.xlsx 是后续三问的输入——问题二、三、四都基于这里列出的冲突对进行消解。因此论文写作时要明确说明检测算法的正确性验证：可以用小规模合成数据做交叉检验（手工算几对，与程序输出比对），或用已知无冲突的数据集做反证测试。

关键实现细节 容易踩的坑

  • 一个冲突装备对可能有 多个矩形重叠（间隔相同时），但模板只写一行
  • 装备编号按 字母 + 三位数字 格式（A001, A002, …, C080）
  • 半开区间判定要用 严格小于：fs < fe 且 ts < te，边界相接不算冲突
  • 避免重复：用 i < j 的双循环保证每对只判一次
  • 冲突对数量 = 模板行数 − 1（表头行）

问题一的定位

纯几何检测，不涉及任何优化或约束。做得正确是后三问的前提——如果冲突都没找全，后面消解就没有意义。

容易踩的坑

① 把半开区间当成闭区间导致边界重复计数；② 模板每对装备多行；③ 忘记排除自冲突（同一装备不同次使用之间）。
