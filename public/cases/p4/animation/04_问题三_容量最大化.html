问题三

在无冲突基线上，不限平移幅度塞更多 C 类 等价于：在问题二消解后的时频网格里做矩形装箱（2D packing）。

题面说「如果不限制频段和时间的平移幅度」——这意味着新增的 C 类装备可以被放到时频网格上的 任何位置，唯一约束是不能与现有（已消解、无冲突的）装备相撞。问题要问的是：最多还能塞下多少个 C 类装备。

这本质上是一道 二维装箱 / 装填密度最大化 问题：把时频平面看作一块 100Δf × maxΔt 的「货舱」，把每件 C 类装备看作一个由 n 个矩形组成的「非连续长条」，问货舱里最多能塞几条。关键在「最多」二字——论文必须给出数量、给出上界、并说明为什么这是一个好的下界。

新装备的形态假设 必须先说清楚

题面未指定要新增的 C 类装备的具体参数，因此作答时必须自行设定并论证。动画演示采用一个标准的 C 类模板作为代表形态：

// 新增 C 类模板（可自行设定） bw = 12Δf // 频段宽度 τ = 8Δt // 单次使用时长 iv = 60Δt // 使用间隔 n = 3 // 使用次数 // 单个装备总占用 = bw × τ × n = 12 × 8 × 3 = 288 时频格
模板选得越大，能塞进去的越少。所以论文里务必做敏感性分析：给出不同 (bw, τ, iv, n) 下的容量曲线，才能说明结论的鲁棒性。

算法思路

贪心在可行空洞里塞矩形 按候选位置逐个尝试，能放下就放，直到放不下为止。

最朴素的做法：枚举所有可能的起始频段（0 ~ 100−bw）和首次时间（0 ~ maxT−…），挑第一个不冲突的位置放进去，再重复。这是一次「先来先占」的贪心——简单、快，且能给出一个可靠的下界。

更聪明的做法是先找空洞（网格上被现有装备包围但空着的区域），再用某种启发式决定填洞顺序。不同的填洞顺序会得到不同的最终数量，这是装箱问题的固有特征：贪心不保证全局最优。

主循环 朴素枚举版（本页动画所用）

输入: 已消解的无冲突装备集 S 输入: 新 C 类模板 E = (bw, τ, iv, n) 输出: 可塞入的数量 M 与位置清单 M ← 0 for fs = 0 .. 100−bw: for ts = 0 .. maxT−iv·(n−1)−τ: // 步进 2 提速 候选 rects ← [(fs, fs+bw) × (ts+k·iv, ts+k·iv+τ), k=0..n−1] if 候选 rects 与 S 中所有装备均无重叠: S ← S ∪ {候选装备}; M ← M + 1 // 就地放入，影响后续判断（因此越早放越占优） 返回 M

算法是在线式的：每放一个，就立刻成为后续判断的障碍。所以先枚举到的位置会"抢"掉空间——这与现实中"先到先得"的频谱分配逻辑一致。

枚举顺序为何影响结果

本页动画按 fs 从小到大、ts 从小到大 枚举（相当于"从左上往右下扫着填"）。若换顺序，结果可能不同：

  • 按空洞大小优先：先填大空洞，通常更省空间（大件难放，先安排）
  • 按时间维度优先：先把时间轴排满，再考虑频段，适合对时延敏感的场景
  • 随机 + 多次重启：跑多组随机顺序取最好，简单有效
这四种顺序的结果差异，正好可以做成论文里的一组对照实验，说明"启发式选择"的重要性。

复杂度与可行性 为什么枚举得动

环节操作复杂度量级估算

更优方法 从可行解走向近似最优

Maximal Rectangle

先把网格所有极大空矩形求出来（类似直方图的"最大矩形"），再在空矩形集合里做匹配——比逐格枚举更贴近空间结构。

模拟退火 / 遗传

允许"先搬走已放装备，再腾位置放新的"，用元启发式在解空间里跳出局部最优，通常能比纯贪心多塞若干个。

整数规划（ILP）

变量 = 每个候选位置是否放置，约束 = 相互不重叠。小规模可求最优；同时它给出的线性松弛就是更强的容量上界。

交付物 & 方法总结

result3.xlsx 的格式与容量结论 新增 C 类编号、频段区间、时间区间（首次）。

交付物 result3.xlsx 记录每一个新增 C 类装备的落位：序号、频段区间、首次时间区间。由于新增装备都是同一种 C 类模板，其间隔与使用次数相同，无需逐行填写——只要在论文里统一说明模板参数即可。

论文里最有价值的部分不是"塞了 N 个"这个数字本身，而是：N 是怎么求出来的（算法）、N 距离上界有多远（最优性讨论）、换个模板会怎样（敏感性分析）。这三点决定了这一问的得分层次。

论文必须交代的关键假设

  • 新增 C 类装备的形态模板（bw、τ、iv、n 各取何值、依据是什么）
  • 不同模板会导致完全不同的容量——必须做 敏感性分析
  • 新装备之间也需互不冲突（动画中已保证），不能只检查与原装备的关系
  • 若题面隐含"C 类新装备参数固定"，则需严格遵守并说明
贪心装箱 极大空矩形 模拟退火 ILP 上界
「基于问题 2 求解得到的无冲突用频计划，如果不限制频段和时间的平移幅度，在不增加时频资源的前提下，最多还能安排多少 C 类用频装备？」
→ 核心在"最多"二字：不能只给一个贪心数，而要给「可行下界（实际塞了多少）」+「理论上界（最多可能多少）」+「两者差距的成因分析」。

论文里应该给出的完整答案结构

① 可行解
—
贪心装箱实际塞入的数量
② 上界
—
理论容量上界（面积估算法）
③ 装填密度
—
已占用 / 总资源
④ 差距
—
上界与可行解之间的空隙
若 ① 明显小于 ②，说明还有优化空间，可继续用模拟退火 / 局部搜索改进；若 ① 已接近 ②，则贪心解已足够好，可据此论证最优性。

方法论定位

问题三是 二维装箱 / 装填密度最大化 问题。它是 NP-hard 的，因此工程上以"贪心给下界 + 面积给上界 + 启发式逼近"三板斧作答最稳妥。

与问题二的衔接

问题二消解得越干净（撤销越少、越紧凑），留下的空洞越规整，问题三能塞的就越多。两问在数据上是串联的。
