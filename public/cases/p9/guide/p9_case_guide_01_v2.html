2026 美赛 D 题 · 实训指导书

成功的体育管理

战绩与财务互相驱动 · 从现状建模到动态决策、定价优化与场馆投资

一、题目重述与信息结构

职业体育俱乐部的经营是典型的竞技目标与财务目标耦合问题：薪资投入决定阵容实力，阵容实力决定战绩，战绩又反过来决定门票需求、商品与赞助收入，最终决定球队利润与市场估值。本题要求为球队业主完成四项任务：

  • 问题一：建立「战绩 + 财务 → 球队利润 / 估值」的现状模型与指标体系，辨识对利润影响最大的关键驱动因素；
  • 问题二：建立动态决策模型，在战绩与财务状态随时间变化的情况下，滚动调整阵容招募与运营策略；
  • 问题三：优化门票定价，量化票价对利润、上座率与球迷效用的影响，给出推荐票价；
  • 问题四：评估场馆投资等资本性决策对球队长期利润与估值的影响，并做敏感性分析与稳健性检验。

关键简化：把球队压缩为「一个状态、一套损益、一个估值倍数」——用薪资档位刻画竞技投入、用线性需求曲线刻画票务市场、用固定倍数把年收入折算成球队估值。四问共用同一骨架：后一问的输出是前一问的输入（问题一的损益模型 → 问题二的决策状态 → 问题三的定价基准 → 问题四的投资评估基准）。

本题第一个得分点是画出「决策 → 战绩 → 需求 → 收入 → 利润 / 估值」的单链结构图，标清四问各自在这条链上做的动作（辨识 / 优化 / 定价 / 投资评估）。评委一眼就能看出你是否抓住了「一条链、四问递进」的主线。

各项固定口径：联盟媒体分成与公共收入 130 M$ / 赛季，场馆运营与差旅等固定成本 95 M$ / 赛季，估值倍数 6.0 × 年收入，年折现因子 γ = 1 / 1.08。

三个必须写清的口径：① 营收不只在门票——商品与本地收入、赞助收入都随战绩上升；② 成本分三层——薪资是最大的一块、固定成本不可变、边际成本只随到场上座数变化；③ 估值按收入倍数——这使得「战绩 → 收入」的每一块钱都会在估值端被放大 6 倍，是问题二和问题四的核心杠杆。

三、现状模型：战绩—财务传导链

把竞技端与财务端串成一条可计算的链条，四问全部建立在这条链上。

R = 50 + 18·ln( PS / 140 ) —— 阵容评级：薪资的对数递减回报 w = 1 / (1 + exp( −(R − 50) / 8 ))，∈ [0.25, 0.72] —— 胜率：logistic 映射 D(p) = 12000 + 9000·(w − 0.5) − 70·(p − 75) —— 每场需求：战绩线性拉动 + 票价线性抑制 收入 = 41·min(D,CAP)·(p + ANC) + (15 + 95w) + (10 + 85w) + 130 成本 = PS + 95 + 41·min(D,CAP)·VC + 运营投入 利润 = 收入 − 成本 V = 6.0 × 年收入

四、四问的模型化路径

问题一 · 关键驱动辨识

以现状为基准，对每一个驱动因素施加同等强度的扰动（+10%，或胜率 +0.05），复算利润并比较变化幅度，得到敏感度排序 战绩 > 薪资 > 票价 > 运营 > 附加收入。这套辨识同时确定 KPI 体系：竞技（胜率 / 胜场）、财务（利润率 / 薪资收入比）、资产（估值 / 估值倍数）、球迷（上座率 / 消费者剩余）。

问题二 · 动态决策模型

决策空间为 5 个薪资档 × 3 个运营档 = 15 个状态，动作约束为「每年每档最多移动一档」（阵容重建需要时间），升档签约成本 18 M$、降档买断成本 25 M$。以业主效用为目标——「5 年经营利润现值 + 末年球队估值现值」，用后向递推求解：

F_t(sp) = max_s [ Π(s) − 换档(sp, s) + γ·F_{t+1}(s) ]， F_6(s) = V(s)， γ = 1 / 1.08

问题三 · 门票定价优化

在现状战绩下需求为线性 D(p) = A1 − 70p，A1 = 17921（需求为零的价格上界 $256）。分别求解三个目标：票务收入最大（max p·D）、贡献利润最大（max D·(p + 附加 − 边际成本)）、球迷效用均衡（消费者剩余加权 25% 后与利润折中）。

问题四 · 场馆投资评估

投资方案为总投资 420 M$、球队自有出资 40% = 168 M$（公共部门分担 60%）、容量 18000 → 21500 座、每场需求上移 +7500 座、附加收入 22 → 30 $/人、年运营成本 +14 M$。以增量现金流折现（15 年、r = 7%）计算经营口径 NPV，并叠加估值增量 ΔV = 6.0 × 增量年收入，得到业主视角综合净收益。

五、求解步骤与代码要点

四个问题共用一套 numpy 流程（仅依赖 numpy，无其它第三方库）：

  • 步骤 1 · 定义状态网格：枚举 5 个薪资档与 3 个运营档，生成 15 个状态，对每个状态算出胜率与完整损益（收入五项、成本四项、利润、估值）。
  • 步骤 2 · 现状基准与驱动辨识：在现状（160 / 8 / $75）处取基准损益，再对票价、薪资、附加收入、运营投入、胜率分别扰动，输出敏感度排序。
  • 步骤 3 · 动态规划：以 15 个状态为节点、每年最多移动一档为动作集，后向递推 5 步（F_6 = 末年估值），再从现状状态回溯出最优路径；同时用「目标胜率 0.60 修正薪资档 + 按利润率修正运营档」构造自适应反馈策略作为对照。
  • 步骤 4 · 定价优化：用一阶条件解出三个目标的最优票价（贡献利润最大的解析解为 p* = (A1 − 70·每人边际贡献) / 140），逐点计算票价 / 需求 / 上座率 / 票务收入 / 贡献利润 / 球迷效用 / 弹性。
  • 步骤 5 · 投资评估与稳健性：算增量年利润，用年金系数折现 15 年并扣减球队出资得 NPV；对需求上移、造价、折现率做敏感性；再用二分法解出保本门槛（需求上移多少座才能覆盖新增成本）。
R = 50 + 18*log(PS/140) w = 1/(1+exp(-(R-50)/8)) D = 12000 + 9000*(w-0.5) - 70*(p-75) att = min(D, CAP); gate = 41*att*p; ancr = 41*att*ANC rev = (gate+ancr)/1e6 + (15+95*w) + (10+85*w) + 130 cost = PS + 95 + 41*att*VC/1e6 + OPS profit = rev - cost; value = 6.0*rev
自检三件套：① 15 个状态的利润应随薪资档单调下降（投入越多当年利润越低），而胜率单调上升；② 动态规划路径的末年估值应不低于任何单条对照策略（否则回溯有错）；③ 定价的三个最优票价应满足「票务收入最大价 > 贡献利润最大价」且两者都位于需求弹性接近 1 的位置。

这一条是本题的定价高光讨论点：现状价 $75 的贡献利润 42.60 M$ 是四个方案里最低的，说明现行定价明显低于最优区间——提价本身就是最直接的价值来源。若评委追问「为什么推荐 $105.72 而不是利润最大价 $124.51」，回答：贡献利润曲线在 $106–$128 之间近乎平坦（差异仅 2.0%），而球迷效用曲线单调下降，取平台区偏低价是用可忽略的利润换取不可忽略的球迷价值。

结论与风控建议：场馆投资在基准与乐观情景下均可行，其价值主体是资产增值（ΔV 273.57 M$）而非当年现金流（NPV 77.75 M$）。第一敏感变量是「需求上移能否兑现」，因此建议分期建设，并把「首年上座率是否达到 89%」作为继续投入的触发条件——这样即使落入悲观情景，也能在中期止损，把 168 M$ 的风险敞口压到最小。

四问总结论：

  • 问题一：现状球队年收入 317.80 M$、年成本 270.79 M$、利润 47.01 M$、估值 1906.8 M$；关键驱动为战绩。
  • 问题二：最优动态策略是「先守后攻」——前 3 年维持中档阵容攒现金，第 4、5 年集中升档冲顶，末年估值 2170.8 M$、业主效用 1632.6 M$。
  • 问题三：推荐均衡票价 $105.72（现状 $75 明显偏低），贡献利润 48.62 M$、球迷效用 32.41 M$、上座率 58.4%。
  • 问题四：自付 168 M$ 的场馆投资在基准情景下经营口径 NPV +77.75 M$、估值增量 +273.57 M$、综合净收益 +351.32 M$，建议分期建设并以首年上座率为触发条件。
三问之间的接口是本题最要紧的连贯性：问题二选出的争冠态（薪资 210）决定了问题四的收入基数；问题三选出的均衡价（$105.72）决定了问题四的需求与收入水平。若把定价换成利润最大价 $124.51，问题四的增量年收入会大幅缩水，因为容量扩张带来的新增座位恰恰是价格敏感度最高的那部分需求——这正是「四问必须自洽」的现实含义。
