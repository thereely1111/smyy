智能手机电池耗电建模

锂电池 SOC 连续时间模型 · 四因素到四问逐级加深

一、题目重述与信息结构

智能手机已成为日常生活的核心设备，其续航表现受屏幕亮度、处理器负载、后台网络活动与环境温度等多因素影响。某厂商提供了一批放电试验日志（含 SOC 序列与整段放电时长记录），并标注了每组试验的四个载荷指标：屏幕亮度 L、处理器负载 u、后台网络活跃度 n（均归一化到 0~1）与环境温度 T（℃）。要求完成四个问题：

  • 问题一：建立锂电池 SOC 的连续时间模型，刻画上述四因素对整机平均功率的影响，并利用日志数据辨识模型参数、评估拟合精度；
  • 问题二：预测四种典型使用场景（A 轻度待机、B 中度常规、C 重度游戏+高清视频、D 高温户外导航）下的剩余可用时间，并给出预测的置信区间；
  • 问题三：在尽量不影响用户体验的前提下提出三条可执行的续航优化建议，量化每条建议的续航增益并说明其代价；
  • 问题四：对模型系数做灵敏度分析，判定最敏感因素，并给出温度影响的定量结论。

关键简化：以整机平均功率 P_total 为核心，把四因素统一压缩为一个静态功率表达式，再叠加温度修正因子 φ(T)；SOC 演化由此化为一组线性方程，四问共用同一骨架（这是本题第一个得分点）。

这一步的关键是画出“环境温度 → φ(T) 修正 → 四载荷叠加 → 整机功率 P_total → SOC 线性下降”的单链结构图，标清四问共用的模型式与各自不同的求解目标（参数辨识 / 续航预测 / 优化 / 灵敏度）。评委一眼就能看出你是否抓住了“一个模型、四问递进”的主线。

三、建模思路：SOC 连续时间模型与温度修正

SOC 以恒定功率放电时近似线性下降，连续时间模型取

dSOC/dt = − P_total / C × 100% P_total = φ(T) · ( P_base + a_s·L + a_c·u + a_n·n ) φ(T) = 1 + 0.006·|T − 25| + 0.00035·(T − 25)²

其中 P_base 为静态底耗，a_s / a_c / a_n 分别为屏幕、处理器、网络的功率系数，单位均为 W；φ(T) 为温度修正因子，以 25℃ 为基准，偏离越远则内阻与极化损耗越大、整机功耗越高。

放电时长与功率的关系为 t = (SOC_HI − SOC_LO)·C / P_total，即续航对功率是反比、对功率是凸函数——这条性质是问题三“联合增益大于逐条增益之和”的根本原因。

建模时最容易踩的坑：① 把 φ(T) 写成乘在温度项之外还是某个载荷上——本题是“整机缩放”，必须整体乘；② 忘记 SOC 观测区间是 0.96→0.32 而非 1→0，算时长时会差一个比例因子。

四、参数辨识方法：最小二乘的线性化推导

直接对 dSOC/dt 求系数会带噪声放大，改用积分形式。对单条试验，从初始时刻积分得

SOC_HI − SOC(t) = φ(T)·( P_base + a_s·L + a_c·u + a_n·n ) · t / C

令 y = SOC_HI − SOC_obs，把 200 组 × 50 点池化成 10000 行，构造设计矩阵

X = [ φ(T)·t/C , φ(T)·L·t/C , φ(T)·u·t/C , φ(T)·n·t/C ] (10000 × 4)

于是 y = X·[P_base, a_s, a_c, a_n]ᵀ 成为标准线性最小二乘，用 numpy 的 np.linalg.lstsq 一次求解即可，系数标准差由残差协方差给出：

θ̂ = argmin ‖X·θ − y‖² , sd(θ̂) = sqrt( diag( (XᵀX)⁻¹ · rᵀr / (m − 4) ) )

辨识结果（池化最小二乘，200 组试验 / 10000 个采样点，numpy）为 P_base = 0.15 W、a_s = 1.35 W、a_c = 1.80 W、a_n = 1.10 W。拟合优度：R² = 0.988、RMSE = 0.021 SOC、MAPE = 4.6%、最大瞬时偏差 0.083 SOC。

线性化的价值：把“辨识一个非线性动态模型”降为“解一个 4 元线性最小二乘”，既避免初值敏感，又天然给出系数不确定度 sd，可直接用于问题二置信带（δ 法传播）。这是本题第二个得分点。

五、求解步骤与代码要点

四个问题共用一套 numpy 流程，建议按下列顺序实现：

  • 步骤 1 · 生成/读入日志：200 组试验，载荷 L、u、n 在 0~1 内随机取值，T 在 −10~40℃ 内取值；真实时长 = (SOC_HI−SOC_LO)·C / P_total，再乘 (1 + 0.058 抖动) 得到记录时长；每组取 50 个采样点并叠加 σ = 0.021 的 SOC 噪声。
  • 步骤 2 · 构造线性方程：按上式堆叠设计矩阵 X（(试验×采样点) × 4）与向量 y，调用 np.linalg.lstsq 得到 θ̂，并按残差给出 sd。
  • 步骤 3 · 精度评估：用 θ̂ 回代预测 SOC 与时长，计算 R²、RMSE、MAPE、最大瞬时偏差。
  • 步骤 4 · 四场景续航：对场景 (L,u,n,T) 计算 φ(T) 与 P_total，续航 t = C / P_total；95% 带 = δ 法参数不确定度 ⊕（载荷波动 5%）场景波动，取 1.96 分位合成。
  • 步骤 5 · 优化与灵敏度：基线取场景 B，改动单因素算续航增益；对四个系数各 +10% 复算续航变化，得到敏感度排序。
φ(T) = 1 + 0.006·|T-25| + 0.00035·(T-25)**2 P = φ * (p[0] + p[1]*L + p[2]*u + p[3]*n) t = C / P band = 1.96 * sqrt( (C/P²·‖g·sd‖)² + (0.05·t)² )
自检三件套：① 拟合残差均值应接近 0、R² 稳定在 0.98 以上；② 四场景续航应随载荷单调递减（A > B > C）；③ 关掉时长抖动/噪声重跑，θ̂ 应逼近真值 [0.15, 1.35, 1.80, 1.10]。三条都过，模型才算站得住。

基线取场景 B（中度常规，7.85 h），逐条测算如下：

凸性结论：逐条增益 +1.25 h、+0.88 h 合计 +2.13 h，而联合实际 +2.46 h —— 因为 t = C/P 对功率 P 是凸函数，同时压低多项载荷的收益大于逐条收益之和。

这一条是论文的高光讨论点：若评委追问“为什么不是简单相加”，就用凸性 t''(P) > 0 回答——边际收益随功率下降而递减，组合优化天然优于单项累加。

八、灵敏度分析与温度结论（问题四）

以基线场景 B 为例，各系数 +10% 后复算续航变化：

系数扰动续航变化敏感度
a_s 亮度系数+10%−3.7%最高
a_c 负载系数+10%−3.1%高
a_n 网络系数+10%−2.2%中
P_base 静态底耗+10%−0.8%低

敏感度排序：a_s > a_c > a_n > P_base，即屏幕亮度是第一敏感因素。

温度结论：|T − 25| 每升高 5℃，φ 上升 3.9%，续航下降 3.7%。温度通过 φ(T) 整体缩放功率，偏离基准温度越远，续航衰减越快（平方项使高温端更陡）。

排序结论与工程直觉一致：最容易被用户主动调节、系数也最大的是屏幕亮度；而静态底耗属于“关机也在耗”的硬件开销，占比小、灵敏度低。

九、结论与注意事项

结论

  • 四问共用一套“SOC 线性下降 + 温度修正”骨架，参数辨识可完全线性化，模型简洁且可解释；
  • 辨识得 P_base = 0.15 W、a_s = 1.35 W、a_c = 1.80 W、a_n = 1.10 W，R² = 0.988、MAPE = 4.6%，精度满足工程预测；
  • 四场景续航 A 23.51 h / B 7.85 h / C 3.98 h / D 5.30 h，均附带 95% 置信带；
  • 三条建议分别增益 +16.0% / +11.2% / +9.5%，联合（亮度+网络）达 +31.3%，凸性使组合收益高于累加；
  • 敏感度排序 a_s > a_c > a_n > P_base，温度每偏 5℃ 续航约降 3.7%。

局限与改进

  • 整机平均功率按载荷线性叠加，忽略载荷间耦合（如高温加剧处理器降频）与动态瞬态，更精细可引入交叉项或状态相关系数；
  • φ(T) 采用对称二次型，低温柔性电池的强非线性未单独建模，可分段拟合；
  • 置信带仅含参数不确定度与 5% 载荷波动，未计入电池老化的容量衰减，长期预测需引入 SOH 折减。
