建立 SOC 连续时间模型：能量视角的四项耗电 从能量守恒出发：SOC 下降速率等于总放电功率除以电池额定能量；总功率由屏幕、处理器、网络三项耗电叠加，再乘温度修正因子 φ(T)。

连续时间 显式含 4 项 φ(T) 温度修正 最小二乘辨识

模型主式 问题一定式

dSOC/dt = −P_total(t,L,u,n,T) / C × 100% P_total = φ(T) · [ P_base + a_s·L + a_c·u + a_n·n ] /* L 亮度、u 负载、n 网络 均归一化 0～1 */

温度修正因子 容量衰减 + 内阻上升

φ(T) = 1 + 0.006·|T−25| + 0.00035·(T−25)^2 φ(25) = 1.000 φ(35) = 1.095 φ(−10) = 1.639 φ(40) = 1.169

高温与低温都会抬高 φ：低温可用容量骤减、内阻上升；高温副反应加剧，同样拉低有效容量。

为什么用二次型 建模动机

① 对称性：高温与低温都损害可用容量，故用 |T−25| 保证以 25 ℃ 为最优。

② 平滑放大：一次项刻画线性内阻上升，二次项刻画副反应/析锂的非线性加剧。

系数 0.006 与 0.00035 同样由附件 1 四个温度点的可用容量与瞬时功率辨识得到。

参数辨识 · 残差随迭代收敛

最小二乘辨识：残差逐轮收缩至 RMSE = 0.021 SOC 以 P_base、a_s、a_c、a_n 为待估参数，对附件 1 全量数据做最小二乘拟合；残差范数随迭代快速下降，数轮后进入平台，残余误差稳定在 2.1% 附近。

辨识要点 为什么能收敛

① 可控变量扫描：附件 1 固定单一变量，使各耗电项彼此可分离，避免参数耦合导致的病态。

② 三项线性可分离：屏幕、处理器、网络三项均为线性项（a_s·L + a_c·u + a_n·n，无幂次），各项贡献可直接分离，仅需辨识系数。

③ 温度正交：φ(T) 由四个温度点独立标定，与三变量扫描解耦，整体拟合稳定收敛。

模型检验 · 附件 1 拟合 + 附件 2 日志

拟合优度：R² = 0.988，日志 MAPE = 4.6% 模型在受控实验上 R² 高达 0.988；迁移到 20 名志愿者的真实日志，MAPE 仅 4.6%、最大瞬时偏差 0.083 SOC，说明模型具备跨工况泛化能力。
