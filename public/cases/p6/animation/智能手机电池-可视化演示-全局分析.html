2026 美赛 MCM A 题 · 全局分析

智能手机电池耗电建模：四因素 → 功率 → SOC → 续航 屏幕亮度 L、处理器负载 u、网络活动 n 共同决定基础功耗，环境温度 T 通过温度修正因子 φ(T) 放大或缩小整机功率；功率再决定 SOC 随时间下降的快慢，最终决定从满电到自动关机的可用时长。

全局 → 总结
全题主线：用附件 1 辨识四耗电项参数，用附件 2 检验精度；再以同一模型回答四场景续航预测（问题二）与三条优化建议（问题三）。核心参数：P_base = 0.15 W、a_s = 1.35 W、a_c = 1.80 W、a_n = 1.10 W、C = 15.4 Wh。
问题关系 · 一条主线层层递进

问题一 建模型 → 问题二 做预测 → 问题三 提建议 → 总结复盘 问题一给出模型与被辨识的参数；问题二在模型上做四场景外推并给 95% 置信区间；问题三再对模型做参数约束，量化优化收益；总结幕做灵敏度分析与结论清单。

问题一 辨识

建立 SOC 连续时间模型，显式含 L、u、n、T 四项；用附件 1 全量拟合辨识参数，用附件 2 检验精度。

输出：RMSE = 0.021 SOC、R² = 0.988；日志 MAPE = 4.6%。

问题二 预测

预测 A 轻度 / B 中度 / C 重度 / D 极端四场景从满电到自动关机的剩余可用时间，并给 95% 置信区间。

输出：23.51 / 7.85 / 3.98 / 5.30 h。

问题三 优化

给出亮度阈值、后台网络限制、温控散热三条建议，定量说明每条延长的续航与代价。

输出：以 B 场景 7.85 h 为基线，亮度 + 网络联合后 +31.3% → 10.30 h。

四问关系：模型是地基。问题二把模型外推到边界工况（含 φ(35)=1.095 的高温修正），问题三把模型当作约束优化的目标函数，总结幕再从参数灵敏度回看「哪个因素最值得约束」。
参数总览 · 最小二乘辨识结果

一套参数撑起全部结论 五个参数 + 一个温度修正因子构成本题全部数值结论的基础。

模型表达式 问题一采用的定式

dSOC/dt = −P_total(t,L,u,n,T) / C × 100% P_total = φ(T) · [ P_base + a_s·L + a_c·u + a_n·n ] φ(T) = 1 + 0.006·|T−25| + 0.00035·(T−25)^2

L、u、n 均为归一化 0～1；φ(T) 刻画高温/低温下可用容量衰减与内阻上升，T = 25 ℃ 时 φ = 1.000。
