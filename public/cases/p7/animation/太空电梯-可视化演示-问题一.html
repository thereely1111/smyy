2026 MCM Problem B · 问题一

双目标优化：最小成本 与 最小时间 2050 年月球殖民地 10 万人，需向月球运送 1 亿公吨（10⁸ 吨）物资；在成本-时间双目标下评估纯太空电梯、纯火箭、混合三方案，用 NSGA-II 求帕累托前沿。

双目标定义 min 同时

min C(M, t)　总成本 = 电梯子模型 + 火箭子模型

min t　完工时间 = 子模型容量上限倒数

约束：运送总量 M = 10⁸ 吨；电梯年容量 Cap_SE、火箭年发射次 N_re 各有上限。

双目标 NSGA-II 帕累托前沿 约束 M=10⁸t

问题一要求建立 cost-time 双目标优化模型，比较四种运输方案：纯太空电梯、纯火箭、混合最快 C1、混合最省 C2。求解工具为 NSGA-II 非支配排序遗传算法，输出帕累托前沿。
子模型 · 成本推导

两个子模型：电梯线性成本 与 火箭线性叠加 电梯：固定维护 + 按吨可变运费；火箭：单次发射成本 × 年发射次。混合方案 γ 在两者间线性配比。

电梯成本公式 C_SE

C_SE(t) = C_main · t + C_var · M /* 固定 + 可变 */ C_main = 10⁹ USD/年（缆索/配重维护） C_var = 2.2×10⁵ USD/吨（电力/损耗） Cap_SE = 5.37×10⁵ 吨/年 t_min = M / Cap_SE = 186.22 年

固定维护 C_main = 10⁹ USD/年 只贡献斜率（1 B/年），9805 B 的可变运费 几乎把曲线拉成水平线——电梯省不了多少钱，但能压低时间。

火箭成本公式 C_R

C_R(t) = C_r · N · t /* 单次 × 次数 × 年 */ C_r = 7.13×10⁷ USD/次 Cap_r = 2750 吨/次 N = 3641 次/年（工位约束） t_min = M / (N·Cap_r) = 183.14 年

单次便宜 C_r = 7.13×10⁷ USD，但 3641 次/年 × 183.14 年累计 ≈ 66.7 万次，对应总成本 ≈ 2.60×10⁴ B USD——快，但总量贵。

成本公式可视化：C_main·t（固定）+ C_var·M（可变）= C_SE 总成本
固定项 C_main·t 可变项 C_var·M 总成本 C_SE 容量约束 t_min

可变项 C_var·M = 2.2×10⁵ × 10⁸ = 2.2×10¹³ USD = 22000 B 占绝对主体；固定项 C_main·t 仅 ~186 B。所以电梯总成本 ≈ 9991.2 B USD，几乎不随时间变化。

混合方案成本 = γ · C_SE(t) + (1−γ) · C_R(t)；混合容量 = γ · Cap_SE + (1−γ) · N · Cap_r。γ ∈ [0,1] 把慢而省的电梯与快而贵的火箭按任意比例配比，从而在 C-t 平面上铺出连续折中曲线。
Pareto Frontier · NSGA-II

帕累托前沿：混合方案支配纯方案 四方案点画在 C-t 平面：C1 占时间最短端、C2 占成本最低端，二者连线即前沿；纯电梯与纯火箭都落在前沿上方、被混合支配。

成本-时间平面：四方案散点 + 帕累托前沿（C1 → C2）
混合 C1（前沿·最快） 混合 C2（前沿·最省） 纯电梯（被支配） 纯火箭（被支配） 帕累托前沿 NSGA-II 种群

C1(93.74 年, 9052.9 B) 与 C2(250 年, 2151.5 B) 连成前沿：两者互不支配——C1 更快但更贵，C2 更省但更慢。纯电梯(186.22, 9991.2) 被 C1 支配（C1 更快且更省）；纯火箭(183.14, ≈2.60×10⁴) 同样被 C1 支配。两个纯方案都落在前沿上方而被淘汰。

NSGA-II 流程 非支配排序

① 初始化种群→ ② 非支配排序→ ③ 拥挤度
④ 锦标赛+交叉→ ⑤ 精英保留→ 迭代至收敛

拥挤度保证前沿分布均匀，是双目标求解的标准算法。种群沿前沿抖动并最终收敛到 C1↔C2 连线附近。

被支配判定 dominance

方案 A 支配 B ⟺ A 在 C 与 t 上都不劣于 B，且至少一项严格更优。

C1 vs 纯电梯 C1：93.74 < 186.22 且 9052.9 < 9991.2 → C1 支配

C1 vs 纯火箭 C1：93.74 < 183.14 且 9052.9 < 25960 → C1 支配

C1 vs C2 C1 更快但更贵 → 互不支配（同在前沿）

方案对比 · 四方案汇总

四方案对比：成本柱 与 时间柱 把四个方案的 C 与 t 并排画成柱状图，按归一化高度直接读出谁最快、谁最省——以及两个被支配的纯方案在两项上都不占优。

关键洞察 双目标权衡

① 电梯的9805 B 可变运费占比 98%+，固定项几乎可忽略。

② 火箭单次便宜、总量很贵：3641 次/年 × 183 年 ≈ 66.7 万次。

③ 混合方案通过 γ 配比，能到达纯方案够不到的前沿段。

④ 决策者按预算/工期在 C1↔C2 前沿上任取折中点。

模型结构 NSGA-II 输出

min C = γ·C_SE + (1−γ)·C_R min t = M / (γ·Cap_SE + (1−γ)·N·Cap_r) s.t. 0 ≤ γ ≤ 1, M = 10⁸ t // 帕累托前沿：C1 ↔ C2 连线 C1 = (93.74 yr, 9052.9 B) γ 中-高 C2 = (250.0 yr, 2151.5 B) γ 中-低
