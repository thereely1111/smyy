一、题目重述与信息结构

某公司 2025 年在搜索引擎投放 SEM 广告，素材组织为推广单元 × 关键词 × 出价三层。附件给出三张表：附件1 为推广单元与关键词的基础信息，附件2 为全年逐日投放日志（展现 / 点击 / 消费 / 转化），附件3 为关键词分类指标。需在预算约束下给出选词、出价与投放节奏的最优策略。

四个问题的递进，本质是决策粒度与不确定性不同：

  • 问题一：检验原投放策略合理性，识别效益时间规律与星期规律 → 描述性诊断；
  • 问题二：按四象限把关键词分为黄金 / 重点 / 潜力 / 问题四类 → 分类治理；
  • 问题三：建立推广单元级投放模型，做选词与预算再分配 → 单元级最优；
  • 问题四：在不确定性下给出六项指标的期望范围 → 风险约束下的决策。

规模核对：全年 7726 个推广单元，5 个方案下共 12 个推广单元参与择优；预算上限取 2025 实测值，因此问题三是「再分配」而非「追加预算」。

写这一步的关键是画出「三附件 × 四问」对应矩阵：哪张表答哪一问、缺什么字段、要做什么预处理。评委一眼就能看出是否理清了数据结构。

二、数据预处理与探索性分析

预处理建议：

  • 字段对齐：把附件2 的逐日日志按推广单元 × 关键词 × 日期拼成主表，与附件1 的出价、附件3 的指标做 join；
  • 缺测与异常：消费为 0 但点击 > 0 的记录按同单元同星期插值；转化漏斗顶端为 0 的关键词单独标记，不参与均值；
  • 星期规律：效益（转化 / 消费）按星期分层，周一至周四一类、周五一类、周末一类，三类差异显著；
  • 时间规律：效益在一天内呈「双峰」（上午 9–11、晚间 20–22），投放节奏应随峰调整。
效益率 = 转化量 / 消费量　；　点击率 = 点击量 / 展现量

探索阶段至少产出三张图：全年日效益热力图、星期 × 时段效益矩阵、四象限分类散点（横轴消费、纵轴转化）。

红线：分类阈值只能用历史数据标定，任何「用当天转化给当天分类」的做法都属于数据穿越，会被直接判为无效。

三、效益指标与饱和响应函数

效益指标体系把原始投放量折成可比的效益分数：

  • 展现 → 点击：点击率；
  • 点击 → 转化：转化率；
  • 转化 / 消费：效益率（ROI 的倒数口径）。

关键词出价 B 与获得流量呈饱和型关系：低出价段近似线性上升，超过拐点后边际递减，最终趋于上限。

f(B) = A · B / (B + τ)　；　f′(B) = A · τ / (B + τ)²

τ 为半饱和出价（f = A/2 处的 B 值），A 为流量上限。参数由历史同单元同档位数据拟合；拟合时以残差平方和为目标，对 τ 施加非负约束。

饱和型而非线性型的关键意义：高回报关键词优先填到拐点，超过拐点后再投不如把预算转给其他单元 —— 这是问题三预算再分配的依据。

四、从问题一到问题四的模型升级路径

问题一：策略合理性诊断

不用建最优模型，只检验原策略：按效益率排序，看头部关键词是否拿到匹配预算、尾部是否还在浪费。效益时间规律与星期规律用同期均值对比即可。

问题二：关键词四象限分类

以消费为横轴、转化为纵轴（或效益率为纵轴），用双阈值把关键词分入四类：

  • 黄金词：高消费高转化 → 维持；
  • 重点词：低消费高转化 → 加预算；
  • 潜力词：低消费低转化但点击率尚可 → 择机承接；
  • 问题词：高消费低转化 → 释放预算。

阈值用历史数据分位数标定，并做 ±10% 扰动检验稳健性。

问题三：单元级投放模型

在预算上限（= 2025 实测）约束下，求各推广单元的出价与预算分配最大化总期望转化：

max　Σ_u A_u · B_u / (B_u + τ_u)　s.t.　Σ_u B_u ≤ B_total,　B_u ≥ 0

由 KKT 条件，最优解满足「各单元边际效益相等」：A_u · τ_u / (B_u + τ_u)² = λ（公共 λ）。预算转移规则：问题词释放 → 重点词承接 + 潜力词择机承接，总量守恒。

问题四：不确定性下的决策

把 A_u、τ_u 视为随机变量，用 CVaR 约束给出六项指标（总展现 / 总点击 / 总消费 / 总转化 / 效益率 / 紧急购流量级）在置信水平下的期望范围，并以区间形式交付。

五、结果与灵敏度分析

分类阈值 ±10% 扰动下，四类关键词的成员变动不超过 8%，说明阈值稳健；单元级再分配后总期望转化相对原策略有提升，问题词预算占比明显下降。

值得写进论文的几个灵敏度结论：

  • 半饱和出价 τ：τ 偏大时最优解更「平均」，τ 偏小时更「集中」—— 预算集中度对 τ 敏感；
  • 预算上限：再分配在「上限 = 2025 实测」下成立，若上限上浮 10%，增量预算优先填重点词而非黄金词（黄金词已近饱和）；
  • CVaR 置信水平：从 90% 提到 95%，六项指标区间展宽，效益率下界明显下移 —— 说明尾部风险主要来自效益端而非消费端。
最后一条是很好的创新点：它把不确定性的量级定位在效益端，而不是简单地说「总预算有风险」。

六、模型评价与论文写作要点

优点

  • 四个问题共用一套「效益指标 + 饱和响应」骨架，只改粒度与约束，论文结构紧凑、代码可复用；
  • 问题三给出 KKT 解析条件，把「预算再分配」从启发式升级为可解释的最优性条件；
  • 问题四用 CVaR 而非均值，区间交付贴合题面要求。

局限与改进

  • 饱和响应参数 τ 用历史均值拟合，未考虑竞争环境动态变化；下一步可用贝叶斯方法在线更新；
  • 四象限分类为静态，未刻画关键词类别的迁移；可引入马尔可夫转移；
  • CVaR 假设指标近似正态，重尾时需换经验分布。
论文结构建议：摘要（务必写六项指标区间）→ 问题重述 → 假设与符号说明（记得补"单位"列）→ 数据分析 → 问题一～四模型与求解 → 灵敏度与稳健性 → 结论 → 参考文献 → 附录（代码 + result1.xlsx ～ result4.xlsx 文件说明）。
