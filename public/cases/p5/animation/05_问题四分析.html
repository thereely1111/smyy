问题四 · 不确定性的量级

2026 年预算不增，且关键指标每日波动 先量出波动有多大，再决定用期望还是用最坏情形做决策。

题面设定 2026 年沿用 2025 年的方案与关键词，预算不超过 2025 年；但竞价、展现量、展现位、点击量、浏览量、注册量每日不确定。不确定性本身没有给分布，只能用 2025 年的历史波动刻画其量级。

建模路径 不确定性的三种处理方式

# A · 随机规划（SP）：假定分布已知 max E_ξ[ f(x, ξ) ] s.t. P( g(x, ξ) ≤ 0 ) ≥ 1 − α # 机会约束 # B · 鲁棒优化（RO）：不假定分布，只假定集合 max min_{ξ ∈ U} f(x, ξ) s.t. g(x, ξ) ≤ 0 ∀ ξ ∈ U # 集合内全部满足 # C · 分布鲁棒（DRO）：介于两者之间 max inf_{P ∈ 𝓓} E_P[ f(x, ξ) ] 𝓓 = { P : d(P, P̂) ≤ ε } # 经验分布邻域 # 求解：样本平均近似（SAA） max (1/N)·Σ_n f(x, ξ_n) # ξ_n 抽样自 P̂
