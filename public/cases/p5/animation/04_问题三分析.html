问题三 · 推广单元级投放模型

在预算约束下为每个单元选词 约束来自题面，选词依据来自问题2 的分类，窗口数据来自附件1 的对应日期。

题面要求在「低成本、高效益、完成但不超过预算资金」的条件下，为每个推广单元建立投放模型，并给出 2 月 1–8 日与 8 月 1–8 日两个窗口的最优策略。采用「推广单元日级时序＋关键词年度画像」层次预测框架：以单元层逐日时序刻画窗口节奏，以关键词年度画像确定选词优先级。下面给出模型结构与约束来源，窗口实算数据见下一幕。

模型结构 0-1 规划 + 预算约束

# 决策变量 x(i,j) ∈ {0,1} 关键词 j 是否进入推广单元 i y(i) ≥ 0 推广单元 i 分得的预算 # 目标：低成本 与 高效益（双目标） min C = Σ 消费额(j)·x(i,j) max B = Σ 有效访问(j)·x(i,j) 有效访问(j) = 点击量(j)·(1−跳出率(j)) # derived # 约束 (1) Σ_i Σ_j 消费额(j)·x(i,j) ≤ 总预算 # 全局上限 (2) Σ_j 消费额(j)·x(i,j) ≤ y(i) ∀i # 单元预算 (3) Σ_i y(i) ≤ 总预算 # 单元之和不超全局 (4) x(i,j) = 0 ∀j ∈ 无效词 # 强制剔除 (5) Σ_j x(i,j) ≥ 1 ∀i # 单元不得为空 (6) x(i,j) ≤ 归属(i,j) # 只能投已有归属
约束 (6) 常被忽略：Sheet3 已给出词与单元的归属关系，关键词并不能自由分配到任意单元。这一条把可行域从 个「词 × 单元」组合压到 个实际存在的组合，变量规模缩减 倍。

类型筛选规则

策略一栏为按分类语义直接得到的操作方向，不涉及未核算的收益预测。

双目标如何处理 标量化

「低成本」与「高效益」是两个方向相反的目标，不存在同时最优的单点，只有有效前沿。两条处置路径：

# 路径 A：ε-约束法 min C s.t. B ≥ B₀ # 效益不低于阈值 # 扫描 B₀ 得整条前沿 # 路径 B：加权标量化（本演示采用） min Z = C − λ·B λ ≡ 单位效益的影子价格（元/有效访问）

路径 B 的关键是 λ 不能拍脑袋定。本演示直接取各类词实测的单位有效访问成本作为 λ：把效益折算到与成本相同的量纲上，目标函数即变成「净成本最小化」，无需引入任何主观权重。

λ 越小表示该类词买有效访问越便宜，在目标函数中越应被优先装入。无效词的 λ 无定义（全年零消耗零点击），由约束 (4) 直接剔除。

求解规模与算法选择

0-1 规划属 NP-hard，但本例的约束矩阵极度稀疏：每个词只出现在 个以内的单元中，可行组合仅 个。这一结构决定了不必上通用求解器也能得到高质量解。

# 贪心：按 λ 升序装入，直到预算耗尽 排序 j : λ(j) 升序 → 依次取 x=1 直至 Σ 消费 = 总预算 # 质量评估：对预算约束做拉格朗日松弛 L(μ) = min Σ (消费额(j) − λ(j)·有效访问(j) + μ·消费额(j))·x 下界 = max_μ L(μ)，与贪心解比较即得间隙
在「单位成本不随投入规模变化」的假设下，该问题是分数背包，贪心即最优；取整后与最优解的间隙有界，可用拉格朗日下界实测。实际投放存在竞价抬升与流量上限，本演示不假装该假设成立——下一幕的滑块会把它放开检验。

两层预算优化结构 单元间 → 单元内

隐患提示：Sheet3 只有全年汇总，不能直接给每个关键词拟合「每日投入—点击—注册响应函数」，数据没有这个时间维度。

把预算决策拆成两层，分别使用不同时间粒度的数据：

# 第一层：12 个推广单元间分预算 Σ_u y(u) ≤ B_total max Σ_u F_u(y(u)) # Sheet1 有 365 天日级数据，可可靠研究"单元在不同投入 # 水平下获得多少点击/注册效益"，建立边际收益递减响应 # 第二层：单元内关键词分配 Σ_j 消费额(j)·x(u,j) ≤ y(u) ∀u # 依据问题二分类： # 黄金词 优先获核心预算 # 重点词 主投但控 CPC/ROI # 潜力词 保留探索资金 # 问题词 压缩 # 无效词 停止
两层结构把「数据有支撑的单元级投入—效益关系」与「分类语义驱动的选词优先级」分开建模：第一层用日级数据拟合响应，第二层用问题二的分类结果作约束。

饱和型响应函数 边际收益递减

每个单元的「预算—效益」关系用饱和型函数刻画，随投入增加边际收益递减并趋近上限：

F_u(B) = A_u × [1 − exp(−B / τ_u)] # B 单元预算 # A_u 潜在流量/效益上限 # τ_u 达到饱和的速度

实际优化推荐用分段线性区间逼近，保持模型易求解。

A_u 与 τ_u 由 Sheet1 各单元的日级投入—点击—注册观测拟合；分段线性近似的拐点取自实测曲率，避免非线性规划带来的求解器依赖。

函数特性：投入 B→0 时 F_u ≈ A_u·B/τ_u（线性段，边际收益近似为 A_u/τ_u）；B→∞ 时 F_u → A_u（饱和段，边际收益趋零）。τ_u 越小越早饱和，A_u 越大天花板越高。

  • 线性段（B ≪ τ_u）：每追加 1 元预算换回约 A_u/τ_u 的效益，是高回报区间，优先把预算填到这里。
  • 拐点（B ≈ τ_u）：边际收益开始递减，分段线性近似在此设第一拐点，之后斜率下调。
  • 饱和段（B ≫ τ_u）：追加预算几乎不增效益，再投不如把余量转给其他单元。

参数 A_u、τ_u 由各单元日级观测做非线性最小二乘拟合；分段线性的拐点取实测曲率最大的两点，使模型在预算约束下可直接走 MILP 求解，不引入非线性求解器依赖。

问题三 · 单元级选词与预算再分配

预算不增的前提下，钱从哪来、到哪去 题面的约束是「完成但不超过预算资金」，因此模型的核心是再分配而不是追加。

2025 年实际投入 元，构成 2026 年的预算上限。把预算从单位成本高的类别转移到单位成本低的类别，是本模型唯一的增效来源。

预算约束的来源 公平可复现的回溯口径

题面要求「不超过预算资金」但附件没有给出 2 月 1–8 日、8 月 1–8 日专门的每日预算表。不能随便设「每天 10000 元」之类的口径。

采用公平可复现的回溯口径：用 2025 年对应日期的实际投入作为预算上限。

这一口径与上一幕的预算上限一致：全年的总预算来自 2025 全年实际投入，两个窗口的逐日预算上限则取 2025 年同日的实测消费额。这样不引入任何主观假设，且可直接由附件复算。

各类词的处置与预算流向

处置方向由类别语义与单位成本排序直接得到；预算流向描述资金在类别之间的转移，总量不变。
问题词·释放 → 重点词·承接 ＋ 潜力词·择机承接

预算在类别间转移、总量守恒：问题词释放多少，重点词与潜力词承接多少，差额为零。流向方向由各类单位有效访问成本的排序唯一决定，不引入主观权重。

  • 黄金词：高效益低成本区间，优先买入至承接容量上限，只承接不释放。
  • 重点词：效益稳定、承接空间最大，是再分配的主力承接方。
  • 潜力词：效益待释放，作为承接方的补充，择机承接。
  • 问题词：单位成本偏高、有效访问偏低，是预算的唯一释放源。
  • 无效词：零有效访问，剔除出投放列表，不进入再分配。
为何是再分配而非追加：题面约束为「完成但不超过预算资金」，2025 年实测投入即构成 2026 年的预算上限，无增量预算可花。故增效的唯一路径是把高单位成本类别的预算转移到低单位成本类别——总量不变、只动结构。
边界条件：问题词释放额以其全年消费额为上限；承接方按单位成本由低到高依次填入，至容量拐点后转入次优类；若仍有余量则留作储备而非强行花完，避免在饱和段低效消耗。
