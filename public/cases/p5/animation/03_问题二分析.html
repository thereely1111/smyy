问题二 · 关键词分类

按「成本 × 效益」两维归类 题面给了维度，没给分界。分界是建模选择，不是题面事实，因此必须说明理由并做稳健性检验。

完整效益链条为「曝光—点击—浏览—注册—成本」，其中点击量是关键词层级唯一可逐词核算的效益口径；注册量仅在单元层汇总，需由单元层注册贡献向关键词层归因。Sheet3 共 2227 条关键词—单元记录、1884 个不同关键词，其中 890 条为零消费零点击（对应 701 个不同无效词）。分界不用中位数——本数据的消费额与点击量都呈幂律，成本中位数仅 元、点击中位数仅 次，中位数切分会把全部消费额塞进同一类。改用帕累托累计 80%，即 ABC 分类中的 A 档。零成本零效益者单独归为无效词。

两级层次归因：单元层回归 + 单元内按质量分摊 注册量只在单元层汇总

关键词层只有点击量可逐词核算，注册量只在 12 个推广单元的日级汇总里出现，因此用「单元层回归归因 + 单元内按质量分摊」两级层次归因把注册效益落到关键词。拆出来的是估计注册贡献（注册效益代理），不是真实注册数。

第一级 · 12 推广单元对每日注册的相对贡献
min Σ_d (R_d − α − Σ_u β_u·X_(d,u) − TimeControl_d)² + λ·Σ_u β_u² s.t. β_u ≥ 0 (非负约束)

用带非负约束的岭回归 / Elastic Net求解。X_(d,u) 为第 u 个单元第 d 天的标准化有效点击或消费；R_d 为第 d 天全单元合计注册量；TimeControl_d 为趋势/星期/节假日等时间控制项；β_u 即单元 u 对每日注册的相对贡献权重。

第二级 · 关键词质量权重在单元内归一化分摊
Reg_k = Reg_u × q_k / Σ_(j∈u) q_j q_k = 点击量 × 访问质量 访问质量 = f(浏览量, 1−跳出率, ln(访问时长))

q_k 在同一单元内归一化分摊，得到关键词 k 的估计注册贡献 Reg_k。访问质量由浏览量、（1−跳出率）、对数访问时长综合度量。

成本维度双口径：总消费额 + CPC 避免把高效核心词误判为问题词

成本不只看总消费额：高搜索量词天然点击更多、消费更高，只按总消费排序会把高效核心词误判为「高成本问题词」。成本项加入 CPC 后再做标准化：

Cost_k = w1·Z[log(1+Spend_k)] + w2·Z[log(1+CPC_k)] # Z[·] 为稳健标准化；w1、w2 为可调权重（默认等权）

这样既保留消费规模信息，又用单位点击成本修正搜索量带来的规模偏置，避免核心词被误分类。

问题二 · 阈值稳健性

换一档阈值，结论还站得住吗 帕累托比例从 60% 到 95% 共 8 档全部算一遍，看哪些结论随阈值摆动。

分界参数只要是人选的，就必须回答一个问题：结论是不是只在某一档上成立。下表把 8 档阈值的分类结果并排列出，单元格上排为词数、下排为单位成本（元/有效访问）。

八档阈值的分类结果与排序检验

「完整排序」指单位成本满足 黄金 < 重点 < 潜力 < 问题。出现倒挂的档位均由样本极小的黄金词与问题词引起——两类词数合计在全部 8 档中只有 个，单个词的成本波动就能翻转均值。

各类的词数与单位成本区间

稳健的部分：无效词恒为 个，与阈值无关；重点词与潜力词的词数与单位成本区间连续变化，没有跳变。不稳健的部分：黄金词在 8 档中只有 个，其加权跳出率在 之间大幅波动，因此黄金词的质量指标不能作为头条结论，只能作为参考。

稳健全分类的处理细节 先变换、再稳健标准化、再灵敏度复核

① 对数变换 + 中位数/MAD 稳健标准化

消费额、点击量呈幂律，先做 log(1+x) 变换压缩长尾，再用中位数和 MAD（中位绝对偏差）做稳健标准化，避免均值/方差被极端值拉偏。

Z(x) = ( log(1+x) − Median ) / ( 1.4826·MAD )
② 分位基准 + 灵敏度复核

以中位数四象限为基准分类，再用 40% / 50% / 60% 分位数重新分类做灵敏度分析，看每个词在多档分位下是否稳定落同一类。

词的稳定性判定：始终落在同一类的词定为核心词（结论可信）；频繁跨越类别边界的词定为待观察词（不进头条结论，需更多数据再判）。这样可避免因阈值微调导致关键词类别翻转、结论不稳。
由此确定交付口径：问题3 的投放优先级以重点词、潜力词、问题词三类的排序为准；黄金词因样本量不足，只标注其存在与量级，不引用其质量指标做定量推断。

注意事项：两个易踩的坑 落地前必看

坑一 · 「/」形式的跳出率不能直接填 0

原始数据中无访问的关键词，跳出率常以「/」占位。若直接当 0 处理，会把无流量词误认为「跳出率 0% 的极品词」，污染黄金词判定。应先按是否有点击/访问过滤，「/」统一记为缺失，不参与质量指标计算。

坑二 · 同编号关键词跨单元不能合并

分类对象是「方案—推广单元—关键词」三元组，同一关键词文本出现在多个推广单元时不能合并：各单元的点击、消费、跳出率独立核算，分属不同行。result2 的序号也是单元内独立编号，跨单元同名词应保留为多条记录。
