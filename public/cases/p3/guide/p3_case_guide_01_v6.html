微网与外部电网的电力调控策略

2026 国赛 C 题 · 实训指导书

1. 题目重述与信息结构

一、题目重述与信息结构

某小区建有微网，内部含光伏电站与储能电站，并与外部电网相连。每日 0:00 需制定当天 144 个时段（10 min/段）的计划购电曲线，全天结束后储能荷电状态须回到初始值。

四个问题的差别，本质上是决策时可获得的信息不同：

  • 问题一：电价、负载、光伏全部已知 → 纯确定性优化，是后面三问的基准；
  • 问题二：电价确定，负载与光伏当天未知 → 需要预测，缺口按 5 倍电价紧急购电；
  • 问题三：增加 0:00 / 6:00 / 12:00 / 18:00 四次光伏预报 → 可以中途修正计划，但要付偏差成本（低于计划部分 50%，高于计划部分 1.5 倍）；
  • 问题四：外网电价实时波动且与供电缺口相关 → 重算问题二、三。

储能关键参数（附录1）：容量 12000 kWh，最大充放功率 5000 kW（单时段 ≤ 833.33 kWh），初始 / 0:00 储电量 6000 kWh，运行区间 [1200, 10800] kWh，充放电效率 90%。

写这一步的关键是画出一张"信息时序图"：每个时刻你知道什么、不知道什么、能改什么。评委一眼就能看出你是否理解了四个问题的递进关系。

2. 数据预处理与探索性分析

二、数据预处理与探索性分析

附件2 给出 2025-01-01 至 12-31 共 365 天 × 144 时段的负载与光伏真值，附件1 给出典型日的电价与光伏预测值。预处理建议：

  • 日历对齐：把每个时段映射为 (年, 月, 日, 时段序号)，并生成星期标签；
  • 缺测与异常：用同星期类型的邻近时段插值；光伏夜间恒为 0，不要当成缺失值；
  • 星期分层：负载天然分成两类 —— 周五/周六一类，周日至周四一类，两类均值差异显著，分开建模可明显降低预测误差；
  • 季节性：光伏出力随月份呈明显起伏，冬夏差可达数倍。
MAPE = (1/n)·Σ |y − ŷ| / y × 100%

探索阶段至少产出三张图：典型日（春分 / 夏至 / 秋分 / 冬至）负载与光伏曲线、全年日总电量热力图、分时电价阶梯图。

红线：预测时只能用当天 0:00 之前的信息，任何"用了当天真值"的做法都属于数据穿越，会被直接判为无效。

3. 模型骨架：单日 MILP

三、四个问题共用的 MILP 骨架

决策变量（t = 1…144）：

  • g_t —— 第 t 时段从外网计划购入的电量（kWh）；
  • c_t / d_t —— 储能充电量 / 放电量（kWh）；
  • S_t —— 时段末储电量（kWh）；
  • u_t ∈ {0,1} —— 第 t 时段储能是否处于充电状态。
min　Σ_t p_t · g_t s.t.　g_t + d_t + PV_t = L_t + c_t　　　　 (功率平衡) 　　　S_t = S_{t−1} + c_t − d_t / η　　　　 (储能递推, η = 0.9) 　　　1200 ≤ S_t ≤ 10800,　S_0 = S_144 = 6000 　　　c_t ≤ 833.33·u_t,　d_t ≤ 833.33·(1 − u_t) (充放互斥)

最后一行是本题最容易被忽略的约束。若不加 0-1 变量（或等价的 Big-M / 互补约束），求解器会得到"同一时段既充又放"的假最优解，因为充放效率差会让能量在纸面上凭空增值。

灵敏度好素材：改变 S_min（1200 → 1500 kWh）后总费用只上升约 0.35%，说明运行区间下界不是敏感参数；而效率的写法（单侧折算 vs 双侧开方）对结果的影响明显更大。

4. 从问题一到问题四的升级

四、从问题一到问题四的模型升级路径

问题二：预测 + 安全裕量

负载用随机森林（输入为 Lag-1…Lag-7 同 时段值、时段序号、星期类别），光伏用近 3 日同 时段滑动平均。训练按月滚动，只用历史数据。关键是引入安全裕量系数 α：把预测负载上抬 α 后再做计划，用"多买一点"的确定性成本去对冲"缺口按 5 倍结算"的风险。

L̂_t = (1 + α) · L_pred,t

α 需要在网格上搜索：太小则紧急购电频繁，太大则日常浪费，全年总费用对 α 呈明显的 U 型曲线。本题最优取 α = 0.02。

问题三：多阶段滚动 + 双向违约

每次预报到手后重新优化剩余时段。若新方案带来的期望节省小于设定阈值 θ，则维持原计划不变，避免"为了修正而修正"。实际与计划的偏差按规则双向结算：

费用 = Σ p_t·g_t^计划 + 0.5·Σ p_t·(g_t^计划 − g_t^实际)⁺ + 1.5·Σ p_t·(g_t^实际 − g_t^计划)⁺ + 5·Σ p_t·e_t

问题四：电价不确定

电价不再是固定的分时表，而是随时间波动的随机变量，且与系统供电缺口正相关。应对办法是先按峰谷平与缺口水平分层做电价预测，再把不确定电价作为输入重算问题二、三。

5. 结果、灵敏度与稳健性

五、结果与灵敏度分析

四个问题的参考结果（报告区间 2025-02-01 至 12-31，共 334 天）：

问题场景关键结果
问题一确定信息 · 单日购电量 59482.70 kWh / 费用 35126.95 元
问题二负载光伏未知 · 全年1369.18 万元，紧急购电占 6.0%（α = 0.02）
问题三四次光伏预报1535.07 万元，紧急购电降至 1.31%
问题四-2电价波动 · 重算问题二1471.70 万元
问题四-3电价波动 · 重算问题三1787.47 万元

值得写进论文的几个灵敏度结论：

  • 是否引入 0:00 之外的预报时刻：逐个加入后总费用单调下降但边际收益递减，说明引入是有必要的，但不必追求更多时刻；
  • 紧急购电倍数从 3 增到 10，全年总费用近似线性上升（约 1535 → 1740 万元）—— 阶段一求解不依赖紧急购电价格，价格只影响最终结算；
  • 波动电价下把安全裕量提高到 α = 0.05，紧急购电量确实大幅下降，但全年总费用反而回升到 1827.27 万元 —— 因为超取部分要按 1.5 倍结算，"多买"同样是成本。这说明最优安全裕量取决于结算规则本身，不是一个固定经验值。
最后一条是很好的创新点：它说明"最优安全裕量"依赖于结算规则本身，而不是一个固定经验值。很多论文只做到 α 网格搜索就停了。

6. 模型评价与论文写作

六、模型评价与论文写作要点

优点

  • 四个问题共用一个 MILP 骨架，只改输入与结算规则，论文结构紧凑、代码可复用；
  • 明确论证了"必须用预测值而不是真实值"：用真实数据回代时紧急购电恒为 0，机制失去意义 —— 这是很有说服力的反证检验；
  • 对照组包含拥有完美信息的三种启发式策略，检验严格。

局限与改进

  • 随机森林是点预测，未给出区间；下一步可用分位数回归 / LightGBM 输出预测分布，做随机规划或分布鲁棒优化；
  • 未考虑储能循环老化成本，容量衰减在长周期滚动中不可忽略；
  • 电价预测仅按峰谷平分层，未刻画缺口—电价之间的动态反馈。
论文结构建议：摘要（务必写关键数字）→ 问题重述 → 假设与符号说明（记得补"单位"列）→ 数据分析 → 问题一～四模型与求解 → 灵敏度与稳健性 → 结论 → 参考文献 → 附录（代码 + result1.xlsx ～ result4-3.xlsx 文件说明）。
