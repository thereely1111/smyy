# 数模演易案例预览图提示词模板

用于为首页轮播案例生成横向封面图。项目将图片放在 `public/hero-assets/`，案例数据通过 `coverImage` 字段引用。

## 可直接复用的通用提示词

将方括号内容替换成当前案例信息后，提交给 GPT Image 2：

```text
为数学建模案例生成一张简约、理性、具有学术科技感的横向预览封面插画。

案例主题：[案例主题]
核心对象：[题目中的物体、系统或场景]
主要建模关系：[关键变量、过程或约束，例如热量与水分扩散、供需调度、传播与干预]
可视化元素：[最多 2-3 个，选择曲线、网格、流线、节点、等值线、时间轴或简化图表]

构图要求：适用于宽幅横向网页卡片封面，画面主体集中在中央横向安全区域，左右边缘只放背景或辅助元素；缩放到约 300×110 像素仍能辨认主题。采用克制的编辑插画风格，结构清楚、留白充分、细节不过密。使用青绿、蓝青、墨色为主，可用少量暖琥珀色强调关键过程；背景干净、低对比，不要让装饰盖过主体。

禁止出现文字、字母、数字、公式、标签、坐标轴刻度、logo、水印、边框、人物或无关装饰。避免照片拼贴、卡通玩具感、过度复杂的仪表盘、密集网格和高饱和霓虹色。不要把关键主体放在四周或裁切边缘。
```

建议图像尺寸使用 `1536x1024`、质量 `high`。组件按横向比例裁切显示，因此提示词中的“中央横向安全区域”和“左右边缘留背景”很重要。

## 示例：中药材热风烘干

```text
为数学建模案例生成一张简约、理性、具有学术科技感的横向预览封面插画。

案例主题：中药材热风烘干过程的热湿耦合建模
核心对象：整齐摆放在干燥托盘上的圆柱形药材切片与根茎
主要建模关系：热量向药材内部传导、水分向外扩散、热风推动表面蒸发
可视化元素：柔和热流线、少量水分扩散等值线、简化的内部温度网格

构图要求：适用于宽幅横向网页卡片封面，药材和托盘位于画面中央横向安全区域；热风流线沿水平方向展开，关键药材主体不要靠近边缘。采用克制的编辑插画风格，青绿和蓝青为主，少量暖琥珀色表现热量。背景干净、留白充分，缩小后仍能看出药材烘干主题。

禁止出现文字、字母、数字、公式、logo、水印、边框、人物或无关装饰。避免照片拼贴、卡通玩具感、密集网格和过度复杂的仪表盘。
```

## 示例：微网电力调控

```text
为数学建模案例生成一张简约、理性、具有学术科技感的横向预览封面插画。

案例主题：微网与外部电网的电力调控策略
核心对象：社区微网中的光伏板、储能电池、用电建筑和外部电网连接
主要建模关系：光伏出力、储能充放电、分时负荷与电网购电之间的时序平衡
可视化元素：简洁能量流线、少量负荷曲线、清晰的节点连接

构图要求：适用于宽幅横向网页卡片封面，主要能源对象集中在画面中央横向安全区域，左右两端仅保留延伸的能量流线或淡化背景。采用克制的编辑插画风格，青绿、蓝青、墨色为主，少量暖琥珀色强调能量调度。留白充分，缩小后仍能辨认微网能源调度主题。

禁止出现文字、字母、数字、公式、logo、水印、边框、人物或无关装饰。避免密集电路板纹理、过度复杂的仪表盘、霓虹光效和写实照片。
```

## 生成后接入案例

1. 将生成的 PNG 文件放入 `public/hero-assets/`，文件名建议使用简短英文主题名，例如 `herb-drying-cover.png`。
2. 在 `src/legacy/prototype/core.ts` 对应的 `PROBLEMS` 项添加图片路径：

```ts
coverImage:'/hero-assets/herb-drying-cover.png'
```

3. 若没有 `coverImage`，卡片会继续使用默认渐变背景和图标；有图片时会自动铺满封面区域。
4. 在 `http://localhost:5181/` 刷新页面检查；确认图片主体没有被裁切后再提交。

## 视觉检查清单

- 缩小到轮播卡片大小时，仍能一眼看出案例主题。
- 关键对象位于中央横向安全区域，不贴边、不被裁切。
- 视觉元素与题目建模关系有关，不只是泛化的科技背景。
- 没有错误文字、伪公式、logo、水印或无关物体。
- 和其他案例封面保持克制、清晰、理性的整体气质。
