# 题目与附件盘点

## 输入
父任务注入的题干、附件清单、附件已读取内容/绝对路径和数据说明。绝对路径只按原样读取；不得遍历工作区猜测附件。

## 步骤
1. 列出每份输入的名称、类型、实际可读状态和内容覆盖范围。附件未读时标 `unread`，不可从文件名推断内容。
2. 将题面分为背景、研究对象、明确事实/数据、任务动词与输出、时间/空间范围、条件/约束、评价口径、格式/文件交付要求。
3. 对每条事实添加来源锚点：文件名及可用的页码、段落标题、表/字段或原文短定位；无法精确定位时说明锚点粒度。
4. 为含糊、冲突、缺失内容登记未知项、影响和是否阻断后续分析。
5. 严格区分 `explicit_fact`、`inference`、`proposed_assumption`、`unknown`。

## 输出与自检
输出 source inventory 和事实/未知项，供 problem_contract 使用。检查每一问均找到对应原文任务，附件状态真实；没有可追溯出处的内容不得标成题面事实。
