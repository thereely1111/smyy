# 数据需求与质量评估

## 步骤
1. 按题目和候选模型逐问列出所需数据、字段、时间/空间粒度、单位、样本范围和来源。
2. 分开记录 `available`、`described_but_unread`、`missing`；不得将计划收集的数据描述为已有数据。
3. 只基于已读取内容报告数据质量事实（如字段缺失、格式不明、单位冲突）；未读取原始数据时只可提出待检查风险。
4. 对每项预处理建议记录触发条件和影响：类型/单位标准化、缺失处理、异常核查、去重、插值/拟合/外推、参数标定、训练/验证切分等。
5. 不默认删除异常值；说明保留、纠错或剔除需依据及其对结论的敏感性。
6. 标注阻断路线选择或参数标定的关键缺失数据，并提出可向用户确认的具体问题。

## 输出与自检
输出逐问数据需求、可用性、质量评估、处理建议和风险。任何统计量必须来自实际可读取且已计算的数据；本 Skill 不执行代码或数据计算。
