## 论文初稿

论文题目；摘要（背景与总体思路，逐问方法/真实结果，已验证的检验与亮点）；关键词；一 问题重述（背景、提出）；二 问题分析（总体、逐问）；三 模型假设（逐问依据）；四 符号说明；五 模型的建立与求解（逐问数据预处理、模型建立含公式、求解步骤、结果分析及检验）；六 模型检验与灵敏度分析；七 模型评价、改进与推广；AI 工具使用声明；参考文献；附录 A 支撑材料文件列表；附录 B 全部真实可运行源程序。问数动态生成，不能按模板里的“三问”和样例程序名填假内容。

题面/模型路线可来自已核准分析，结果数值/图表/实算结论只准来自 S4 已核验用户运行回传的 claims.json，逐条留来源和单位。没有结果的摘要、第五六章写【待用户回传运行结果】，不得谎称已求得。附录 A 仅列真实文件（赛题原始数据不列）；附录 B 不得把 README 当源码或把未运行的代码写成已验证。只引用实际提供且经核查的文献。

纸质版 Word 模板包含承诺书、编号专用页、摘要页、正文和附录；电子版首页是摘要页，不应混入前两页。AI 工具使用声明位于参考文献之前；AI 使用详情需要记录真实工具名称/版本、用途环节、提示过程、人工采纳修改核验，不能自动替用户作真实声明。平台 DOCX 导出使用用户提供的模板资源作为电子稿来源，清空其示例正文与身份页，保留节设置但不能保证公式、图表、样式与封面完整复刻；提交前由用户检查摘要页、页码、公式、表图、身份信息、附录、源码、支撑材料与竞赛当年规则。
