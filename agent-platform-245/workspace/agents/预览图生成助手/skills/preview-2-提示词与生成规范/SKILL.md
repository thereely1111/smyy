# 提示词与生成规范

## 默认生成参数

- 尺寸：`1536x1024`；
- 格式：PNG；
- 质量：high；
- 方向：landscape；
- 文件名：短英文主题名 + `-cover-v<revision>.png`；
- 保存目录：父任务指定的 `asset_root`，本项目默认 `public/hero-assets/`。

## 提示词结构

输出 `preview_prompt.txt`，按以下顺序组织：

1. 说明这是数学建模案例的横向预览封面；
2. 写出案例主题和核心对象；
3. 写出主要建模关系，使用视觉过程表达，不写正式公式；
4. 指定 2-3 个可视化元素；
5. 规定中央横向安全区、左右留白、卡片缩小后的识别度；
6. 指定克制的学术编辑插画风格、色彩和背景；
7. 明确负面约束。

## 通用模板

```text
为数学建模案例生成一张简约、理性、具有学术科技感的横向预览封面插画。

案例主题：[title]
核心对象：[core_objects]
主要建模关系：[modeling_relations]
可视化元素：[visual_elements]

构图要求：适用于宽幅横向网页卡片封面，主体集中在中央横向安全区域，左右边缘只保留背景或辅助流线；缩小到约 300x110 像素仍能辨认主题。采用克制的编辑插画风格，背景干净，留白充分，细节不过密。

色彩要求：以青绿、蓝青、墨色为主，可用少量暖琥珀色强调关键过程。不要让装饰盖过主体。

禁止出现文字、字母、数字、公式、标签、坐标轴刻度、logo、水印、边框、人物或无关装饰。避免照片拼贴、卡通玩具感、过度复杂的仪表盘、密集网格和高饱和霓虹色。不要把关键主体放在四周或裁切边缘。
```

## 一致性规则

提示词只描述当前案例，不复制其他案例的核心对象。跨案例可复用的是构图、安全区、颜色控制和负面约束，而不是主体内容。若用户提供已有 `PROMPT_TEMPLATE.md`，优先保留其中的项目术语和尺寸约定。
