# 先导实战式 — 理论模块 + 章末小案例

适用：项目任务式

## 骨架结构

- 与单章案例式结构无异：第 1 章为理论章（工具/环境/理论概述），其余章每章一个章末案例
- 区别仅在于适用体例（项目任务式）与目录结构（标题不含案例名，案例为章末模块而非整章贯穿）
- 章节类型分布：第1章 `理论类`，其余章 `案例类`

## 标题格式

| 体例         | 格式                   |
| ------------ | ---------------------- |
| 项目任务式   | `第X章 XX知识主题`   |

- 章节标题仅为知识主题，**不附加案例名称**，无 `——` 分隔符
- 每章结构：前N个模块进行知识点讲解（配必要示例：抽象/操作/易混/后文案例依赖的知识点必配，简单概念可不配），最后1个模块综合本章知识点完成一个小案例或示例
- 无跨章案例依赖

## 案例规则

- 不要求章节标题含案例名，不要求章间案例依赖
- 章末案例须在章内形成领域流程闭环，覆盖本章知识点的完整阶段链
- 示例可自包含（常量、内置数据、模拟场景），不强制读取外部数据文件
- 跨章案例名不得重复

## 调度策略
 N 章并行（章间无跨章依赖）。
