# 项目式

> 适用：中职、高职

```
项目X  XX知识主题——XX案例名称
├── 【教学目标】
│   ├── 1．技能目标
│   ├── 2. 知识目标
│   └── 3．素养目标
├── 【项目描述】
│   ├── 1．项目背景
│   ├── 2. 项目目标
│   └── 3．项目分析
├── 【思维导图】
├── 【知识准备】                 （从项目引出知识点，知识准备 ≥ 项目实施知识点）
│   ├── X.1 二级标题A
│   │   ├── X.1.1 三级标题
│   │   │   ├── 1. 四级标题   （可选）
│   │   │   └── 2. 四级标题
│   │   └── X.1.2 三级标题
│   └── X.2 二级标题B
│       ├── X.2.1 三级标题
│       └── X.2.2 三级标题
├── 【项目实施】                 （基于知识准备实现项目目标）
│   ├── X.3 二级标题C
│   │   ├── X.3.1 三级标题
│   │   └── X.3.2 三级标题
│   └── X.4 二级标题D
│       ├── X.4.1 三级标题
│       └── X.4.2 三级标题
├── 【项目小结】  
├── 【实训】
├── 【课后习题】
│   ├── 1．选择题
│   ├── 2. 填空题
│   └── 3．实操题
└── 【阅读拓展】
```

## 标题级别对应

| 级别 | 编号格式  | Word 样式 | 说明                           |
| ---- | --------- | --------- | ------------------------------ |
| 一级 | `项目X` | 标题1     | 项目标题，含`——XX案例名称` |
| 二级 | `X.1`   | 标题2     | 知识准备/项目实施子标题        |
| 三级 | `X.1.1` | 标题3     | 知识点标题                     |
| 四级 | `1.`    | 标题4     | 可选，知识点子项细分           |

## 约束

知识准备下至少有两个及以上二级标题
