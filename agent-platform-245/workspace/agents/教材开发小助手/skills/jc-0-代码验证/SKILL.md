## 脚本

| 脚本                                                        | 用途                             |
| ----------------------------------------------------------- | -------------------------------- |
| `scripts/install.py <md文件路径>`                         | 扫描 import，安装缺失的第三方包  |
| `scripts/execute_code.py <md文件路径> [--img-dir <目录>]` | 执行 Python 代码块，插入运行结果 |

## 调用方式

通过 `execute_command` 执行：

```bash
python scripts/install.py <md文件路径>
python scripts/execute_code.py <md文件路径> --img-dir <图片目录>
```

## 执行流程

1. install.py → 扫描 `import`，安装缺失包
2. execute_code.py → 逐块执行 `` ```python `` 代码，自动插入：
   - 文本输出（print/DataFrame）→ 结果展示段落
   - matplotlib 图表 → 保存 PNG → `![]()` 引用
   - 执行失败 → 保留原代码，插入错误说明

## 本地化规范

调用方在编写代码时须遵守，确保代码可本地执行：

| 规范     | 规则                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 数据路径 | 指向`artifacts/{教材名称}/第X章_{标题}/数据/{数据集名}/`                       |
| 代码存储 | 每个代码块保存为独立文件`代码/{题注}.py`，如 `代码/代码1-1 缺失值处理.py` |
| 图片输出 | matplotlib 图表保存到`图片/` 目录                                           |
| 操作系统 | 路径使用`Path` / `os.path.join`，兼容 win11                               |

## 修复规范

execute_code.py 执行失败时的修复流程：

1. 读取报错信息，定位失败代码块
2. 修复代码（路径错误、语法错误、API 变更等），**修复不得引入本章知识点范围外的函数/方法**
3. 重新执行，最多 3 轮
4. 3 轮仍失败 → 保留错误标记，继续后续流程

## 约束

- 代码执行超时 30 秒
- matplotlib 图表分辨率 1080dpi
- 执行失败不阻塞，标记错误继续
- 修复不得超纲：不得使用知识点外的函数/方法/库
