## 输入上下文

- **导图组件**：导图（PNG 图片 + 引用的 Markdown）
- **章节目录**：当前章节标题树（`目录结构.json`）

> **路径（本 Skill 的输入/产出）**：**输入**文件路径由父编排在 task 中注入，是**绝对路径**（运行态根 + 产出方会话目录 + 相对路径），**原样使用**，**禁止**用相对路径去猜；**产出**一律用**相对路径**写在自己的会话空间（会话之间不共享目录），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）。完整规则见 `jc-0-路径工具`。

## 执行方式

**AI 读图审核**：导图产出为 PNG 图片，用 `read_image` 工具读取图片内容（把图片转成文字描述），核对导图内容与目录的对应关系。视觉属性（宽度、底色、留白、节点布局）与层级对应关系**由 `read_image` 读图完成**，不依赖脚本。

> 说明：格式类硬约束（PNG 格式、留白裁剪、宽度约束、字体、折行）已在 `jc-3-思维导图` 的 `render_mindmap.py` 生成阶段强制保证，本审核不重复检查，仅聚焦生成阶段无法自动保证的「与目录对应」。
>
> **视觉把关分工**：`read_image` 只做「内容对应」的文字判定（导图节点是否与目录/章节标题一致）。纯视觉审美（配色、留白、布局美感）属主观判断，AI 不给确定性结论，交由主编在闸门处看图定夺——本审核对视觉项只做「与目录对应」检查，不判美丑。

## 审核步骤

读取被审核文件实际内容及导图 PNG 图片，逐项审核：

### 1. 内容对应

- 第 1、2 级节点内容是否与教材的二级、三级标题对应
- 是否去除了「了解」「熟悉」「认识」「掌握」等动词前缀
- 层级（展开深度）是否与目录一致（目录含 H4 时导图也应展开到 H4）

### 2. 格式规范

- 图片格式：PNG 或 JPG（不能是 SVG）
- 底色尽量浅
- 整体宽度尽量缩小，无过宽/过扁
- 思维导图顺序全书统一（统一逆时针或顺时针）
- 左右两边如有空白需裁剪掉

## 输出格式

```
[审核结果] 通过 / 不通过

## 通过项
（列出所有通过的检查项）

## 不通过项
（每项注明具体位置、问题描述、修改建议）
```
