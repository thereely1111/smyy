## 输入上下文

- Markdown 文件路径（任意格式）
- 【章编号】：用于题注编号（X-N格式），非教材场景可传0
- 【版本号】：v{N}.{retry}，可选

> **路径（本 Skill 的输入/产出）**：**输入**文件路径由父编排在 task 中注入，是**绝对路径**（运行态根 + 产出方会话目录 + 相对路径），**原样使用**，**禁止**用相对路径去猜；**产出**一律用**相对路径**写在自己的会话空间（会话之间不共享目录），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）。完整规则见 `jc-0-路径工具`。

## 依赖安装

```bash
python scripts/install.py   # 自动检测并安装 python-docx / latex2mathml / lxml，已存在则跳过
```

> 未安装公式依赖（`latex2mathml` + `lxml`）时，公式降级为纯文本显示，不影响其他功能。

## 执行方式

```bash
python scripts/md2docx.py <md文件路径> <章编号> <版本号> [输出目录]
```

示例：

```bash
python scripts/md2docx.py 第3章.md 3 1.0
python scripts/md2docx.py README.md 0 1.0 ./output
```

## 支持格式

| 元素           | 支持                                                                            |
| -------------- | ------------------------------------------------------------------------------- |
| 标题           | `#` ~ `####`，使用模板 `Heading 1~4` 样式                                     |
| 正文           | 模板 `书写正文` 样式                                                           |
| 代码块         | ``` 围栏式，模板 `代码字体` + 等宽字体                                          |
| 表格           | 模板 `写书表格样式` + `表头字体` + `表格字体`                                   |
| 图片           | `![图X-N 描述](图片/文件名.png)`，嵌入 docx（非链接），居中+题注，宽≤14.65cm |
| **公式** | `$...$` 行内 / `$$...$$` 块公式，自动转换为 Word 原生 OMML 公式             |
| 列表           | 有序`1.` / 无序 `- * +`                                                     |
| 引用           | `>` 块引用                                                                    |
| 行内格式       | `**粗体**` `*斜体*` `` `代码`` ``                                           |

## 公式处理（OMML 原生渲染）

- **依赖**：`latex2mathml` + `lxml`
- **转换流水线**：LaTeX → latex2mathml → MathML → 自定义 → OMML → 嵌入 .docx
- **行内公式**：`$x_i$` → Word 原生 `<m:oMath>` 行内公式
- **块公式**：`$$...$$` 独占行 → Word 原生 `<m:oMathPara>` 块公式
- **编号**：`` \tag{X-N} `` 保留在公式右侧
- **已支持**：分数、上下标、根号、求和/积分/乘积、重音符号、cases/pmatrix/bmatrix/matrix 矩阵、上下大括号
- **已知限制**：`` \begin{aligned} `` 对齐环境可用但不显示对齐效果（`&` 显示为字符）
- **行距**：含公式的段落自动设置为 `auto` 行距以避免裁切

## 图片处理

- **路径解析**：脚本将 `![ ]()` 中的路径相对于 Markdown 文件所在目录解析
- **嵌入方式**：使用 `run.add_picture()` 嵌入为 inline shape（非浮动、非链接引用），确保 docx 独立可分发给读者，且不随文字排版浮动错位
- **尺寸约束**：宽度限制 14.65cm（A4 21cm − 左右页边距 3.18cm×2 = 14.64cm），等比缩放
- **居中定位**：图片所在段落设为居中对齐，`first_line_indent=0` 清除缩进 → 图片真实居中
- **不遮挡文字**：图片及题注均为独立段落，段前 8pt / 段后 2pt 间距，与上下文文字明确分离
- **题注**：图/表/代码/提示词/结果题注统一使用模板 `Caption` 样式（Word「题注」样式），自动与正文引用句建立 Word REF 交叉引用
- **缺失处理**：图片文件不存在时，显示灰色斜体占位提示"（图片待补充）""（此处待替换为真实截图）"等，不输出技术错误信息

## 页面与输出

- **页面**：A4，上下 2.54cm，左右 3.18cm
- **命名**：`{原文件名}_v{版本号}.docx`（无版本号则 `{原文件名}.docx`）

## 约束

- 所有格式由模板 `样式.docx` 定义，脚本仅做微量补充（如代码等宽字体）
- 章编号为0时不产生表题注
