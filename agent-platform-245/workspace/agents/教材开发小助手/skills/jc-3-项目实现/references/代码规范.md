# 代码规范

## 一、代码展示格式

### md 阶段展示形式

1. Python 代码块用 ` ```python `，普通语法/输出用 ` ``` `
2. 每个代码块前必须有 `代码X-N 描述` 题注
3. 每个代码块后紧跟运行结果
4. 结果省略时加说明：`注：此处部分结果已省略。`
5. 输出结果若分为两列，加说明：`注：由于代码运行结果篇幅过长，此处分两栏进行展示。`
6. **代码序号按二级标题重置**：一般一个二级标题对应一个代码文件，每个二级标题内的代码输入输出序号 `N` 从 1 开始递增（`代码X-N` 中的 `X` 为章号，`N` 为该二级标题内的代码序号）

---

## 二、代码→结果→解释 三连规范（硬约束）

**每个代码/图/表出现后，必须立即按以下顺序跟进**：

```
代码题注 → 代码 → "运行代码X-N得到的结果如下。" → 结果展示 → 结果解释段落
```

### 结果解释段落结构

```
从结果可以看出：…（是什么）→ 这意味着…（应用方向）→ 与XX方法相比，…（如有比较）
```

| 规则       | 说明                                                             |
| ---------- | ---------------------------------------------------------------- |
| 必须解释   | 每个图/表/代码输出必须有对应的文字解释                           |
| 解释结构   | 意义 → 应用 → 比较/趋势，见 `结果解释规范.md`                |
| 多方法比较 | 如有多种方法的结果须进行方法间比较                               |
| 备注格式   | 若结果与理论不符（如输出近似0而理论值为0），加"注："备注解释原因 |

## 三、Python 工具规范

### 函数与方法区分

|      | 函数                                    | 方法                                        |
| ---- | --------------------------------------- | ------------------------------------------- |
| 位置 | 直接写在文件中（不在Class中）           | 只能写在Class中                             |
| 参数 | 不含 `self`                           | 必须含 `self`                             |
| 调用 | 直接调用且必须设置参数                  | 跟在对象后面调用                            |
| 表示 | `XX函数`（无括号），如 `concat函数` | `XX()方法`（有括号），如 `append()方法` |

### 类与模块区分

- **类**：写在一个代码文件中，导入后需实例化才能使用
- **模块**：可包含多个代码文件，import导入后即可调用其中函数和方法
- 模块中可包含多个类

### 语法格式展示

1. 先解释类/函数/方法的作用，再用"XX的基本语法格式如下。"
2. 语法格式用 `` ``` `` 代码块展示（不带语言标识）
3. 参数说明统一用表格列出（即使只有一个参数），表头为"参数名称"和"参数说明"

### 代码注释

1. 注释与代码必须匹配，逻辑清晰
2. 注释中四位数以上数字加千分空
3. 生成的示例代码包含详细注释

### 字段说法统一

- 数据挖掘场景用"属性"
- 机器学习场景用"特征"
- Excel/Power BI 场景用"字段"
- 构建指标体系同理

### Matplotlib 图片清晰度

生成的 Python 代码中使用 Matplotlib 绘图时（Matplotlib 默认 dpi=80）：

- 通过 `plt.figure(figsize=(a, b), dpi=dpi)` 设置输出尺寸和清晰度
- 保存图片前调用 `plt.tight_layout()` 保证完整度
- 使用 `plt.savefig(outfile, dpi=1080)` 保存高清图片
