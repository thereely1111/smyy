# 理论型知识结构

**适用场景**：概念介绍、算法原理、分类体系、理论背景

## 一、内部编排结构

编写时的逻辑顺序，**不可颠倒**。输出时用自然段落流，不可显示序号标记。

```
H3/H4标题
  ├─ ① 背景（必选，1-3句）→ 为什么有这个理论、它的定位
  ├─ ② 概念定义（必选）→ 书面定义，中文名（英文名）。中职加通俗解释
  ├─ ③ 分类（可选）→ 有明确分类体系时输出，优先用表格
  ├─ ④ 作用（必选）→ 这个理论的价值
  ├─ ⑤ 应用场景（必选）→ 贴近读者生活
  ├─ ⑥ 原理/公式（可选）→ 有公式或算法流程时输出，有流程的优先画图
  ├─ ⑦ 举例子（必选）→ 遵循5步结构（见 `例子规范.md`）
  ├─ ⑧ 比较（可选）→ 有相关概念需要对比时输出，表格式对比
  └─ ⑨ 收尾过渡（必选）→ 引出下一知识点
```

**6项必选**（背景、概念、作用、应用场景、举例子、收尾过渡）+ **3项可选**（分类、原理、比较）。

## 二、输出句式

编写时按序自然衔接，不编号：

| 步骤     | 必/可选 | 句式模板                                                                   |
| -------- | ------- | -------------------------------------------------------------------------- |
| 背景     | 必选    | "XX是…" / "在…中，…" / "随着…的发展"                                   |
| 概念     | 必选    | "XX是指…" / "XX（英文名）是一种…"（中职额外加"通俗地说，XX就是…"）      |
| 分类     | 可选    | "XX主要分为以下几类：…" → 表格；无分类体系则跳过                         |
| 作用     | 必选    | "XX的主要作用是…" / "通过XX，可以…"                                      |
| 应用场景 | 必选    | "在实际中，XX常用于…"                                                     |
| 原理     | 可选    | 先文字解释基本原则，再配公式/流程图；公式用"计算公式如式（X-N）所示。"引入 |
| 举例子   | 必选    | "下面通过一个具体例子演示…" → 见`例子规范.md`                          |
| 比较     | 可选    | "XX与YY的主要区别如表X-N所示。" → 表格；无相近概念则跳过                  |
| 收尾     | 必选    | "以上介绍了XX的基本概念和应用，下一节将讨论…"                             |
