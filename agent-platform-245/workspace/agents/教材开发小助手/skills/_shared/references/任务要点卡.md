# 任务要点卡

> **用途**：编排向子会话派发内容生成类任务时，`【规范要点】` 按本卡第三节的骨架逐条注入，不再每轮从上下文重新推导。
> **效力**：本卡是**索引与固定结论清单**，不是规范原文。条目与权威文件冲突时**一律以权威文件为准**，冲突须在 return 中注明。
> **边界**：本卡只收「可直接执行的结论」，不复制规范原文；规范唯一依据仍是各技能 `references/` 下的权威文件。

## 一、权威文件索引（子智能体按需回查，禁止开局通读）

| 要点 | 权威文件 | 取哪一段 |
|---|---|---|
| 体例组件与层级名 | `jc-1-目录生成/references/体例模板/{体例类型}.md` | 章级组件树（H2 清单与顺序） |
| 题注写法与引用句式 | `题注与编号规范.md` | §一 编号格式表 + 题注细节 1–9 |
| 层级 ↔ Markdown 级别映射 | `题注与编号规范.md` | §二 要点 1–3（`children2`→`##`、`children3`→`###`、`children4`→`####`） |
| 用语口径与禁用词替换表 | `用语与格式规范.md` | 替换表与语句书面化条款 |
| 代码写法与本地可执行要求 | `代码规范.md` + `jc-0-代码验证/SKILL.md` | 「本地化规范」「修复规范」 |

## 二、error 级判据口径（一审脚本按此判，生成侧按此自查）

- **判据只面向正文散文**：代码围栏（```）、围栏化的运行结果、行内代码是程序产物，变量名、注释、print 文案、报错信息一律**不按写作规范判**；不要为了过检而改写围栏内的内容。
- **敏感内容**：政治/领土、不良社会现象、烟酒、宗教迷信、歧视等类别绝对禁止（清单见 `_shared/_audit_base.py` 的 `SENSITIVE`）。单字词（酒/烟）只在非中性复合词时命中（「酒店」「烟囱」不判）；「酒精」「饮酒」「一支烟」照判。
- **模糊时间词**：`当前`/`去年`/`今年`/`前年`/`最近`/`近期`/`不久前` 禁用于正文表述；`当前` 后接技术复合词（当前目录、当前状态、当前节点…）属术语用法，不判。
- **禁用词**：按 `用语与格式规范.md` 的替换表逐处替换（`其它`→其他、`比如`→如/例如、`点击`→单击、`拷贝`→复制…）；替换时注意**命中≠违规**——代码围栏内、行内代码、术语与数量表述（如「以上」）逐处判断。
- **人称代词**：正文不使用「你/我/他/她/它」及其复数（「我国」「用户」等固有词除外）。
- **书面化**：不使用口语化表述。

## 三、`【规范要点】` 注入骨架（按任务类型选用条目，逐条写实）

```
【规范要点】
1. 体例层级名：本章 H2 = {按体例模板顺序的组件清单}；组件内无编号子项用四级标题。
2. 题注体例：代码X-N / 表X-N / 图X-N / 提示词X-N / 结果X-N 五套独立编号，各自从 1 递增；
   题注行只写「编号 描述」，引用句「如X-N所示」只出现在正文且紧邻题注前；无引用的图/表/代码禁止出现。
3. 号段分配：{见第四节，逐路写实}。
4. 用语口径：按禁用词替换表替换；语句书面化；不用人称代词；不用模糊时间表述。
5. 超纲边界：只使用本章知识点清单内的函数/方法/库，清单={知识点 id 与名称}。
6. 数据口径：{数据集/字段/取值范围/可复跑要求，结论句}。
7. 输入绝对路径：{逐项列出}；【教材名称】={字面值}。
8. 判据口径：代码围栏与运行结果不按写作规范判（见 `references/任务要点卡.md` §二）。
```

## 四、号段预分配（并行派发时的唯一防撞手段）

- **跨组件连续的编号属于共享资源**：`代码X-N`、`表X-N`、`图X-N`、`提示词X-N`、`结果X-N`、实训题号、习题题号。
- 派发前编排按**盘上实测末号**（读已落盘产物的最大号）为每路分配**指定号段**，写进 task：
  `【号段分配】代码1-：3~12；图1-：1~4；实训题号：3~4`
- 子智能体**只用被分配的号段**，从号段起点连续递增；**禁止**自行推导编号、禁止跨段占用。
- 号段一经分配即归该组件专用；退回修改沿用原号段，不重新分配。

## 五、验证分级（生成侧自查到什么程度为止）

- **草稿期**（组件写盘、尚未成章）：只做**清洁扫描**——结构完整、题注连续、围栏闭合、路径契约自查。
- **收口期**（组件集齐、进入一审/拼装）：由审核侧跑全套判据与代码复跑，**每项只做一次**。
- 禁止在草稿期做收口期级别的全量验证：那会把单轮可用次数耗在验证上，挤掉后续组件的落盘。
