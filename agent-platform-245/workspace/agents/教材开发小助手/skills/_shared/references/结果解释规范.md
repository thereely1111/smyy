# 结果解释规范

> 适用：代码输出、图表、表格、提示词等需要解释的结果内容。置于结果展示之后。

## 一、解释内容要求

结果解释需覆盖以下全部维度：

1. **解释意义**：此结果说明了什么问题，揭示了什么规律
2. **解释应用**：此结果在实际中有什么用途，能解决什么问题
3. **比较/趋势**：与同类方法进行比较，或揭示此结果反映的发展趋势（适用时）

> 若有多种方法的结果，则需对多种方法进行比较（"XX方法比YY方法在…方面更优"）。

## 二、输出句式

| 场景     | 句式模板                                            |
| :------- | :-------------------------------------------------- |
| 通用引入 | "运行代码X-N得到的结果如下。"                       |
| 逐项解读 | "从结果可以看出…" / "第X行表示…" / "XX列代表了…" |
| 应用方向 | "基于此结果，可以用于…" / "在实际中，这有助于…"   |
| 方法比较 | "对比XX与YY的结果，XX在…方面表现更优，因为…"      |
| 收尾过渡 | "以上介绍了…的基本用法，能够满足多数情况…"        |

## 三、约束

1. 必须放到结果之后（代码输出/图表/表格之下），不可前置
2. 不能只抄输出内容，必须有分析性文字
3. 至少包含"意义解释"和"应用方向"两个维度
4. 多种方法的结果必须进行横向比较，列出异同及使用建议
5. 不凭空编造结论，所有结论基于实际输出结果
6. 涉及图表时，解释应关联到正文中对应的概念或操作步骤
