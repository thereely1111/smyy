# 思政融入规范

> 本文档定义思政融入的通用规则。是否融入思政由 `目录结构.json` 中的 `思政_required` 字段决定（`true` 才融入，`false` 不融入）。本文件只规定"如何融入"，不规定"是否融入"。

---

## 一、融入方式

| 方式       | 做法                     | 示例                             |
| ---------- | ------------------------ | -------------------------------- |
| 关键词延伸 | 从技术词联想到国家战略词 | "效率"→"提质增效"→"高质量发展" |
| 范围扩大   | 从具体事物联想到国家层面 | "房价"→"民生"→"为民造福"       |
| 示例背景   | 例子背景中融入正面因素   | 数据选择环保、科技自立方向       |

延伸示例：

- "房价/住房"→"民生"→"为民造福"
- "人才"→"人才强国"
- "安全"→"国家安全"
- "质量"→"高质量发展"
- "基础"→"基础研究"
- "效率"→"效能"
- "竞争"→"斗争"
- "从产品转向了客户"→"以人民为中心"

---

## 二、正文内融入位置

- 示例背景中：例子数据背景自然融入
- 小提示中：操作注意事项后加"思考："引导
- 结果解释末尾：1 句正面引导

---

## 三、引用政府报告原文（硬约束）

阅读拓展等场景引用政府报告（如"十五五"规划、二十大报告）原句时：

1. **必须用报告原文**，一字不漏、一个符号都不能改，照抄使用
2. **不要对引用的思政原文进行解读**

> 注：本规范**不禁止**"二十大"等表述出现，正文可按需引用"党的二十大报告""十五五规划"等原文；引用时遵守上述两条硬约束。

---

## 四、思政注意事项

1. **每章思政点不重复**（全书各章思政元素唯一）
2. **融入字数控制在 2 行以内**，不过多解释、不单独占用一个级别目录
3. **所挑选的热点事件/新闻必须已有官方发文**（不可用未经官方确认的传闻）
4. **不要通过负面事件或新闻体现积极观点**（应直接写优质正面事件）
5. **中立的事情也尽量不写**
6. **未来不确定的事情不要写**
7. **尽量不要使用国外的示例**
8. **正文中每一点思政描述内容不能太多**，写出关键思政点即可
9. 以上规则在与 `用语与格式规范.md` 中的敏感内容清单冲突时，以更严格者为准

---

## 五、敏感内容完整清单

> 本节为**内容安全**反向约束（非思政融入），对应图书规范 4.2.3。以下内容**绝对不能出现**：

| 类别     | 具体禁止内容                               |
| -------- | ------------------------------------------ |
| 政治     | 领导人姓名、国旗国徽、党旗党徽、军装、钱币 |
| 领土     | 港澳台、新疆、西藏敏感表述                 |
| 外交     | 中美、中澳关系                             |
| 地图     | 带中国国境线的地图                         |
| 党政     | 党政军、民族、外交政策、法律法规           |
| 不良引导 | 犯罪行为、自杀、社会不良现象               |
| 反华     | 崇洋媚外言论、反华的人和品牌               |
| 烟酒赌   | 烟、酒、槟榔、彩票、赌博                   |
| 宗教迷信 | 宗教（天堂/庙宇/灵魂）、星座、算命、风水   |
| 歧视     | 性别歧视、地域歧视、种族歧视               |
| 医疗     | 药物、器械、疫情                           |
| 经济     | 房价（尤其大城市）、加班（996）、奢侈品    |
| 娱乐     | 游戏名、明星照片                           |
| 节日     | 西方节日（如圣诞节等）                     |
| 组织     | 非政府组织                                 |
| 其他     | 已脱贫的"贫困县"不应出现；品牌需脱敏处理   |

> 图片中涉及品牌的需做脱敏处理，可用商品ID；图片标题、展示数据需审核不含敏感词。
