## 平台约束备忘（踩过的坑，别再走一遍）

- **脚本必须放在某个 Skill 目录下**：平台只把 `skills/` 物化到 `<运行态根>/.harness/skills/`，方案里设想的顶层 `tools/` 目录在 shell 里不可达。
- **`python` 不在 PATH 上**（平台只注入固定的 `PATH`，`inheritEnv=false`），跑脚本一律经 **`<RUN>`** —— 它是宿主相关占位符，Windows 展开为 `<MM2_SCRIPTS>\run.cmd`、Linux/macOS 为 `sh <MM2_SCRIPTS>/run.sh`；定义见 `skills/mm-0-路径与会话隔离` §4.2。它会按候选清单自动挑一个已装依赖的解释器；`python_path.txt` 可覆盖（**机器专属，别跨机拷**）。
- 包装脚本的行尾/编码要求（`.cmd` 纯 ASCII+CRLF、`.sh` 纯 ASCII+LF）属**维护者须知**，见 `skills/mm-0-路径与会话隔离` 末尾。
- **定义区只读**：`AGENTS.md`/`skills/`/`subagents/` 读得到、写不了；`schemas/`、`examples/` 没有可寻址的绝对路径，运行时等于读不到。
- **上传的附件名会丢中文**（`附件1.xlsx` → `<uuid>-1.xlsx`），配对要用附件列表接口拿原始文件名。
