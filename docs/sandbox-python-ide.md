# Python 3.11 IDE 沙箱

沙箱编辑页采用 CodeMirror 6 和 Pyodide 0.25.1（CPython 3.11.3）。沿用首页的青绿主色、青蓝辅助色、浅青背景和共享主题变量。左侧是当前智能体会话的逐问 Python 解题代码，右侧上方编辑代码，下方显示运行输出和 Python 控制台。两条分隔线均可拖动，支持方向键调整、双击恢复及本机尺寸记忆。

## 环境准备

```sh
pnpm install
pnpm python:prepare
pnpm python:check
pnpm dev
```

`python:prepare` 将解释器和 NumPy、SciPy、pandas、Matplotlib、SymPy 及其依赖准备到项目内的 `public/python`。本地完整运行包约 138 MB（不含前端资源）。首次准备需要网络，下载验证 SHA-256，可重复执行并复用完整文件。科学计算包较大，网络慢时单次下载最长等待 10 分钟，最多尝试 3 次。`pnpm build` 会先检查运行包完整性，再将本地资源一同打包到 `dist/python`。运行包二进制不进 Git，换机器后需要重新准备。仅安装 npm 依赖不会自动下载全部科学计算包。

打开原来的 `/sandbox/work/:problemId` 或 `/sandbox/editor/:problemId` 均进入 IDE。旧会话和产物接口沿用现有后端认证，不会创建另一套会话。

## 操作和文件

- 左栏采用简洁的问题代码列表，不展示通用目录树、CSV、JSON、JavaScript 或报告文件。按真实路径中的 `questions/q01`、`solve_q1.py` 等问题编号归类并按数字排序；未标注问题编号的 Python 文件保留在“解题代码”组，避免误删可运行入口。排除 `__init__.py` 等双下划线文件与常见测试文件。
- 代码生成阶段落盘到当前会话的 Python 文件通过轮询或手动刷新更新。优先打开交接请求指定的代码，否则打开最近的 Python 文件。隐藏的数据和辅助模块仍参与运行快照，不影响读取和导入。
- 点击文件即可编辑，Ctrl/Cmd+Enter 运行当前编辑内容，Ctrl/Cmd+S 弹出覆盖保存确认。运行未保存的代码不会自动覆盖智能体源文件。
- 每次运行把会话中的代码和数据复制到浏览器虚拟工作区，保留接口原始相对路径，当前目录为入口脚本所在目录。同目录模块和相对数据路径可直接访问，跨目录数据使用正确相对路径。
- 文件快照上限为 256 个伴随文件、单文件 20 MB、总输入 32 MB。文档、压缩包、视频和 HTML 不复制。数据读取失败会明确停止执行，避免用缺失输入运行。
- Python 控制台保留上一次运行的变量和文件。再次运行脚本会重建工作区并清理本地模块缓存。停止、刷新或离开页面会销毁解释器和内存文件。
- 新建或修改的结果文件显示为“本地生成”，可下载；Matplotlib 图表自动保存为 PNG。输出文件总导出上限 20 MB，单次终端输出上限约 1 MB。运行结果不会自动写回后端、更新模型流程或替代结果回传验收。

## 运行边界

这是浏览器内的 Python 3.11，不是操作系统终端或服务器容器。支持标准库和准备好的 WebAssembly 科学计算包，不支持任意系统命令、原生扩展、后台服务和交互式 `input()`。其他依赖需要具有对应 Pyodide 包，并单独准备到本地；不能假定任意 pip 包可用。需要 GPU、系统工具或大数据集的解题代码仍需服务器或本机 Python 环境。

代码运行在独立 Worker，停止按钮可以终止 CPU 死循环，单次操作限制为 120 秒。Worker 隔离 UI 线程，不是恶意代码的完整安全边界；如果需要运行不可信第三方代码，应进一步采用独立来源或服务端容器隔离。

浏览器本地验证使用模拟的会话产物接口，实际 Python 解释器与科学计算包在浏览器中运行。此验证不等同于真实账号下智能体生成、落盘、编辑、保存和结果回传的完整后端联调。
