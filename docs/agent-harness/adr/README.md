# Architecture Decision Records

Create an ADR only for decisions that are hard to reverse or have meaningful
trade-offs. Do not create an ADR for ordinary implementation details.

## Naming

`0001-short-decision-name.md`

## Template

```md
# ADR-0001: <decision title>

## Status

Accepted / Superseded by ADR-000N

## Context

Why this decision was needed.

## Decision

What was decided.

## Alternatives Considered

- Option A: why not.
- Option B: why not.

## Consequences

Positive and negative consequences.
```
