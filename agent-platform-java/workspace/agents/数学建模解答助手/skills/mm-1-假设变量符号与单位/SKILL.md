# 假设、变量、符号与单位

## 步骤
1. 仅提出使模型可分析/计算所需的候选假设；每条记录理由、适用范围、可能偏差和待确认状态。
2. 不得把事实改写成假设，也不得用计算结果反向构造先验假设。
3. 变量角色限定为 `state`、`input`、`decision`、`parameter`、`metric`；不确定角色标 `unknown` 并解释。
4. 每个符号记录唯一 `symbol_id`、符号、名称、定义、角色、单位、所属问题、来源及状态。
5. 检查同符异义、异符同义、百分数/比例混淆、时间/空间尺度冲突和量纲不一致风险；仅能静态推断的风险注明待核实。

## 输出与自检
输出 assumptions 与 symbols。未知单位保持 null/待确认，不自行补充；推荐路线引用的变量和参数必须在契约中有定义。
