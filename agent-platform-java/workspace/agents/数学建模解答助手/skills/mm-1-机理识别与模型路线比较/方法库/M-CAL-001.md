### M-CAL-001 参数估计、校准与反问题
- **task_types**：物理模型参数识别、曲线拟合、系统辨识、实验校准。
- **problem_signature**：已知机制方程但参数未知；观测由模型生成且带噪声。
- **core_idea**：使模型输出与观测最一致，同时控制不可识别性和过拟合。
- **methods**：最小二乘、最大似然、正则化、贝叶斯反演、卡尔曼滤波。
- **inputs**：机制方程、观测、参数边界、初值、误差模型。
- **outputs**：参数估计、置信/可信区间、拟合轨迹、残差、可识别性诊断。
- **assumptions**：模型结构足够；观测信息能识别参数；误差模型合理。
- **validation**：留出数据、残差、参数扰动、不同初值、合成数据回收实验。
- **selection_tags**：`calibration, inverse-problem, system-identification`
- **fallbacks**：简化模型、固定不可识别参数、增加实验设计。
- **agent_actions**：写前向模型 -> 做量纲和边界检查 -> 校准 -> 识别性/残差诊断 -> 外部验证。
