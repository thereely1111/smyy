# mm-2-分析到场景映射

## 输入前提

父任务已注入题目 PDF 与附件目录的**绝对路径**。没有拿到真实路径时返回 `BLOCKED`，不要扫盘找附件。

## 第一步：盘点输入（必做，不可跳过）

**先看输入是哪一种**，再决定要不要整备：

| 输入形态 | 动作 |
|---|---|
| 已经是「题目目录 + `附件/`」结构 | 直接跑下面的 `probe_inputs.py` |
| 平台聊天上传的平铺文件（`uploads/` 下一堆散文件） | **先整备**（只复制归类、不改内容）：`<RUN> prepare_input.py --pdf <题目.pdf> --title <题名> --out-dir <运行态根>/<自身会话目录>/artifacts/<case_id>/input <附件文件…>`，产出 `artifacts/<case_id>/input/<题名>/input_manifest.json` 及其同目录的题面与附件 |

```
<RUN> probe_inputs.py --problem "<题目目录或题目 PDF 的绝对路径>" --out-dir "<运行态根>/<自身会话目录>/artifacts/<case_id>/analysis"
```

`<MM2_SCRIPTS>` 的探测方法见 `mm-0-路径与会话隔离` 第四节（脚本路径因部署而异，首次使用必须先探测）。

产出：

| 文件 | 用途 |
|---|---|
| `<out-dir>/input_digest.md` | 题面正文 + 附件结构说明 + **已计算事实摘要**（你读这个） |
| `<out-dir>/facts.json` | 附件事实（渲染脚本据此把真实数组注入 chart；你只引用键名，不抄数组） |
| `<out-dir>/pages/page_NN.png` | 题目页码图（用 `read_image` 看，**公式以图为准**：文本层会把分式/上下标拉平） |

三项都落在 `--out-dir` 指定的目录下（上面命令里是 `artifacts/<case_id>/analysis/`），**不是固定的 `truth/facts.json`**。下游（渲染脚本）要用同一个实际路径，别按文件名猜目录。

盘点后先做三件事：
1. 用 `read_image` 逐页看页码图，核对文本层里的公式与数字有没有被拉平或错位；
2. 数清**题目问数**（问题一/二/…），它决定档数 = 1 + 问数；
3. 读 `facts.json` 的 `_catalog` / `_series` / `_stats` / `_notes`，确认每份附件支撑哪一问；`_notes` 里列出的读取问题必须如实反映到场景里（例如某份结果是空模板，就在对应幕标"待运行"）。

## 第二步：产出 scene_map.json

严格按 `references/scene_schema.md`（**权威契约，正文逐字沿用上游**）写 `artifacts/<case_id>/analysis/scene_map.json`：

- 第一档固定 `name="全局问题分析"`，**恰好 3 幕**：对象与关系 → 附件与任务矩阵 → 共同底座（变量/边界/评价口径）；
- 其后每个子问题一档，`name="问题N分析"`（中文数字），**恰好 1 幕**，只讲相对前问**新增**的条件、模型与结论口径；
- 每幕 `h1`/`lead` 非空、`blocks` ≥ 2，且至少一种可视化或小切换（`chart` / `pills` / `matrix` / `svgclick` / `slider`）；
- 数值只来自三步：(a) 题面明确给出，(b) `chart` 块用 `spec.from = "facts:<键名>"` 引用真实序列，(c) 明确标注为示意/待运行。**没有第四种**。

**分次写盘**：先写全局档，再用 `edit_file` 逐问追加，避免单次输出过长被截断。写完必须能通过 JSON 解析（无注释、无尾逗号、无 markdown 代码块包裹）。

## 第三步：交给渲染

scene_map 落盘后不要再手工拼 HTML —— 交给 `mm-2-Web动画实现规范` 的 `render_animation.py`，它负责清洗、结构闸门、真实数组注入与模板填充。

## 失败分支

| 情况 | 动作 |
|---|---|
| 题面正文为空且没有页码图 | `BLOCKED`，列出问题（可能是扫描件或加密 PDF） |
| 附件读不出或 `_notes` 提示解析失败 | 若影响图表 → `PARTIAL` 并在对应幕标"数据缺失"；若整档无法成立 → `BLOCKED` |
| 问数无法判定（题面表述含糊） | `[HITL_REQUIRED]` 交父编排，给出你判断的候选问数与依据 |
| 结构与闸门冲突 | 以**闸门**为准（见实现规范），改 JSON 重跑，不要改闸门或本文 |

## 自检

- [ ] 档数 = 1 + 问数，第一档 3 幕、其余每档 1 幕
- [ ] 每幕 `h1`/`lead` 非空、`blocks` ≥ 2、含至少一种可视化或小切换
- [ ] 无封面/概览/题面原文/禁用开场词（题目原文、题面原文、赛题原文、原题全文、封面、内容概览）
- [ ] 每个 chart 的 `from` 键名都能在 `facts.json`（`--out-dir` 下的那份）里找到
- [ ] 没有把示意数字写成实测结论；缺数据处明确标注
