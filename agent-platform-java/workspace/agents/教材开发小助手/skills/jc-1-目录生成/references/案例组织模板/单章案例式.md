# 单章案例式 — 一章一个独立案例

适用：项目式

## 骨架结构

- 第 1 章为理论章（工具/环境/理论概述），不承载案例、不检索 KB 案例库
- 其余每章一个独立案例，章间案例无依赖
- 章节类型分布：第1章 `理论类`，其余章 `案例类`

## 标题格式

| 体例     | 格式                               |
| -------- | ---------------------------------- |
| 项目式   | `项目X XX知识主题——XX案例名称` |

> 仅项目式支持单章案例式。

- `——` 左侧：知识主题，右侧：案例名称
- 每章一个独立案例，整章围绕该案例展开。案例虽小但须在章内形成领域流程闭环（覆盖该章知识点对应的阶段链），章间无案例依赖

## 案例规则

- 跨章案例名不得重复（同 case_name 不可跨章）
- 案例阶段划分须与依赖链一致，不得跳过关键阶段
- 理论章（第 1 章）知识讲解配必要示例：抽象/操作/易混/后文案例依赖的知识点必配，简单概念可不配（遵循"示例必配原则"）

## 调度策略

N章全并行，每章上下文含前置知识点摘要。
