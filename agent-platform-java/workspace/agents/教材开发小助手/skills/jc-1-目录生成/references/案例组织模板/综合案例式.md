# 综合案例式 — 前M章知识点+示例，后K章综合案例

适用：项目任务式

## 骨架结构

- 前 M 章为"知识点+示例"章（操作类），后 K 章为案例章（案例类）
- M + K = 计划章数
- K 由课时决定：案例章课时占比 15%~25%，K 取 1~3（课时充足取 3，课时紧张取 1~2）
- 每案例章预留 2~3 实战课时

## 标题格式

| 阶段           | 标题格式                       | 说明                   |
| -------------- | ------------------------------ | ---------------------- |
| 知识点+示例章  | `第X章 XX知识主题`           | 纯知识主题，不含案例名 |
| 案例章         | `第X章 案例实战：XX案例名称` | 固定前缀"案例实战："   |

> 仅项目任务式支持。

## 规则

### 知识点+示例章（前 M 章）

- 章内附自包含小示例演示，不涉及跨章案例场景
- 示例按"示例必配原则"按需配：抽象/操作/易混/后文案例依赖的知识点必配，简单概念可不配
- 理论章内部示例 data_scale 通常为 small，同样需标注数据需求并写入案例清单

### 案例章（后 K 章）

- 综合应用前置全部理论知识，须构造完整的端到端流程链
- 案例流程阶段须覆盖前置理论章的关键知识点
- 进阶知识点可嵌入案例章在实战语境深化讲解
- 没有额外知识点的话，案例章可不讲解新知识点
- 案例名格式 = `案例实战：{领域}全流程{任务}`

## 案例设计

理论章（前 M 章）不设计章级案例，案例章（末尾 K 章）各设计 1 个综合案例：

- 每个案例章综合应用全部前置理论章的知识点
- 案例流程阶段须覆盖前置理论章的关键知识点，形成完整的端到端流程链
- **K ≥ 2 时维度差异化**：不同案例须在领域、难度层级、方法论等维度上拉开显著差异
- 案例章可嵌入进阶知识点在实战语境深化，但以综合演练为主
- 理论章内部示例与案例章案例之间维度有显著差异

## 调度策略

理论章并行 → 全部入库 → 案例章并行。
