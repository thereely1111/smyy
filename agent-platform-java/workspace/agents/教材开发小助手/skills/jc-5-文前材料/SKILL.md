## 通用规范

> **产出与路径**：`前言/`、`内容提要/` 用**相对路径**写在自己会话空间（`artifacts/{教材名称}/前言/`，`内容提要/` 同理），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）（见 jc-0 路径工具 §1/§4）。

编写内容必须遵守以下共享规范：

- `references/用语与格式规范.md` — 用词替换表、标点符号、敏感词、内容质量
- `references/思政融入规范.md` — 思政融入方式与敏感词清单

## 一、前言

### 结构要求（4部分，严格按序）

1. **引入段**：一段话从**行业背景、人才需求**引入为什么要写这本书。
2. **本书特色**：从**内容设计**角度编写，**不罗列内容提要的内容**。
3. **适用对象**：分点列出适用对象。
4. **代码下载及问题反馈**：直接使用模板，注意：核实本书的数据和代码是否只有数据、代码是什么语言的代码。

### 前言约束

1. 四部分结构完整，不可缺项
2. 不与内容提要重复
3. 正文中「二十大」三字不得出现

---

## 二、内容提要

### 结构要求（2段）

**第1段**：一句话写出本书内容设计上的特色 + 简洁概述全书包含的主要内容（对照章节目录）

**第2段**：说明本书的适用对象

**不冗长，不与前言内容重复。**

### 内容提要约束

1. 字数精炼，不冗余
2. 不重复前言内容
3. 准确反映目录结构
