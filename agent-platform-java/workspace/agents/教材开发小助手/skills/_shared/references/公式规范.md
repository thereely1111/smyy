# 公式规范

## 一、公式内容处理规范

- 公式前必有文字引入："计算公式如式（X-N）所示。"
- 公式后立即解释符号含义："式中，…为…"
- 如有变体（如加权公式），紧接说明："有时，为了…，这得到了加权…，如式（X-N）所示。"
- 如有局限性，补充："XX的主要问题是…。为了消除…的影响，可以使用…"

---

## 二、公式 Markdown 格式

使用 LaTeX 语法。

```markdown
若求$N$个原始数据的平均值，则计算公式如式（4-1）所示。

$$
\bar{x} = \frac{1}{N}\sum_{i=1}^{N}x_i \tag{4-1}
$$

式中，$x_i$为第$i$个观测值，$N$为观测值总数。
```

### 格式规则

| 格式     | 语法                          | 用途                   |
| -------- | ----------------------------- | ---------------------- |
| 行内公式 | `$...$`                     | 文字段落中嵌入小公式   |
| 块公式   | `$$...$$`（独占行）         | 独立成行的展示公式     |
| 公式编号 | `\tag{X-N}`（在 `$$` 内） | 右对齐编号 `（X-N）` |

### 正斜体 LaTeX 写法

确保 md→Word 转换后变量斜体、常量正体：

| 类型                | LaTeX 写法                                 | 对应场景                 |
| ------------------- | ------------------------------------------ | ------------------------ |
| 变量（斜体）        | `$x$` `$y_i$` `$\alpha$`             | 一般变量、变动附标、标量 |
| 函数名（正体）      | `$\sin$` `$\cos$` `$\log$` `$\ln$` | 已知函数                 |
| 常数（正体）        | `$\pi$` `$\mathrm{e}$`                 | 圆周率、自然对数底       |
| 向量/矩阵（粗斜体） | `$\boldsymbol{x}$`                       | 向量、矩阵               |
| 集合符号（粗正体）  | `$\mathbf{N}$` `$\mathbf{R}$`          | 自然数集、实数集         |

### 公式编写规则

1. 连续公式之间用半角逗号：`$a=1$, $b=2$`
2. 含优先级的运算用 `\left(` `\right)` 圆括号隔开
3. 函数符号 ≥2 个字母且自变量无 ± 运算时，自变量圆括号可省略：`$\sin x$`（函数与变量间空一格）
4. 大于等于/小于等于使用 `\geq` `\leq`（下方线为斜线）
5. 省略号使用 `\dots`（居中三点）；方程式中间省略号需连续12个点
6. 公式转行时下一行紧靠运算符（`=` `+` `-` `\pm` `\times`）后断开
7. 公式编号放在 `\tag{X-N}` 中
8. 中文文字描述中出现的数学符号也要用 `$...$` 包裹（如"变量 $x$ 的取值"）
9. 纯文字描述中的字符（非公式场景）使用纯文本，不用 LaTeX（如"定义变量a"而非"定义变量$a$"）

## 三、LaTeX 语法参考

### 3.1 常用运算符与结构

| 类型     | LaTeX                     | 说明                   |
| -------- | ------------------------- | ---------------------- |
| 上标     | `x^2`, `e^{-x}`           | 幂次、上标             |
| 下标     | `x_i`, `x_{ij}`           | 索引、下标             |
| 分式     | `\frac{a}{b}`             | 分数                   |
| 根号     | `\sqrt{x}`, `\sqrt[n]{x}` | 平方根/高阶根号        |
| 上划线   | `\bar{x}`                 | 变量均值标记           |
| 尖帽     | `\hat{y}`                 | 估计值标记             |
| 求和     | `\sum_{i=1}^{N}`          | 累加求和               |
| 积分     | `\int_{a}^{b}`            | 定积分                 |
| 乘积     | `\prod_{i=1}^{N}`         | 连乘                   |
| 无穷     | `\infty`                  | 无穷大符号             |
| 自适应括号 | `\left( ... \right)`    | 自动调整高度的括号     |
| 上大括号 | `\overbrace{a+b}^{n}`     | 标注上方说明           |
| 下大括号 | `\underbrace{a+b}_{n}`    | 标注下方说明           |

### 3.2 希腊字母

| 小写                              | 大写                                          |
| --------------------------------- | --------------------------------------------- |
| `\alpha` `\beta` `\gamma` `\delta` `\epsilon` | `\Gamma` `\Delta` `\Theta` `\Lambda` `\Sigma` `\Omega` |
| `\zeta` `\eta` `\theta` `\iota` `\kappa` | `\Xi` `\Pi` `\Phi` `\Psi`                     |
| `\lambda` `\mu` `\nu` `\xi` `\pi` |                                               |
| `\rho` `\sigma` `\tau` `\phi` `\chi` `\psi` `\omega` |                                               |

### 3.3 矩阵环境（全部支持）

| 环境                          | 效果               | 说明                 |
| ----------------------------- | ------------------ | -------------------- |
| `\begin{cases}`               | 大括号方程组       | 分段函数、条件表达式 |
| `\begin{pmatrix}`             | 圆括号矩阵         | 矩阵/向量            |
| `\begin{bmatrix}`             | 方括号矩阵         | 矩阵                 |
| `\begin{matrix}`              | 无括号矩阵         | 纯行列结构           |

> 以上均可在块公式 `$$` 和行内公式 `$` 中使用。

### 3.4 已知限制

| 功能                       | 状态     | 说明                                            |
| -------------------------- | -------- | ----------------------------------------------- |
| `\begin{aligned}` 对齐     | ⚠️ 受限  | 不崩溃但无对齐/换行效果，`&` 显示为字符，暂不建议使用 |

> 禁用 `\begin{aligned}`，如需多行公式请拆为独立的 `$$...$$` 块公式逐一编号。
