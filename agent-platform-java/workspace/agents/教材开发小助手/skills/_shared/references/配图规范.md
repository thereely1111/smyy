# 配图规范

> 本文档定义配图判定规则、`@图片清单` 格式和图片存储规范。知识准备、项目实现均遵循本规范。

---

## 一、配图判定（两步）

正文中每个需要配图的位置，按以下两步判定素材来源：

### 第一步：查 KB 图片索引

该位置所引用的资料来源为 **KB 来源**、且**原文该位置恰好有配图**时，读取 `图片/KB图片/索引.json`，用 `context` 匹配定位图片：

- 命中 → 直接插入正文 `![图X-N 描述](图片/KB图片/kb_xxx_01.png)`，**不纳入 @图片清单**
- 未命中 → 进入第二步

> KB 图片来自 `jc-0-知识库检索` 下载原文时顺带提取（`fetch_entry.py`），索引结构见该 Skill。

### 第二步：按配图类型分型

| 触发条件                            | 素材类型     | 说明                                                                     |
| ----------------------------------- | ------------ | ------------------------------------------------------------------------ |
| 结构化流程图（节点和分支明确）      | `代码生图` | graphviz，无水印、布局精确                                               |
| 概念关系图、抽象示意图              | `AI生图`   | image_gen                                                                |
| 软件安装界面、IDE操作页面、设置面板 | `待补齐`   | 进入 `@图片清单`，正文占位 `![图X-N 描述](@TODO)` |
| 数据可视化结果（Matplotlib等）      | 不走视觉素材 | 由 execute_code.py 直接产出                                              |

> **硬规则**：真实界面 → `待补齐`（不生成）。算法流程 → `代码生图`。抽象概念 → `AI生图`。禁止混用。

## 二、@图片清单格式

配图判定第二步中，代码生图、AI生图、待补齐三类素材写入正文末尾的 `@图片清单` YAML，供 `jc-3-视觉素材` 批量生成：

```yaml
@图片清单:
  - 图号: "1-1"           # 图X-N 中的 N（章内连续编号）
    类型: "AI生图"        # AI生图 / 代码生图 / 待补齐
    描述: "AI-ML-DL关系图" # 题注描述（不含"图X-N"前缀）
    内容: "人工智能、机器学习、深度学习三者关系示意"
  - 图号: "1-3"
    类型: "待补齐"
    描述: "Trae安装向导界面"
    内容: ""              # 待补齐类内容可为空
```

| 字段   | 说明                                        |
| ------ | ------------------------------------------- |
| 图号   | 图 X-N 中的 N，章内连续递增                  |
| 类型   | `AI生图` / `代码生图` / `待补齐` 三选一      |
| 描述   | 题注文字（不含"图X-N"前缀）                 |
| 内容   | 图片内容描述；待补齐类可为空                 |

> 数据可视化结果不走 @图片清单，由 execute_code.py 直接产出。

## 三、图片命名与存储规范

**生成图片时必须遵守：**

1. **图片命名**：以题注命名，格式 `图X-N 描述.png`，如 `图1-1 AI-ML-DL关系图.png`
2. **存储位置**：图片属**共享中间产物**——用**相对路径**写在自己的会话空间（`artifacts/{教材名称}/第X章_{标题}/图片/`，落到 `runtimes/{agentId}/<自身会话>/...`），并在 `【TASK_RESULT】artifacts` 里逐文件登记（见 jc-0 路径工具 §3/§4）
3. **Markdown引用**（知识准备正文中）：

   ```markdown
   ![图X-N 描述](图片/图X-N 描述.png)
   ```

   仅使用文件名，由 md转word 脚本从 md 文件同级 `图片/` 目录解析
4. **题注规范**：图中必须有对应题注引用（"如图X-N所示，……"，引用用逗号隔开），且题注号与文件名一致
5. **图片尺寸**：等比例缩放，宽度不超过14.65cm，高度不超过18.0cm
6. **图片格式**：PNG 优先（公式/流程图用 PNG），照片可用 JPEG
7. **图片不内嵌标题**：流程图/原理图内部不显示题注文字，题注由 Markdown `![图X-N 描述]` 外部标注
8. **文字清晰**：label 简洁（不超过12字），确保节点内文字完整无遮挡
9. **节点数量**：单图节点 ≤ 15 个，超过时应拆分或多图呈现

> AI生图 prompt 模板见 `jc-3-视觉素材` Skill 第一节；代码生图 JSON 格式见 `jc-3-视觉素材` Skill 第三节。
