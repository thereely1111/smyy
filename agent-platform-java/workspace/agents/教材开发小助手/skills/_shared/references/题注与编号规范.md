# 题注与编号规范

## 一、题注规范

### 题注编号与引用格式

| 类别 | 题注编号格式 | 引用句式 | Markdown 位置 |
|------|------------|---------|------|
| 图   | 图X-N 描述 | 如图X-N所示 | 图下方，居中 |
| 表   | 表X-N 描述 | 如表X-N所示 | 表上方，居中 |
| 代码 | 代码X-N 描述 | 如代码X-N所示 | 代码上方，居中 |
| 公式 | （X-N） | 式（X-N） | 公式右侧 |
| 提示词 | 提示词X-N 描述 | 如提示词X-N所示 | 代码块上方，居中 |
| 结果 | 结果X-N 描述 | 如结果X-N所示 | 代码块上方，居中 |

### 题注细节

1. 题注编号与描述文字中间**空一格**
2. **所有题注在正文中必须有提前引用（强制）**：正文在引用图/表/代码时，必须以"如图X-N所示""如表X-N所示""如代码X-N所示"等句式提前引用，且引用句必须紧邻对应的图/表/代码之前。**严禁出现无引用的图/表/代码**。
3. **题注行格式（强制）**：题注行只写「`编号` + `空格` + `描述`」，**禁止**在题注行出现「如」「所示」等引用词。引用句式「如X-N所示」**只出现在正文引用句中**，绝不可混入题注行。

   正确示范：
   ```markdown
   将上述提示词输入 AI 工具后，可得到如下模块划分结果，如结果2-1所示。

   **结果2-1** 在线商城功能模块划分

   ```text
   1. 用户模块：……
   ```
   ```

   错误示范（题注行误加「如…所示」）：
   ```markdown
   如结果2-1所示 在线商城功能模块划分
   ```
4. 题注描述要与内容对应
5. 引用句式：
   - 与描述用逗号隔开：`如图X-N所示，`（注意用逗号，不用句号，否则该句会缺少主语）
   - 作为定语（无标点隔开）：`图X-N所示的……`
6. 图片文件名 = 题注字符串（如题注"图1-1 AI关系图" → 文件名 `图1-1 AI关系图.png`）
7. Markdown 中图片、题注前不得使用 `-` `*` 等列表标记，图片和题注必须作为独立段落存在
8. **提示词/结果题注**：`提示词X-N`、`结果X-N` 与 `代码X-N` 为三套独立编号，各自从 1 递增，互不干扰。提示词题注紧跟 ``` 代码块（文本用 ```text，代码用对应语言）；结果题注按内容类型二选一——代码用 `代码X-N` 题注 + 代码块，文本用 `结果X-N` 题注 + ```text 代码块（详见 `提示词驱动型知识结构.md`）
9. **题注样式（转 Word 后）**：所有题注（图/表/代码/提示词/结果）在 Markdown 中以独立段落呈现，转 Word 时由 `jc-4-md转word` 脚本统一套用 Word「题注」样式（`Caption`），并与正文引用句建立 REF 交叉引用。**生成层无需也不得为题注额外指定加粗/居中/字号等格式**，样式由模板 `样式.docx` 的 `Caption` 样式统一控制。

## 二、标题与编号规范

### 标题级别模式

| 级别 | 格式 | 例 |
|------|------|-----|
| 一级 | 第X章 / 项目X | `# 第1章 概述` |
| 二级 | 组件标题 / X.X / 任务X.X | `## 教学目标`、`## 1.1 背景` |
| 三级 | X.X.X | `### 1.1.1 定义` |
| 四级 | 1. / 组件内部子项 | `#### 1. 概念`、`#### 1. 技能目标` |
| 五级 | （1） | `##### （1）子项` |
| 六级 | ① | 正文内编号 |
| 七级 | a. | 正文内编号 |
| 八级 | （a） | 正文内编号 |
| 九级 | 带圈字符（如 ⓐ） | 正文内编号 |

### 标题级别要点

1. **组件标题用二级（`##`）**：教学目标、项目描述、思维导图、知识准备、项目实施、项目小结、实训、课后习题、阅读拓展等组件标题，统一使用 `## `（二级），与 X.X 节标题**同级**。
2. **逻辑层级 ↔ Markdown 标题级别固定映射**：目录结构.json 的 `children2` → `##`、`children3` → `###`、`children4` → `####`，生成与拼装均**不得增减 `#` 数量、不得偏移层级**。
3. **组件内部子项用四级（`####`）**：组件内无编号子项（如「技能目标/知识目标/素养目标」「项目背景/项目目标/项目分析」「导读/思考题」「训练要点/需求说明/实现思路及步骤」「一、选择题」等）统一用 `#### `（四级），不得与 X.X 二级、X.X.X 三级抢占层级。

### 编号规范

1. 不使用无序列表的项目符号（`-` `*`）作为章节编号
2. 正文内分点使用的编号从 `（1）` 开始（五级，不用标题样式），严格按级别递进；若对应标题超过五级，则正文编号从下一级开始
3. 标题（前三级）：总起下文、内容简短、无句号
4. 正文编号（五级起）：内容为一段话、有句号
5. 分点内容很多（超过4行或2段以上）时，提升为标题+正文形式
