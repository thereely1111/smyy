# 用语与格式规范

## 一、用词规范

### 替换表

| 禁止                     | 替代 | 禁止          | 替代                       |
| ------------------------ | ---- | ------------- | -------------------------- |
| 其它                     | 其他 | 比如          | 如/例如                    |
| 等等                     | 等   | 用来          | 用于                       |
| 点击                     | 单击 | 就可以        | 即可                       |
| 或者                     | 或   | 如下所示      | 如下                       |
| 拷贝                     | 复制 | 的时候/时候   | 时                         |
| 键入                     | 输入 | 拖拽          | 拖曳                       |
| 拖到/拖动                | 拖至 | 把            | 将                         |
| 来/去/说/讲/演示/想/当然 | 改掉 | 你/我/他/我们 | 改掉 |

### 书写风格

- 拖拽统一用"拖曳"；"拖到/拖动"改为"拖至"
- 描述全国的省份时，用"省（自治区）"
- 描述名词涉及中文、英文全称、英文简称，统一为"中文（英文全称，英文简称）"
- 描述键盘上的快捷键或组合键，统一用"快捷键"

### 人称与指代

- **禁止使用**"你""我""他""我们"等人称代词，一律使用陈述句
- **禁止使用**"上面""下面""以上""以下""上述""接下来"等指代不明确的词
- "其"字尽量少用，特别在"其"之前有2个以上事物时
- 引用图/表/代码用交叉引用介绍清楚具体内容，如"如图X-N所示"
- 引用章节内容用"X.X.X小节"或"第X章"

### 关联词搭配

| 标准搭配                                         |
| ------------------------------------------------ |
| 在……中，当……时，XX是……的                   |
| 如果……那么…… / 若……则……                  |
| 不仅……而且……（一般不用"不仅……而且还……"） |
| 因为（由于）……所以…… / 之所以……是因为……  |
| 除……之外，还有/还需/还可以……                 |

## 二、内容质量

### 正文内容

1. 尽量避免出现含有消极的例子（犯罪、死亡、传染病等）
2. 例子尽量是最新的，特别是涉及到日期的数据
3. 文中大段内容（如3页以上），要适当提炼成标题，分点介绍
4. **总分说法要统一**：总述句包含几点，分点介绍就应该包含几点——数量、说法、顺序都要完全一致
5. **某些词介绍的顺序要与正文描述的顺序一致**（如总述中提"A、B、C"，分述必须按A→B→C顺序）
6. 对于正文中输入的内容、对话框名、单选框名等，统一加双引号
7. 英文人名统一为"中文名（英文名）。"
8. **主语要明确**：不能少了主语，特别是用句号隔开后
9. **尽量少用疑问句**，最好使用一般的陈述句
10. **用词必须统一**：相同描述的词语统一，描述风格统一
11. 一句话尽量不要包含3个以上的信息，要适当用标点符号断句
12. **表述不能过于绝对**："最""第一"尽量少用，精准数字也不要
13. 文档中不能出现网址
14. 软件结果不符合实际时，必须备注说明（如输出近似0而理论值为0）
15. 时间描述一定不要模糊（"当前""去年""前年"等），因为写书时间和出版时间不同
16. 四位数以上数字加千分空（除年份和代码行号外，但代码注释中需千分空）。整数从右往左每3位；小数从左往右每3位。如 `1 234.025 8`

### 数据

1. 所有数据字段必须加单位，形式统一为：`变量/单位`，如"消费金额/元"
2. 展示部分数据时需写明"部分数据"，且后面引用不要用表格编号
3. 字段说明与数据示例可放在一个表展示（特别是文本数据，容易出敏感词）

---

## 三、标点符号

1. 软件和版本号之间空一格，如"Python 3.6.0"
2. 表示范围用波浪号（如"1~10"），时间范围用"-"（如"2010年-2021年"）
3. 尽量少用冒号，且不能分段使用
4. 连续的双引号""、书名号《》、中括号【】中间不加标点
5. 中文（全角）和英文（半角）的标点符号不能混用。除代码、数学表达式外，统一使用全角符号
6. 必须去除多余空格（英文单词和汉字之间、英文单词和标点符号之间、数字和汉字之间不需要空格）
7. 逗号和顿号不要混用：连续且同级的词用顿号；多级之间用逗号
8. 顿号、"和""以及"顺序不要混用

### 标题格式
1. **标题不得使用斜体**：所有级别标题必须使用直立字体（非斜体）。
2. **标题左侧不得出现项目标记（黑色小方块）**：标题是结构元素，不是列表项。Markdown 中标题行必须以 `#` 开头，不应使用 `-` `*` 等符号作为标题标记。
3. 标题字体颜色统一为黑色。

### 正文样式规范
1. 所有正文段落统一使用"书写正文"样式（Word 中对应标准正文样式）。
2. **禁止使用加粗（`**xxx**`）或斜体（`*xxx*`）作为整段/整行的文字样式**。行内加粗仅用于关键词强调（如"**角色定位**是 Prompt 的第一个要素"），不得出现整行加粗。
3. 英文术语、API 名称、函数名、参数名统一用行内代码 `` `xxx` `` 包围，在 Word 中渲染为等宽字体，与中文正文明确区分。

---

## 四、数量表述

1. 个数 < 3：用"一"或"两"表示
2. 个数 ≥ 3：用阿拉伯数字表示
3. 计算机语言和数学中半角符号与全角符号不能搞混（如 `1×1`不是 `1*1`，坐标 `(1,1)`不是 `（1,1）`）

---

## 五、英文规范

1. 英文单词的大小写（特别是首字母），全文统一
2. 英文尽量翻译成中文

---

## 六、敏感内容禁止

**绝对不能出现**：地图、领导人姓名、国旗国徽、党旗党徽、军装、钱币、港澳台/新疆/西藏、中美/中澳关系、酒/槟榔、犯罪行为/自杀/社会不良现象、崇洋媚外/反华/反华品牌、烟/彩票/赌博、宗教（天堂/庙宇/灵魂）、迷信（星座/算命/风水）、歧视（性别/地域/种族）、西方节日、房价（尤其大城市）、加班（996）、明星照片、非政府组织、奢侈品、游戏名。

> 已脱贫的"贫困县"不应出现；品牌需脱敏处理（可用商品ID分析）。
