## 通用规范

> **产出与路径**：`附录/` 用**相对路径**写在自己会话空间（`artifacts/{教材名称}/附录/`），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）（见 jc-0 路径工具 §1/§4）。

编写内容必须遵守以下共享规范：
- `references/用语与格式规范.md` — 用词替换表、标点符号、敏感词、内容质量
- `references/思政融入规范.md` — 思政融入方式与敏感词清单

## 输入上下文

- **全书知识准备产出**：所有章节正文内容
- **章节目录**：全书完整目录

> **路径（本 Skill 的输入/产出）**：**输入**文件路径由父编排在 task 中注入，是**绝对路径**（运行态根 + 产出方会话目录 + 相对路径），**原样使用**，**禁止**用相对路径去猜；**产出**一律用**相对路径**写在自己的会话空间（会话之间不共享目录），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）。完整规则见 `jc-0-路径工具`。

## 内容（3类，按需选择）

1. **补充知识点**：
   - 文中提到但未详细阐述、且内容重要的知识点
   - 作为正文知识点的扩充和升级信息
2. **查询表**：
   - 全书中用到的固定参数汇总（如函数速查表）
   - 官网上已有的内容不建议附录，以官网作为参考文献
3. **名词中英文解释**：
   - 对目标读者来说较难理解的词
   - 主要用于翻译类书籍

**不重复正文内容，准确完整。**

## 格式要求

- 附录用「标题2」样式，编号 A、B、C……
- 附录下标题从四级开始
- 以表格为主时可统一不加题注

## 约束

1. 不重复正文已详细介绍的内容
2. 数据准确、格式规范
3. 编号连续

---

## 修改模式

当收到 `[修改指令]` 时：
1. 提取版本号
2. 仅修改反馈中的问题点，其余保持原样
3. 逐条对照审核反馈修正
4. 输出完整内容，标注版本号
