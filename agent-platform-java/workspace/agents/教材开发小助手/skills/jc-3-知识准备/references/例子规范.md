# 例子规范

每个题注化示例严格按以下结构（内部编排逻辑，输出时不显示序号）：

```
① 例子的背景 → ② 数据的解释 → ③ 操作的原因 → ④ 具体的操作过程 → ⑤ 解释结果
```

| 步骤        | 句式模板                                                    | 内容                                               |
| ----------- | ----------------------------------------------------------- | -------------------------------------------------- |
| ① 背景     | "以…为例" / "某公司收集了…"                               | 一句话说清要做什么                                 |
| ② 数据解释 | "数据特征主要包括XX（字段含义）、YY（单位）…"              | 字段+含义+来源                                     |
| ③ 操作原因 | "根据…，需要分别使用…"                                    | 为什么做这个操作（实际意义，不能"为了操作而操作"） |
| ④ 操作过程 | 代码题注 → 代码(含详细注释)                                | 代码X-N 描述                                       |
| ⑤ 结果解释 | "运行代码X-N得到的结果如下。" → 结果 → "从结果可以看出…" | 逐项解释意义、应用方向                             |

## 硬约束

1. 贴近读者生活，阳光积极向上，绝不含敏感词和负面内容
2. 具有实际意义，不能为了操作而操作
3. 例子尽量最新，涉及日期的数据保持时效性
4. 避免含有消极的例子（犯罪、死亡、传染病等）
