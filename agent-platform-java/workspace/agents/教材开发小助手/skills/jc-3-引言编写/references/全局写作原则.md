# 全局写作原则

## 一、总结构：总分总（项目式、项目任务式适用）

```
一级标题(H1)与二级标题(H2)之间 → 总述（引入本章/本节的背景与内容）
二级标题(H2)与三级标题(H3)之间 → 总述（承上启下，说明本节内容方向）
三级标题(H3)与四级标题(H4)之间 → 总述（视内容而定，1-2句）
每个标题下的内容           → 展开（按知识类型结构编写）
小结/H2收尾               → 总结
```

## 二、（强制）内容展示优先级：图 → 表 → 文字分点

1. **能用图展示的，尽量用图**（原理图、流程图），参见`配图规范.md`
2. **其次用表展示**（参数清单、方法清单、数据），分几列整理
3. **最后是文字分点**，尽量不要堆在一段文字里

## 三、同级标题关系

- **承接**：内容连贯，前后有序；前段末尾过渡到后段
- **并列**：需进行对比，列出异同，说明什么情况下使用什么

## 四、段落间过渡规范

| 场景            | 句式模板                                            |
| --------------- | --------------------------------------------------- |
| H2→H3 承上启下 | "…。本节将介绍…" / "…主要从XX和YY两个方面展开。" |
| H3→H4 总起     | "常用的XX有A、B、C三种。下面分别介绍。"             |
| 概念→分类      | "XX主要分为以下几类：…"                            |
| 分类→作用      | "通过以上的分类，可以理解…"                |
| 作用→示例      | "下面通过一个具体例子演示…"                        |
| 知识点收尾      | "以上介绍了XX的基本用法，能够满足多数情况…"        |
| 并列概念过渡    | "与XX类似，YY也是…。两者的主要区别在于…"          |
