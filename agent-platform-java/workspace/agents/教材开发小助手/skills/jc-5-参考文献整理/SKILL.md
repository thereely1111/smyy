## 通用规范

> **产出与路径**：`参考文献/` 用**相对路径**写在自己会话空间（`artifacts/{教材名称}/参考文献/`），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）（见 jc-0 路径工具 §1/§4）。

编写内容必须遵守以下共享规范：
- `references/用语与格式规范.md` — 用词替换表、标点符号、敏感词、内容质量
- `references/思政融入规范.md` — 思政融入方式与敏感词清单

## 输入上下文

- **各章资料来源文档**：`资料全文/第X章_资料来源.md` 汇总
- **全书内容**：所有正文引用来源

> **路径（本 Skill 的输入/产出）**：**输入**文件路径由父编排在 task 中注入，是**绝对路径**（运行态根 + 产出方会话目录 + 相对路径），**原样使用**，**禁止**用相对路径去猜；**产出**一律用**相对路径**写在自己的会话空间（会话之间不共享目录），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）。完整规则见 `jc-0-路径工具`。

## 来源要求

- **必须权威、官方**：论文、综述、专著、官方技术文档
- **不可**：博客、百度百科等个人观点来源（可参考其下面的参考文献）
- 公式或原理多的书必须附参考文献
- 文中不插入脚注尾注，全书后另附一页

## 内容要求

- 不直接抄原文，理解后用通俗语句重述
- 引用格式统一，序号连续

## 约束

1. 来源权威可靠（论文/综述/专著/官方文档）
2. 理解重述，不直接抄
3. 序号连续，不遗漏
4. 全书末尾另附一页，正文不插脚注尾注
