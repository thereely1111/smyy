## 输入

| 参数          | 说明                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| 目录.md       | 章节目录，含【知识准备】/【项目实施】组件标记，判定知识准备范围        |
| 目录结构.json | 章节结构树（含`思政_required`/`os`/`tools`），检索词叶子节点来源 |

> **路径（本 Skill 的输入/产出）**：**输入**文件路径由父编排在 task 中注入，是**绝对路径**（运行态根 + 产出方会话目录 + 相对路径），**原样使用**，**禁止**用相对路径去猜；**产出**一律用**相对路径**写在自己的会话空间（会话之间不共享目录），并在 `【TASK_RESULT】artifacts` 里逐文件登记（`<自身会话目录>/<相对路径>`）。完整规则见 `jc-0-路径工具`。

## 执行步骤

### Step 1：提取知识准备知识点（检索词）

**只检索「知识准备」知识点，不检索「项目实施」环节。**

- **知识准备范围判定**：以 `目录.md` 中【知识准备】组件下的 H2/H3/H4 为准；【项目实施】组件下的内容不作为检索对象。
- **检索词来源**：`目录结构.json` 的叶子节点，遍历 `children2 → children3 → children4`，取最细层（H4）标题作为检索词；无 `children4` 时退到 `children3` 层标题。

### Step 2：检索

**2.1 技术知识点（知识准备）** — 仅 KB 检索（默认）：

- KB：**仅通过 `../jc-0-知识库检索/scripts/search_kb.py --scope knowledge` 检索「学科知识库」**，禁止用 `--scope case` 或 `--scope dataset`
- **资料来源模式（取父任务注入值，未注入一律按「仅知识库」）**：
  - **仅知识库（默认）**：**禁止联网**——不得调用 web_search；KB 未覆盖的知识点在该条目下标注 `⚠️ KB未覆盖，需人工补充`，不得编造来源
  - **知识库+互联网**：KB 未覆盖的知识点，才可通过 web_search 补充（KB 命中结果必须原样保留，不得降级）

**2.2 案例检索** — 本 Skill 不执行。案例库（`--scope case`）检索由 jc-1-目录生成 负责，案例原文下载由 jc-2-来源核查 负责。

**2.3 思政素材** — 优先 KB 检索（`--scope knowledge`）；KB 无命中时：仅「知识库+互联网」模式下可用 web_search 补充，「仅知识库」模式下标注 `⚠️ KB未覆盖，需人工补充`（若 `目录结构.json` 顶层 `思政_required = false` 则跳过）。

### Step 3：输出

按输出模板汇总写入。KB 命中结果必须原样写入，不得降级为外部来源。

## 来源规范

**允许（仅知识库模式，默认）**：仅知识库条目（含 URL + entry_id）。
**额外允许（仅知识库+互联网模式）**：官方技术文档、工具/产品官网、行业报告、政府/官方来源、图书（书名+作者+出版社+ISBN）、期刊论文。每条标注来源类型并附 ≤200字摘要。

**禁止**：个人博客、知乎、CSDN、简书、掘金、博客园、搜狐号、百家号、微信公众号、未署名网络文章、社区文档、百度百科。

思政额外禁止：境外媒体、未经官方确认的传闻、社交媒体热帖。

---

## 约束

1. 严禁捏造来源，来源必须可溯源
2. **默认仅知识库，禁止联网**：未注入「资料来源模式=知识库+互联网」时，一切 web_search / 外部抓取均禁止，KB 未覆盖处标注告警
3. 重检仅补未达标部分，已达标保留不动
4. `os`/`tools` 从目录结构.json 章级读取
5. **检索范围仅限「学科知识库」（`--scope knowledge`）**，禁止检索案例库/数据库
6. **仅检索「知识准备」知识点**（以目录.md 的【知识准备】组件为准），不检索【项目实施】环节

---

## 重检模式

接收核查报告时，仅补充未达标部分：

| 核查指示          | 动作（仅知识库，默认）                        | 动作（知识库+互联网）                       |
| ----------------- | --------------------------------------------- | ------------------------------------------- |
| 无来源 / 来源不足 | KB 换词重新检索；仍无命中 → 标注「⚠️ KB未覆盖」 | 双路换词重新检索（KB 优先 + web_search）    |
| 环境不匹配        | KB 换词检索（携带核查报告指定的 OS/工具检索词） | 外部搜索（携带核查报告指定的 OS/工具搜索词） |
| 思政不达标        | KB 换词检索；仍无命中 → 标注「⚠️ KB未覆盖」     | 换词 web_search                              |

补搜结果追加到对应知识点下，更新来源统计表。
