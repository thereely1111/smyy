按你的要求重构配色：全程无黑色。主操作按钮、用户气泡、选中态统一使用靛蓝 Indigo（#4F46E5）；「AI 正在思考/生成」使用专属紫色 Violet（#7C3AED），两个色相同属蓝紫家族、 和谐共处又各司其职；中性色从纯黑灰换成冷调 Slate 石板灰，界面整体更轻盈通透。 保留 Cal Sans + Inter 字体、ring 阴影质感与 4px 间距体系，所有规范按 Tailwind v4 + shadcn 技术栈给出落地映射。

01设计原则

四条原则决定之后的每一个 token、组件和布局决策。它们来自对现有界面的审计与你的新要求：去黑、轻盈、智能感。

🫧
轻盈为底，色彩即信号

告别炭黑重压：界面以白与浅石板灰铺底，靛蓝承担主操作，紫色只在「智能发生」时点亮。色彩稀缺，才可信。

🧩
Token 三层，一处定义

Primitive（原始色阶）→ Semantic（语义角色）→ Component（组件用法）。页面禁止写死色值，换主题/改品牌只动一层。

👪
蓝紫一家，分工明确

靛蓝与紫同属冷色家族，天然和谐；用「靛蓝=用户操作、紫=AI 行为」这条单规则，让用户一眼分辨「我做的」和「AI 做的」。

♿
可访问性是地基

对比度、44px 触达、焦点环、键盘路径在 token 层一次做对。现网次要正文 #898989 不达标，本方案直接修正为 slate-500。

04间距、圆角与深度

06响应式布局策略

工作台（/space）是核心场景：会话列表、聊天主区、产物面板三者的关系随断点变化。 关键原则：聊天主区永远在场，列表与产物面板按断点降级为抽屉（Sheet）。 侧边导航由深色改为浅石板灰底 + 靛蓝选中态，整页无重色块，更轻盈。 分栏聊天列保留 8px 右内边距，避免滚动条贴分隔条。

桌面 ≥ 1280px三栏常驻

侧边导航 220px（浅灰底、靛蓝选中）+ 会话列表 280px + 聊天区自适应；产物面板 320px 可折叠。

平板 768–1279px两栏 + 抽屉

导航折叠为图标栏（64px）；产物面板改为右滑 Sheet，消息内产物 chip 常驻可点。

手机 < 768px单列 · 主区为王

单列聊天；导航与会话列表统一收进左滑抽屉；输入框吸附底栏，触达目标 ≥44px。

键盘与焦点

全部交互可 Tab 到达，顺序符合视觉流；焦点环 3px 靛蓝统一 token；Dialog 打开锁焦点、ESC 关闭、关闭后焦点归还。命令面板支持 ⌘K。

动态与缩放

所有动效尊重 prefers-reduced-motion；页面支持 200% 文字缩放不破版；流式光标、骨架屏动画均提供降级静态态。

08落地路线图

按「先体系、后组件、再页面」的顺序推进，每一阶段独立可交付、可回滚。本轮仅评审本方案，任何阶段动代码前都会再次与你确认。

P1
Token 层落地

在 index.css 建立三层 token（primitive / semantic / component），主色切靛蓝、中性色切 Slate、次要正文色修正为 #64748B。shadcn 变量名保持兼容，44 个组件零改动直接受益。

下一阶段执行 · 改动最小、收益最大
P2
组件规范收敛

按钮/输入/卡片/气泡按本方案状态矩阵核对与补齐（loading、焦点环、触达热区、用户气泡靛蓝化、AI 光标紫色化），输出 Storybook 状态对照页作为设计 QA 基准。

待评审后排期
P3
响应式三档布局

工作台三栏/两栏+抽屉/单列三档改造，侧边导航浅色化+靛蓝选中态，产物面板 Sheet 化；保留 8px 聊天列内边距等既有细节约定。

待评审后排期
P4
暗色模式

基于 semantic token 做 dark 变体（Tailwind v4 @custom-variant dark 已就绪）：Slate 反转为深底、靛蓝提亮至 #818CF8、紫提亮至 #A78BFA，逐页面验收对比度。
